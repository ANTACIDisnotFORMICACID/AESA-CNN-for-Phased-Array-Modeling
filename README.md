# AESA-CNN 算法版本演进

本仓库整理 47 GHz 有源相控阵项目中由本人完成的算法版本。提交历史从 V2.5 开始，
每个版本对应一个独立提交和同名 Git 标签；接手项目前的原始主线代码不在本仓库中。

当前已纳入：**V2.5**。

## 研究主线

项目围绕物理约束的远场建模和波束控制展开：将阵列几何、传播相位和相干叠加写入
解析主干，再用轻量神经网络学习解析模型未覆盖的残差。后续版本逐步增加 HFSS 数据合同、
幅度监督、复算子审计、结构消融和跨阵列验证。
