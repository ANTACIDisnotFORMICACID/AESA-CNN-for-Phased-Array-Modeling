# V2.16 DCAR Stage-0 结果与路线判断

日期：2026-09-14。结论状态：`v216_stage0_stop`。

后续状态：本文件保留首版单空间层DCAR的负结果。恢复V2.12控制变量后的Stage-1已经通过，见 [V2.16_STAGE1_CONTROLLED_DCAR_RESULTS_20260914.md](V2.16_STAGE1_CONTROLLED_DCAR_RESULTS_20260914.md)；Stage-1不覆盖或删除本文件证据。

## 一句话结论

从V2.12重新分叉、去除graph/S后的首版DCAR没有形成性能候选。`axial_gated`相对V2.12 control在validation平均退化2.216 dB，在coverage probe平均退化2.103 dB，均为0/3种子改善；不建立、不开启新的confirmatory test。

本轮真正获得的结论是：方向gate相对同为单空间层的各向同性对照有弱的正信号，但初始方案把V2.12的空间计算图削减得过多，不能据此否定轴向结构本身。

## 实验边界

- 四臂均从头训练，paired seeds为21601、21602、21603；每组240 epochs，共12组、2880 epochs，累计训练4036.1 s。
- train为22600方向×64命令；validation为4900方向×16命令；coverage probe为4380方向×16命令。
- V2.16 train/validation包从V2.12与V2.14源重新生成，并与V2.15对应包逐字节一致。
- checkpoint只由validation linear NMSE选择；coverage只在训练全部结束后审计。
- 旧V2.15 external test未读取；新confirmatory test未定义、未开启。
- 假设来自已观察过的旧结果，因此validation/coverage只属于机制探索证据。

## 结构与结果

所有模型共享V2.12的解析相位、逐阵元复基准、L=4 filtration SSH、Fourier-27方向编码、IQ残差与相干求和。差异仅在CNN residual分支。

| arm | residual空间结构 | 参数量 | validation NMSE / MAE | coverage NMSE / MAE | 复operator NMSE |
|---|---|---:|---:|---:|---:|
| `control_v212` | 3×3 stem + 2个双3×3 residual blocks + 3×3 head | 28,789 | −26.469 dB / 0.633 dB | −26.590 dB / 0.619 dB | −20.493 dB |
| `axial_static` | 1×1 stem + 并联3×1/1×3 + 1×1 head | 30,861 | −24.161 dB / 0.914 dB | −24.422 dB / 0.895 dB | −18.411 dB |
| `axial_gated` | static + 两个方向条件gate | 30,917 | −24.253 dB / 0.948 dB | −24.487 dB / 0.922 dB | −18.690 dB |
| `iso_control` | 1×1 stem + 单个3×3 + 1×1 head | 30,877 | −23.917 dB / 0.930 dB | −24.199 dB / 0.904 dB | −18.409 dB |

表中为三种子均值。`axial_gated`与`iso_control`只差40个参数，即0.130%；与V2.12 control相比参数增加7.392%。CPU审计延迟分别为21.56与20.85 μs/方向，gated约慢3.4%，该数字只代表当前CPU批量实现。

## 成对统计

改善定义为“reference NMSE − candidate NMSE”，正值才表示candidate更好。95%区间使用三对种子的Student-t区间；样本很小，区间只作尺度提示。

| 比较 | 平均改善 | 3个配对值 | 95% CI | 正向种子 |
|---|---:|---|---|---:|
| gated vs V2.12，validation | −2.216 dB | −1.936, −2.064, −2.649 | [−3.162, −1.271] | 0/3 |
| gated vs V2.12，coverage | −2.103 dB | −1.858, −1.860, −2.591 | [−3.152, −1.054] | 0/3 |
| static vs V2.12，validation | −2.308 dB | −2.939, −2.220, −1.765 | [−3.777, −0.838] | 0/3 |
| gated vs static，validation | +0.092 dB | +1.003, +0.156, −0.884 | [−2.256, +2.439] | 2/3 |
| gated vs iso，validation | +0.336 dB | +0.455, +0.936, −0.384 | [−1.324, +1.995] | 2/3 |
| iso vs V2.12，validation | −2.552 dB | −2.391, −2.999, −2.265 | [−3.527, −1.577] | 0/3 |

机制gate只有“gated优于iso的均值/方向”“参数匹配”“有限非负输出”“外部测试封印”通过；主性能、static增量和gated对static均值门槛未通过。

## 弱场为何退化最明显

gated相对V2.12在validation四个场强区的平均变化依次为：

| 真值场强 | gated相对control改善 |
|---|---:|
| −3至0 dB | −1.306 dB |
| −10至−3 dB | −1.482 dB |
| −20至−10 dB | −2.253 dB |
| 低于−20 dB | −4.644 dB |

coverage上对应为−1.351、−1.543、−2.174、−4.107 dB，趋势一致。

对命令 (w)，复场与预测扰动为

\[
E(q,w)=\sum_n w_ng_n(q),\qquad
\Delta E(q,w)=\sum_n w_n\Delta g_n(q).
\]

当真实场靠近零陷时，\(|E|\)很小，一阶相对幅度误差近似满足

\[
\frac{\Delta |E|}{|E|}
\approx
\frac{\Re\{E^*\Delta E\}}{|E|^2}.
\]

因此相干抵消区会放大阵元间相关残差的微小错误。当前DCAR只有一次“十字形”邻域传播，既没有对角路径，也没有多跳孔径传播，弱场首先恶化与这一物理敏感性相符；但这仍是机制解释，不是唯一因果证明。

## 对原方案的自检

合理之处：数据完全配对、结构臂在训练前冻结、参数对照达到0.5%门槛、零残差起步、validation与coverage职责分离，并且旧/新外部测试均保持封印。

需要修正之处：原方案把V2.12写成“depth=2”，容易误读成两次空间卷积。实际V2.12 residual含3×3 stem、两个各含两次3×3的block以及3×3 head，总计6次空间卷积；首版DCAR和iso只有1次空间卷积。此外新臂还移除了edge/corner两张拓扑图。因此：

\[
\text{V2.12}\rightarrow\text{当前新臂}
=\text{空间深度变化}+\text{感受野变化}+\text{拓扑图变化}+\text{核形状变化}.
\]

`iso_control`只完成了参数量匹配，没有完成深度、感受野和输入图匹配。故不能把约2 dB退化唯一归因于“axial不合理”，也不能声称已经干净证明“深度就是唯一原因”。

raw gate也存在尺度/符号gauge：若卷积权重变号而gate同步变号，实际消息可不变。三种子中row gate与\(q_y\)的Pearson相关从−0.696到+0.243，column gate与\(q_x\)从−0.660到+0.575，没有稳定的轴向物理图景；在计算有效消息贡献前，不对raw gate作物理归因。

## 后续路线

当前模型停止，不做test，也不在其上继续堆模块。下一次实验应先预注册一个正交的两步拆解：

1. `V2.12-29map`：保持V2.12全部6次3×3空间卷积，只去掉edge/corner图，单独测量拓扑提示的价值；
2. `deep-iso-29`与`deep-axial-29`：使用相同29图输入、相同残差级数、匹配感受野与参数量，再只改变3×3和3×1/1×3传播；
3. 只有deep-axial稳定不差于deep-iso后，才加入direction gate；gate应审计有效消息 \(\gamma_a(q)F_a(H)\)，而不是只看不可辨识的裸标量；
4. 继续把S参数留在主线之外，直至轴向/深度机制被独立确认。

这条路线保留了用户方案中“从V2.12物理核心分叉、只研究规则孔径残差传播”的主旨，同时修正了首版实验中深度和输入拓扑未被隔离的问题。
