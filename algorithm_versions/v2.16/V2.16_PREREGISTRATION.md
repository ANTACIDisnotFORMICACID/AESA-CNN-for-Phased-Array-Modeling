# V2.16 DCAR 路线分叉与机制实验预注册

日期：2026-09-14。本版本从 V2.12 的相干复算子重新分叉，不继承 V2.15 graph residual。现有 V2.15 及其已开启 external test 保持冻结，不覆盖、不重解释、不用于 V2.16 结构选择。

## 唯一研究问题

V2.12 已确定学习对象：去除解析传播相位后的复 envelope residual。V2.16 只检验：

> 剩余复残差在规则4×4阵列孔径上是否具有局部、轴向各异、且随观察方向变化的空间结构？

固定物理骨架为

\[
g_n(q)=a_n(q)e^{jkq^Tr_n},\qquad
a_n(q)=s[b_n+a_{\mathrm{SSH},n}(q)+\delta_n(q)],
\]

\[
\hat y(q,w)=\left|\sum_{n=1}^{16}g_n(q)w_n\right|.
\]

解析相位、逐阵元复基准、L=4 filtration SSH、Fourier-4方向编码、IQ残差和相干求和均不改变。

## DCAR 结构

真实阵列孔径轴是 column-+Y 与 row-+Z，boresight 是 +X。输入仅为27维方向编码和2张连续阵元坐标图，不使用 edge/corner map：

\[
z_n(q)=[\Gamma(q),u_{\mathrm{row},n},u_{\mathrm{col},n}]\in\mathbb R^{29}.
\]

1×1 stem 只做逐阵元特征嵌入，不进行空间混合：

\[
H_0=P_{\mathrm{in}}z.
\]

唯一空间传播为 row 方向3×1卷积与 column 方向1×3卷积：

\[
H_1=H_0+\gamma_r(q)F_{3\times1}(H_0)+\gamma_c(q)F_{1\times3}(H_0).
\]

static arm 固定 \(\gamma_r=\gamma_c=1\)；gated arm 使用

\[
[\gamma_r(q),\gamma_c(q)]=\tanh(W_g\Gamma(q)+b_g).
\]

最终1×1 IQ head只解码通道，不再混合空间，并保持 weight/bias 全零；输出继续使用 componentwise \(2\tanh(z/2)\)。主模型不包含graph、S参数、普通3×3 residual block、edge/corner map或自由16×16矩阵。

## 四个固定实验臂

| arm | residual结构 | 对应假设 |
|---|---|---|
| `control_v212` | V2.12 width=24、2个3×3 residual blocks | H0基线 |
| `axial_static` | 1×1 stem + 3×1/1×3 + 1×1 head，无方向gate | H1轴向分解 |
| `axial_gated` | static结构 + 27→2方向gate | H2方向条件化轴向传播 |
| `iso_control` | 1×1 stem + 普通3×3 residual + 1×1 head | 等容量各向同性反事实 |

`axial_gated` width固定68；`iso_control` width固定56，使两者参数差小于0.5%。三种新结构都从零残差开始。参数量、感受野和初始化在训练前由单元测试冻结。

## 数据与泄漏边界

- 重新从 V2.12 amplitude dataset、split、codebook 和 V2.14 acquisition 生成 V2.16 独立包；固定 exchange removal seed=21470。
- train：22110个原方向+490个acquisition方向，64条train commands，共22600方向。
- validation：4900个既有validation方向、16条validation commands，仅用于checkpoint选择和探索性结构比较。
- coverage_probe：4380方向、同16条validation commands，仅在训练完成后开启，不参与checkpoint选择。
- 旧V2.15 external test、其方向、命令、幅度和结果均不进入任何V2.16程序参数或产物。
- 因为当前结构假设是在看过V2.15结果后形成，旧validation/coverage也只能作为机制探索证据，不作为全新confirmatory test。
- 本阶段不定义或开启新的confirmatory test。只有机制gate通过后，才另行预注册全新方向/命令holdout；在此之前不授予模型资格。

## 完整训练协议

- paired seeds：21601、21602、21603；四臂全部从头训练；
- 240 epochs，AdamW，batch=512；
- LR=1e-3，第181 epoch降为3e-4；
- `lambda_separation=0.001`；
- checkpoint只按validation linear NMSE选择；
- coverage、复算子audit和gate解释均在训练结束后执行。

## 探索性机制gate

全部条件在运行前固定：

1. `axial_gated` 相对 `control_v212`：validation平均改善≥0.30 dB且3/3正向；
2. `axial_gated` 相对 `control_v212`：coverage_probe平均改善≥0.30 dB且3/3正向；
3. `axial_static` 相对 `control_v212`：validation平均改善≥0.10 dB且至少2/3正向；
4. `axial_gated` 相对 `axial_static`：validation平均改善≥0.10 dB且至少2/3正向；
5. `axial_gated` 相对 `iso_control`：validation平均改善≥0.10 dB且至少2/3正向；
6. `axial_gated` 与 `iso_control` 参数差≤0.5%；
7. 全部预测有限且非负，所有checkpoint记录旧test未使用。

gate通过只表示“值得建立新confirmatory test”；失败则保留完整结果并Stage-0 stop。无论结果如何，本阶段不读取旧V2.15 test，也不声称硬件、OTA或FPGA有效。
