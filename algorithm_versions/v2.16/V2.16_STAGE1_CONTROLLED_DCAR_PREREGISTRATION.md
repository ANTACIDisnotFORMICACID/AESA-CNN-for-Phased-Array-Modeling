# V2.16 Stage-1：受控DCAR验证预注册

日期：2026-09-14。本实验在看到Stage-0退化后设计，属于探索性修正验证；不覆盖Stage-0结果，不使用旧V2.15 external test，也不定义或开启新的confirmatory test。

## 研究问题

Stage-0同时改变了空间深度、stem/head核、edge/corner输入和轴向传播，不能单独归因DCAR。Stage-1只改变V2.12两个residual block内部的空间传播：

\[
B_{\rm V212}(H)=H+C_2^{3\times3}\sigma(C_1^{3\times3}H),
\]

替换为

\[
B_{\rm DCAR}(H,q)=H+gamma_r(q)R_2^{3\times1}\sigma(R_1^{3\times1}H)
+\gamma_c(q)C_2^{1\times3}\sigma(C_1^{1\times3}H).
\]

其他结构固定为V2.12：31张输入图（Fourier-27、row、column、edge、corner）、width=24、3×3 stem、两个residual blocks、每条最长路径每块两次空间卷积、SiLU位置、3×3 IQ head、第二卷积和head零初始化、L=4 SSH、解析相位与相干求和。

两个DCAR block串联后允许row→column和column→row的跨轴组合；它修复Stage-0只有一跳十字传播的问题。

## 固定实验臂

| arm | 唯一用途 | 参数量 |
|---|---|---:|
| `control_v212` | 原V2.12结构；复用Stage-0同种子checkpoint | 28,789 |
| `dcar_static_native` | width=24，各轴内部宽度24，固定gate=1 | 21,973 |
| `dcar_gated_native` | native + 每个block两个方向gate | 22,085 |
| `dcar_static_pm` | 主宽度24；两block轴宽交替(36,35)/(35,36) | 28,643 |
| `dcar_gated_pm` | pm + 每个block两个方向gate | 28,755 |

`dcar_gated_pm`与control只差34参数（−0.118%）。交替轴宽使两层合计row/column容量完全对称，不把更多参数固定给某一物理轴。native臂回答参数效率，pm臂回答近等容量的DCAR作用。

## 数据和训练

- 完全复用Stage-0 `prepared_20260914`，不重新选择方向；
- paired seeds：21601、21602、21603；
- 新四臂从头训练240 epochs，AdamW，batch=512；
- LR=1e-3，epoch 181降至3e-4，`lambda_separation=0.001`；
- checkpoint只按validation linear NMSE选择；
- control复用同数据、同协议、同种子的Stage-0 checkpoint；
- coverage probe与复operator只在全部训练结束后审计。

## 探索性gate

主候选为`dcar_gated_pm`。全部条件在训练前固定：

1. 主候选相对control：validation平均改善≥0.30 dB且3/3正向；
2. 主候选相对control：coverage平均改善≥0.30 dB且3/3正向；
3. `dcar_static_pm`相对control：validation平均变化≥−0.10 dB且至少2/3不退化；
4. gated-pm相对static-pm：validation平均改善≥0.10 dB且至少2/3正向；
5. gated-native相对static-native：validation平均改善≥0.10 dB且至少2/3正向；
6. gated-pm与control参数差≤0.5%；
7. 全部预测有限非负，coverage不参与checkpoint选择，所有external test保持未使用。

全部通过只表示DCAR值得另行建立全新confirmatory test；任一失败则保留结果并停止当前结构。
