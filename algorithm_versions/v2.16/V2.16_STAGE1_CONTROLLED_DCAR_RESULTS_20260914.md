# V2.16 Stage-1 受控DCAR验证结果

日期：2026-09-14。状态：`v216_stage1_pass_eligible_for_fresh_confirmation`。

## 结论

在恢复V2.12的输入、主宽度、空间深度、stem/head、激活位置与零初始化，并把总参数匹配到0.118%后，方向条件化DCAR相对V2.12 control取得稳定改善：

- validation：平均+0.983 dB，3/3正向，95% CI为[+0.432,+1.534] dB；
- coverage probe：平均+1.011 dB，3/3正向，95% CI为[+0.428,+1.595] dB；
- 复Ephi operator：平均+1.019 dB，3/3正向，95% CI为[+0.531,+1.508] dB；
- gated-pm相对static-pm：平均+0.592 dB，3/3正向，95% CI为[+0.146,+1.039] dB。

因此Stage-0退化不是DCAR本身造成，而是当时同时删除了深度、3×3 stem/head与edge/corner图，并大幅改变参数配置。当前结果支持“深度保持、近等容量的轴向分解 + 分block方向gate”作为新候选；但仍是探索证据，只获得建立全新confirmatory test的资格。

## 控制变量如何闭合

V2.12 block为

\[
B(H)=H+C_2^{3\times3}\sigma(C_1^{3\times3}H).
\]

受控DCAR只把block内部改为

\[
B_D(H,q)=H+\gamma_r(q)R_2^{3\times1}\sigma(R_1^{3\times1}H)
+\gamma_c(q)C_2^{1\times3}\sigma(C_1^{1\times3}H).
\]

以下项目均与V2.12一致：Fourier-27+row/column/edge/corner共31图、主width=24、3×3 stem、两个residual blocks、每条最长路径每block两次空间卷积、SiLU位置、3×3 IQ head、第二卷积及head零初始化、L=4 SSH、解析相位和相干求和。

两个block串联后自然产生跨轴项，例如

\[
\gamma_{2,c}\gamma_{1,r}C_2R_1H,
\qquad
\gamma_{2,r}\gamma_{1,c}R_2C_1H,
\]

因此既保留row/column可解释性，又恢复了Stage-0缺失的二维、对角和多跳交互。

近参数匹配臂保持主宽度24，只把两block的内部(row,column)宽度交替设为(36,35)与(35,36)。两轴跨block总容量相同：

| 模型 | 参数量 | 相对control |
|---|---:|---:|
| V2.12 control | 28,789 | 0 |
| DCAR static-native | 21,973 | −23.68% |
| DCAR gated-native | 22,085 | −23.29% |
| DCAR static-pm | 28,643 | −0.507% |
| DCAR gated-pm | 28,755 | −0.118% |

所有模型初始CNN残差严格为零，完整初始算子预测逐值一致。

## 完整结果

| 模型 | validation NMSE / MAE | coverage NMSE / MAE | 复operator NMSE |
|---|---:|---:|---:|
| V2.12 control | −26.469 / 0.633 dB | −26.590 / 0.619 dB | −20.493 dB |
| static-native | −25.610 / 0.725 dB | −25.776 / 0.705 dB | −19.889 dB |
| gated-native | −26.077 / 0.678 dB | −26.241 / 0.663 dB | −20.275 dB |
| static-pm | −26.859 / 0.620 dB | −26.949 / 0.609 dB | −20.788 dB |
| gated-pm | **−27.452 / 0.590 dB** | **−27.601 / 0.575 dB** | **−21.512 dB** |

### 分步归因

1. native static相对control平均−0.859 dB：按原生轴向分解直接减少23%参数会损失精度；
2. native gate相对native static平均+0.467 dB，3/3正向：方向条件化能补回部分损失；
3. static-pm相对control平均+0.390 dB，3/3正向：近等容量后，静态DCAR本身已优于3×3 control，但三种子CI仍跨0；
4. gated-pm相对static-pm平均+0.592 dB，3/3正向且CI不跨0：方向gate提供独立、稳定增益；
5. gated-pm相对gated-native平均+1.375 dB，3/3正向：足够的轴向分支容量仍然关键。

### 场强分桶

gated-pm相对control的平均改善为：

| 真值场强 | validation | coverage |
|---|---:|---:|
| −3至0 dB | +1.508 dB | +1.463 dB |
| −10至−3 dB | +1.072 dB | +1.065 dB |
| −20至−10 dB | +0.950 dB | +0.985 dB |
| 低于−20 dB | +0.401 dB | +0.561 dB |

coverage四档均为3/3正向；validation最低场强档有一个种子−0.032 dB，其余为正。因此新结构没有重现旧V2.15明显的强场牺牲，但最深零陷仍是收益最小、最需要后续验证的区域。

## 代价与边界

- gated-pm参数量与control几乎相同，但当前CPU批量延迟为24.08 μs/方向，control为19.87 μs/方向，约慢21.2%；轴向小卷积数量更多，当前实现没有做算子融合。
- validation MAE只从0.633降到0.590 dB，coverage从0.619降到0.575 dB；NMSE约1 dB收益并不等于所有样本误差都下降1 dB。
- 四个新臂×三种子均从头训练240 epochs，共2880 epochs，累计4269.0 s；control复用完全相同数据、协议与种子的Stage-0 checkpoint。
- 旧V2.15 external test未读取；新confirmatory test未定义、未开启；coverage没有参与checkpoint选择。

## 当前版本判断

可以认为，在当前validation/coverage机制实验内：

\[
\boxed{\text{depth-matched, parameter-matched gated DCAR}>
\text{V2.12 3×3 residual}}
\]

而且改善同时出现在幅度和复operator上，结构逻辑比旧V2.15 graph/S混合路线更清楚。下一步不是继续修改网络，而是冻结`dcar_gated_pm`，单独预注册全新方向×命令confirmatory holdout；只有该测试通过，才能升级为正式替代V2.12的结论。
