# V2.6 implementation and gate report

## Outcome

The V2.6 physical-control code path is implemented and its deterministic host
tests pass.  It is not yet a release checkpoint and it is not a Vitis/FPGA
result.  The present evidence points to a fixed-array physical limit rather than
a V2.5-only model defect: production-setting amplitude/phase optimization made
only hundredths of a decibel improvement in three representative directions and
did not approach the required 3 dB strong-peak margin.

## Implemented contracts

- The canonical 47 GHz four-port embedded `ETheta/EPhi` data is used directly.
  No ideal steering fit and no second S-parameter multiplication is present.
- HFSS coordinates, `+Y` port order, 6.8 mm spacing, electrical boresight, phase
  ramp sign, and full-sphere peak search are locked by tests.
- Four DFT commands and eight greedy D-optimal fixed angles form the calibration
  acquisition.  An unknown global scan phase is removed after complex least
  squares with a healthy-port weighted gauge.
- The DPU candidate is a 15-channel, width-16, three-block 1x3 residual CNN.  It
  has 1,250 parameters and statically contains only Conv2d, depthwise Conv2d,
  ReLU6, and residual addition.
- All complex correction, health masking, disk projection, final INT8 lattice
  quantization, physical metrics, and reason bits are outside the CNN.
- The 96/24/48 state profiles use seeds 26001/26002/26003, 64 stratified targets
  per state, complete requested error/SNR ranges, 10% single-port failures, and
  whole angular macroblock split ownership.
- Resumable 64x64 oracle shards, teacher shard generation, exact-HFSS training
  losses, validation-ordered loss-grid selection, conditional NNDCT PTQ, XModel
  export, and optional `vai_c_xir` compilation entry points are present.

## Evidence obtained on this computer

- V2.6 tests: 16 passed, 0 failed.
- Calibration design condition number: about 1.114 (limit 20).
- 40 dB SNR calibration smoke residual NMSE: about -40.36 dB.
- Unseen-state calibration study: all 48/48 deterministic test states passed,
  including random global phase, 25-40 dB SNR and single-port failures.  Median
  independent-angle NMSE was `-44.24 dB`; the worst case was `-32.22 dB`, still
  beyond the required `-20 dB`.
- Observer linear-superposition gate: uses the previously validated direct-source
  report and retains the exact complex linearity test.
- Production oracle spot check (32 starts, up to 300 steps):

  | Target `(theta, phi)` | Phase-only margin | Continuous margin | INT8 margin | Continuous feasible |
  |---|---:|---:|---:|---|
  | `(113°, -8°)` | 0.0581 dB | 0.0758 dB | 0.0881 dB | no |
  | `(90°, 0°)` | -0.6856 dB | -0.6752 dB | -0.6751 dB | no |
  | `(75°, 20°)` | -2.0078 dB | -1.9752 dB | -1.9743 dB | no |

- Complete 64x64 phase-only map (4,096 targets, 32 deterministic starts): zero
  feasible directions.  Median target-to-peak was `-0.7463 dB`, median pointing
  error was `25.95°`, and the maximum 8°-outside strong-peak margin was only
  `0.0879 dB`.  This is a complete phase-only result; the continuous amplitude/
  phase map remains pending and is not inferred from it.
- Calibrated analytic/zero-residual baseline on 384 unseen samples (three healthy
  and three single-port-failure states): all outputs were finite and target-power
  regret versus the state-specific phase-only oracle was only `0.0211 dB` at the
  median (`0.0349 dB` at p95).  Nevertheless, feasible count remained zero,
  median pointing error was `23.03°`, and median strong-peak margin was
  `-0.6830 dB`.  This separates accurate target-power maximization from the
  array's inability to form an unambiguous beam.

- V2.5 read-only regression: all 35 unit tests pass; the V2.4 controller/golden
  bundle check passes.  The V2.5 full-pattern JSON check reports only one FP64
  last-bit difference (`4.93e-32`) and no file was regenerated.
- Static deployment audit: pass, zero unsupported PyTorch core nodes.  This is
  not an XIR compiler result.
- Vitis gate: blocked because Docker CLI, NNDCT, and compiler are not discoverable
  in the current host process.  No new software was downloaded.
