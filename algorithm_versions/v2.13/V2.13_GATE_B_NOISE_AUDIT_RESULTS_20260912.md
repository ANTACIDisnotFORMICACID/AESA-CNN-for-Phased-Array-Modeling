# V2.13 Gate-B 幅度-only 可辨识性与噪声审计（2026-09-12）

## 1. 结论

仓库只读审计没有找到可用于真实噪声估计的非相同独立 HFSS/实测功率重复。因此：

- Gate B 的算法状态保持 **ideal-synthetic-only**；
- Gate B 的硬件状态保持 **hardware-blocked**；
- 本报告的 SNR 扫描只用于测量设计和失效边界，不能证明硬件 amplitude-only 可辨识。

## 2. 数据审计

唯一带 repeat 轴的功率文件是 V2.12
`hfss_operator_96_20260910/audit/power_repeats.npy`，shape 为
`[32400,96,3]`。机器核验得到：

- repeat 0/1 最大绝对差：`0.0`；
- repeat 1/2 最大绝对差：`0.0`；
- repeat range 大于零的方向—命令单元数：`0`。

生成脚本也明确使用 `np.repeat(abs(g@w)^2,3)`，PREPARATION metadata 标记为
`synthetic_identical_zero_noise_baseline`。它不能估计噪声协方差。

V2.8/V2.10 幅度数据各自只有一个由 HFSS FFD/复场合成的幅度面，没有 repeat 轴。
Gate A 的 8 份直接 HFSS 报表对应 8 条不同命令；H00/H90 是刻意相差 90° 的全局相位
控制。二者功率相对 L2 差约 `1.50e-15`，但不是独立重复采集，而且复用同一已收敛
HFSS 解，因此也不能估计真实噪声。

## 4. Synthetic noise protocol

使用现有 privileged HFSS complex truth，但只选择 `query_validation` 的全部 4900 个方向。
没有读取或评价 external-test observations，也没有训练或评价 CNN。

- recovery：64 条冻结 train commands；
- held-out：16 条冻结 validation commands；
- synthetic repeats：每个场景 5 次；
- inversion：V2.12 graph synchronization + rank-one factor fitting，400 步；
- SNR：20/30/40 dB；
- 置信区间：按方向 bootstrap 400 次，95% CI；
- additive：功率域零均值 Gaussian，负值裁剪为 0；
- multiplicative：均值为 1 的 lognormal 相对功率噪声；
- mixed：加性与乘性分量等方差分配，使总噪声满足目标 SNR。

SNR 定义为：

\[
20\log_{10}\frac{\operatorname{RMS}(P_{\rm clean})}
{\operatorname{RMS}(\Delta P)}.
\]

## 5. 主要结果

下表的 operator NMSE 对比 `Q_hat_amp` 与 privileged `Q_truth=g^*g^T`；power NMSE
在 held-out validation commands 上对比 clean HFSS truth。CI 是方向 bootstrap CI，
不是对未来硬件噪声分布的置信保证。

| 噪声模型 | SNR | operator NMSE / 95% CI | held-out power NMSE / 95% CI |
|---|---:|---:|---:|
| additive Gaussian power | 20 dB | -23.230 / [-23.365, -23.065] dB | -26.136 / [-26.304, -25.940] dB |
| additive Gaussian power | 30 dB | -33.445 / [-33.569, -33.294] dB | -36.232 / [-36.393, -36.078] dB |
| additive Gaussian power | 40 dB | -43.480 / [-43.563, -43.372] dB | -46.328 / [-46.466, -46.191] dB |
| multiplicative lognormal power | 20 dB | -24.138 / [-24.221, -24.043] dB | -27.012 / [-27.149, -26.872] dB |
| multiplicative lognormal power | 30 dB | -34.218 / [-34.319, -34.113] dB | -37.007 / [-37.145, -36.867] dB |
| multiplicative lognormal power | 40 dB | -44.080 / [-44.183, -43.983] dB | -46.931 / [-47.077, -46.775] dB |
| mixed equal-variance power | 20 dB | -23.692 / [-23.812, -23.562] dB | -26.518 / [-26.660, -26.360] dB |
| mixed equal-variance power | 30 dB | -33.698 / [-33.855, -33.482] dB | -36.518 / [-36.722, -36.303] dB |
| mixed equal-variance power | 40 dB | -43.561 / [-43.866, -43.076] dB | -46.175 / [-46.655, -45.477] dB |

三个模型的 aggregate operator NMSE 基本随 SNR 每增加 10 dB 改善约 10 dB。30 dB
时三类模型均达到约 `-33.4` 至 `-34.2 dB` operator NMSE，因此它可以作为首轮接收链
设计目标；这只是 synthetic design target，不是硬件验收线。

## 6. Jacobian condition 与失败角区

未加权 Jacobian condition 在全部场景都很稳定：median 约 `14.75–14.83`，P95 约
`20.32–20.45`。由 5 次 synthetic repeat 的样本标准差加权后：

- additive：median `21.26–21.62`，P95 `38.71–39.71`；
- multiplicative：median `22.38–22.96`，P95 `37.70–39.05`；
- mixed：median `17.81–18.05`，P95 `33.11–33.56`。

400 步反演后，最明显的 20 dB 失败区仍是：

| 模型 | 最差 10° 角格 | operator NMSE P95 | 角格内差于 -10 dB | 全 validation 差于 -10 dB |
|---|---|---:|---:|---:|
| additive | theta 50–60°, phi 30–40° | -4.80 dB | 8.0% | 0.18% |
| mixed | theta 50–60°, phi 30–40° | -12.01 dB | 2.0% | 0.04% |
| multiplicative | theta 20–30°, phi 30–40° | -18.23 dB | 0.0% | 0.00% |

30 dB 时 additive/mixed 的全局差于 -10 dB 比例分别降到 `0.02%/0.02%`；40 dB
时 additive/multiplicative 为 0，mixed 为 `0.02%`。因此当前失效边界主要由低 SNR
下的加性功率噪声和少量特定角区长尾主导，而不是由全局 codebook 条件数整体崩溃。

## 7. 可成立与不可成立的结论

可成立：

- 冻结 64 条 train codebook 在三类明确的 synthetic 功率噪声下表现出近似线性的
  SNR—误差关系；
- 20 dB 加性噪声存在局部角区长尾，30 dB 明显缓解；
- 当前合同、验证器和协方差估计接口已经可以接入真实重复测量。

不可成立：

- 不能由此声称硬件 amplitude-only `Q` 可辨识；
- 不能把 synthetic repeat 当作仪器重复性或 HFSS 独立重复；
- 不能把 30 dB 当作未经暗室数据验证的硬件验收阈值；
- 不能使用本结果训练 CNN 或打开 external test。
