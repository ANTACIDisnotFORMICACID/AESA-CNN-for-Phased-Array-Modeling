# V2.13 首轮物理闭环结果（2026-09-12）

## 1. 结论先行

本轮成功建立了可重复的 Gate A–E 验证程序，并随后补充了 HFSS 直接组合端口复场。
当前仍未完成硬件物理闭环，最关键的边界是：

1. Gate A 已由 HFSS `Edit Sources + Far Fields report` 的独立代码路径关闭；它验证
   HFSS 线性多端口后处理，不验证真实 RF 链的非线性。
2. 三次 repeat 是完全相同的零噪声合成副本，因此 -120 dB 的 `Q` 恢复结果只证明
   inversion 与数据生成器自洽，不能证明未来硬件 amplitude-only 可辨识性。

external test 未打开，本轮未训练新模型。

## 2. Gate 状态

| Gate | 当前状态 | 可成立的结论 |
|---|---|---|
| A 独立 HFSS LTI | **Pass: HFSS linear report path** | 8 组直接 HFSS 复场与单端口 FFD 合成一致 |
| B amplitude-only | **Ideal synthetic only** | 结构化 64 条 train commands 在零噪声同源数据上可精确恢复 `Q` |
| C CNN 结构 | **Pass by construction + validation** | 网络保持 Hermitian/PSD/rank-1，validation 预测与梯度整体可靠 |
| D 结构解释 | **部分成立** | 去名义相位降低局部图粗糙度，但未使 `L<=5` 能量占比升高 |
| E 最终决策 | **Validation diagnostic only** | surrogate 权重在 truth `Q` 回放时通常接近数值参考，但无全局证书 |

因此现在不能宣称“自由空间阵列算子物理闭环已经通过”。

## 3. Gate A/B：HFSS 线性闭合，硬件幅度可辨识性仍缺失

Gate A 新增 8 组、每组 181×361 点的 HFSS 直接复数 `rEPhi` 报表：2 组公共相位
控制、4 组随机恒模相位和2组随机幅相权重。H00 复用 V2.9 已有的非合成 A01 HFSS
报表，其余7组在本轮由 PyAEDT 0.9.6 自动导出。组合复场不是 Python 生成；仅比较
端的 `g@w` 来自已有单端口 FFD。

- 聚合 complex NMSE：`-229.34 dB`；
- 每条新随机/幅相命令：`-226.75` 至 `-229.71 dB`；
- H00/H90 公共相位控制：约 `-293.5 dB`；
- 8×65341=`522728` 个方向–命令复场样本；
- HFSS 工程文件前后摘要一致，未保存源激励修改；
- external test 未使用，数据明确标记 `not_for_training=true`。

新报表由 HFSS 自动输出为 mV，历史 H00 为 V；解析器读取每列单位并显式统一到 V。
首次未换算时约 0 dB 的异常比对已被阻断和修正，原始 HFSS 报表未覆盖。

因此 Gate A 可以在“同一 HFSS 已收敛多端口线性解的 source/report 路径”范围内通过。
这验证端口顺序、功率到幅度、相位符号、单位和 coherent combination；它不意味着每个
`w` 进行了新的网格求解，也不能证明放大器压缩、状态相关器件或实测漂移不存在。

由 complex truth 直接构造的 `Q=g* g^T` 满足：

- Hermitian relative error：0；
- 最小特征值相对误差：`-4.98e-16`；
- `lambda2/lambda1` P95：`2.47e-16`；
- `w^HQw=|g^Tw|^2` 相对 L2 误差：`2.31e-16`。

这些结果与新的 HFSS 直接组合报表共同支持当前仿真的 rank-1/LTI 合同。

幅度反演相对 truth `Q` 的 aggregate NMSE 为 `-120 dB`，held-out validation
power 也是 `-120 dB`；Jacobian condition median 为 `14.23`，P95 为 `19.82`。
然而数据说明文件确认标签由同一个 `g` 合成，三次重复也完全相同。因此该结果只应
记录为“理想、零噪声、同源 inversion unit test”。

## 4. Gate C：网络结构正确，算子误差高于幅度误差

冻结候选 `G2-J-LR240_sep0p001_seed21201` 在 validation-D 上得到：

- amplitude NMSE：`-24.664 dB`；
- dB MAE：`0.750 dB`；
- bias：`-0.014 dB`；
- P95 absolute dB error：`2.621 dB`。

对应的完整 gauge-invariant operator NMSE 为 `-18.367 dB`。这比幅度 NMSE 差
约 `6.30 dB`，说明有限命令上的幅度拟合会掩盖一部分完整 `Q` 误差；以后不能只看
幅度 NMSE 判断 operator 学习质量。

power-gradient alignment：

- cosine mean：`0.9787`；
- cosine median：`0.9959`；
- cosine P05：`0.9365`；
- relative gradient error mean：`0.1814`；
- relative gradient error P95：`0.5092`。

梯度方向整体可靠，但尾部相对幅值误差仍明显，后续决策失败组应与这些低 cosine / 高
relative-error 方向做关联分析。

## 5. Gate D：`D_r` 降低局部粗糙度，但不是简单低通器

在 validation directions 上，名义去相位前后得到：

| 指标 | raw `g` | de-embedded `a` | 变化 |
|---|---:|---:|---:|
| graph roughness | 404.906 | 297.971 | **下降 26.4%** |
| `C_5` | 0.2702 | 0.1955 | **下降 27.7%** |
| `C_12` | 0.5924 | 0.6287 | 上升 6.1% |
| filtration gradient | 32.54 | 47.56 | 上升 46.2% |

这不是矛盾，而是说明不同复杂度指标观察到不同结构：局部 6 邻域变化变缓，但能量并
未集中到最低的 `L<=5` filtration；它更多被重新分布到中阶，且归一化谱梯度升高。
因此目前允许的表述是：

\[
\boxed{D_r\text{ 在冻结名义几何下减少了局部角域粗糙度。}}
\]

不允许写成“`D_r` 已证明把真实场变成低阶 SSH 包络”。此外 complex-audit artifact
没有内嵌阵元位置，当前结果依赖 V2.10 冻结的 47 GHz、4x4、15 mm/6.8 mm 名义几何；
补齐几何 provenance 后才能关闭这一限制。

受控解析扰动全部通过：通道 7 幅度乘 0.8 后 `Q_77` 比值为 0.64；通道 5 增加
20° 后相对 operator phase 误差小于 `3.4e-16`；方向相关公共相位下 `Q` 相对变化
为 `1.3e-16`。这验证了 representation 对已知物理扰动的响应和 gauge invariance。

## 6. Gate E：预测对决策有用，但数值 oracle 尚不充分

在 64 组 validation 四方向、phase-only constant-modulus max-min 问题上：

- decision gap median：`0.072 dB`；
- decision gap P95：`0.391 dB`；
- relative regret median：`1.64%`；
- relative regret P95：`8.61%`。

这说明冻结 surrogate 找到的权重在 truth `Q` 上通常接近较高预算数值参考。不过在
`26.6%` 的组中，surrogate 方案的 truth 回放值反而高于单独的 truth 优化器局部解。
所以数值参考定义为两组可行解中的较优者，并明确 `oracle_is_global=false`。当前只能
证明“具有良好的 validation 决策迹象”，不能宣称达到 HFSS 全局 oracle。

## 7. 下一步顺序

1. **补 Gate B 真实噪声**：使用非相同的重复测量，估计功率协方差，重跑 rank-1
   recovery、held-out commands、condition/failure-map 和置信区间。
2. **补齐几何 provenance**：把 16 个阵元位置、坐标系、相位符号和频率写入 complex
   audit artifact；不要借用不兼容的旧 1x4 geometry contract。
3. **强化 Gate E 数值参考**：增加多起点、独立求解器或上界/松弛，报告 optimality
   gap；再把决策失败组与 operator error、gradient alignment、弱场深零点关联。
4. Gate B 关闭后再进行 noise、方向稀疏、相位量化和通道漂移四条鲁棒性曲线。

在完成第 1 项前，不建议继续训练更大的 CNN，也不建议把当前结果写成硬件可辨识或
自由空间物理闭环证据。

## 8. Gate-B 后续更新（同日）

随后完成了全仓库重复数据审计、稳定测量导入合同和 synthetic noise sensitivity。
没有找到真实非相同重复，因此 Gate B 的硬件状态仍为 blocked。基于全部 4900 个
validation directions、64 条 train commands 和 16 条 held-out validation commands，

`[-24.14,-23.23] / [-34.22,-33.44] / [-44.08,-43.48] dB`。
