# V2.13 冻结 CNN 结构画像与压力演练（2026-09-13）

## 1. 目的与边界

本轮不训练新模型，而是回答“当前结构依靠什么、在哪里失效、下一次结构实验应改什么”。
对象为冻结的 V2.12-S `G2-J-LR240, lambda_sep=0.001` 十个种子；等参数
`G1-M5` matched-Fourier 为配对对照。只使用 4900 个 validation directions 和 16 条
validation commands，external test 继续封存。

方向扰动表示合成的坐标/指向元数据误差，不是硬件鲁棒性证据；SSH/Fourier latent
只用于结构解释，物理结论仍限于 gauge-invariant operator。

## 2. 当前结构画像

当前模型共 `29142` 个可学习参数：

| 参数组 | 参数量 | 占比 |
|---|---:|---:|
| 基准复增益 | 31 | 0.11% |
| SSH auxiliary | 1125 | 3.86% |
| Fourier residual CNN | 27986 | 96.03% |

Fourier-CNN 接收 27 个方向通道与 4 个几何通道，在物理 `4x4` 孔径上使用 width=24、
两个 residual blocks 及 3x3 stem/head；其后保持解析传播相位、rank-1 operator、
相干命令收缩和幅度观测不变。

validation 基线 NMSE 为 `-24.156±0.418 dB`；matched-Fourier 对照为
`-23.516±0.547 dB`。候选平均领先 `0.640 dB`，配对 bootstrap 95% CI
`[0.352, 0.981] dB`，复现了冻结 V2.12 的等参数优势。

## 3. 特征依赖

以下为 post-hoc 移除后的 NMSE 退化，不代表分支独立重训后的能力：

| 移除项 | 平均退化 | bootstrap 95% CI |
|---|---:|---:|
| 整条 SSH | +16.942 dB | [16.599, 17.255] |
| 整条 Fourier-CNN | +12.058 dB | [11.836, 12.280] |
| SSH l=1 | +16.744 dB | [16.351, 17.096] |
| SSH l=2 | +4.304 dB | [3.992, 4.627] |
| SSH l=3 | +3.054 dB | [2.807, 3.294] |
| SSH l=4 | +2.471 dB | [2.211, 2.702] |
| SSH l=5 | +1.933 dB | [1.809, 2.054] |

结论是：仅占 3.86% 参数的 SSH 并非装饰项，且 `l=1` 是最强结构锚点；占 96.03%
参数的 Fourier-CNN 仍不可删除。二者是强协同关系，不能按退化 dB 相加归因。

Fourier residual 的 IQ 输出中，超过固定 `tanh` 幅度上限 90% 的比例平均为 `30.0%`
（方向中位数 27.8%，P95 59.4%）。但该饱和比例与误差的 Spearman 相关为 `-0.277`，
因此它是需要受控验证的容量/参数化信号，不能据此直接断言“放宽上限一定改善性能”。
SSH/Fourier 分支能量相对最终包络可能大于 1，这是相干抵消的正常结果，不是概率占比。

## 4. 方向元数据扰动

每个 validation direction 沿两个正交切向方向做正负旋转，共四个扰动。目标仍固定在
名义方向，以模拟推理时方向元数据偏差。

| 偏差 | 候选 NMSE | 相对无扰动退化 | 对 Fourier 优势 | 优势 95% CI |
|---:|---:|---:|---:|---:|
| 0° | -24.156 dB | 0 | 0.640 dB | [0.352, 0.981] |
| 0.25° | -22.996 dB | +1.160 dB | 0.484 dB | [0.256, 0.757] |
| 0.5° | -20.882 dB | +3.274 dB | 0.293 dB | [0.142, 0.470] |
| 1° | -17.210 dB | +6.946 dB | 0.142 dB | [0.048, 0.237] |
| 2° | -12.514 dB | +11.642 dB | 0.041 dB | [-0.038, 0.110] |

SSH 的优势随坐标误差增大而收缩，2° 时已没有可靠优势。因子拆分显示，0.5° 下仅改变
CNN 包络造成的输出变化 NMSE 为 `-29.26 dB`，仅改变解析传播相位为 `-25.02 dB`，
完整变化为 `-23.58 dB`；2° 时分别为 `-20.62/-13.56/-12.74 dB`。因此大部分
指向敏感性来自物理上必须保留的阵列传播相位，不能用平滑 CNN 将其抹掉；可优化的部分
是方向元数据质量，以及只针对去相位包络的稳健性。

自检补充：0.25°、0.5°、1° 的全部扰动仍满足严格 `q_x>0`；2° 时约 1.0% 的扰动
越过该合同边界。因此 2° 只作为边界压力诊断，不能与前三档作完全同口径的合同内比较。

## 5. 误差定位

逐方向误差最强相关因素是到最近训练方向的角距离：Pearson `0.631`、Spearman
`0.638`。相对场强的相关较弱（Spearman `-0.251`），0.5° 局部敏感度为 `0.348`，
SSH/Fourier 能量占比分别只有 `0.259/0.046`。角域覆盖是当前最强、最可操作的关联指标，
但相关性不证明因果；是否优于结构修改必须通过受控补样/加权实验验证。

最差中位数 10° 角格包括 `(theta,phi) = (80–90,80–90)`、
`(120–130,-90–-80)`、`(130–140,80–90)` 与既有 Gate-B 长尾
`(50–60,30–40)`。其中部分边缘角格 P95 仅约 `-7 dB`。后续抽样和验证应优先覆盖
这些区域，而不是只提高全域网络宽度。

## 6. 对 CNN 优化的结论

下一轮结构实验按以下优先级预注册，仍须使用等参数对照和 validation-only 选择：

1. **先改数据与稳健性合同**：补齐远离训练集和最差角格的 train/validation 覆盖；加入
   小角度方向抖动，但一致性约束只作用于去相位包络，不惩罚解析传播相位的真实变化。
2. **小型可审计融合**：保持 SSH、Fourier 独立归一化与独立输出，在两者到 16 元复包络
   之间加入小型线性或 1x1 gated fusion；与无融合版本做等参数配对。
3. **受控测试容量重分配而非整体增大**：以 width=24 为对照，测试缩小 Fourier-CNN并把
   释放参数用于低阶 SSH/融合。分支移除只证明联合模型的依赖性，不能线性解释成“单位参数贡献”。
4. **单独验证 residual 输出参数化**：固定其他结构，仅比较当前 `2*tanh(raw/2)`、可学习
   全局尺度和更柔和的有界映射。由于饱和与误差没有正相关，这一项优先级低于角域覆盖和融合。
5. **不建议**直接引入 Transformer、GNN 或更深 CNN；现有证据没有显示“总容量不足”，
   而显示了覆盖误差、物理相位敏感性和容量分配不均。

正式结构变更前，建议先运行一个最小 2x2 因子实验：`fusion on/off × envelope jitter
regularization on/off`，每格使用相同配对种子与相同参数预算。验收同时看 validation NMSE、
最差角格 P95、0.5° 包络-only sensitivity、主瓣 MAE 和 Gate C 的 operator/gradient 指标。
