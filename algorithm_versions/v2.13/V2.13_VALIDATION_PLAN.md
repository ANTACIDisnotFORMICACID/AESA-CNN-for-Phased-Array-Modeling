# V2.13-Validation 冻结方案：物理闭环审计

## 1. 版本目标与边界

V2.13 只回答“现有算法是否可信”，不增加新网络结构。验证对象是 V2.12 的：

\[
a(q)\rightarrow g(q)=D_r(q)a(q)
\rightarrow Q(q)=g^*(q)g^T(q)
\rightarrow |g^T(q)w|.
\]

`a(q)` 仍用于解释网络学习的去名义传播相位表示；关于 amplitude-only 数据支持
什么的物理结论，只建立在 gauge-invariant 的 `Q`、`Q_tilde` 和观测幅度上。

冻结边界：

- 不训练新模型，不追加 SSH/Fourier 融合结构；
- 不使用 external test 进行选择或诊断；
- HFSS 复场只可作为仿真阶段的 privileged truth；
- 同一份单端口复场合成出的幅度不能作为独立 LTI 证据；
- 没有独立组合端口 HFSS 导出时，Gate A 必须报告 blocked。

## 2. 五道验证门

### Gate A：独立 HFSS LTI 闭合

需要两套彼此独立的数据：单端口复响应 `g_n(q)` 与 HFSS 对随机组合命令直接
导出的复数 `Ephi(q,w)`。评价：

\[
\epsilon_{\rm physics}
=\frac{\|E_{\rm HFSS}-g^Tw\|_2}{\|E_{\rm HFSS}\|_2}.
\]

必须同时检查复 NMSE、幅度 NMSE、逐方向 P95、强弱场分区和 HFSS 数值误差。
当前由 `abs(g^T w)` 生成的训练标签仅能检查数据流水线自洽，不能关闭本门。

### Gate B：Amplitude-only 可辨识性

仅由 train commands 的功率恢复 `Q_hat_amp`，与 privileged
`Q_truth=g* g^T` 比较，并在 held-out validation commands 上回放。真实结论还需：

- 非重复的独立测量重复样本；
- 噪声协方差与置信区间；
- codebook 条件数和失败角区；
- 不使用 validation/test commands 构造恢复目标。

零噪声、三次完全相同的同源合成重复只能标记为理想算法自检。

### Gate C：CNN 物理结构与优化梯度

验证预测 `Q` 的 Hermitian、PSD、rank-1、二次型恒等式以及 validation-D 幅度。
另外比较：

\[
\nabla_{w^*}(w^H\widehat Qw)=\widehat Qw,
\qquad
\nabla_{w^*}(w^HQ_{\rm truth}w)=Q_{\rm truth}w.
\]

梯度 cosine 和相对误差是波束优化是否会被 surrogate 引向错误方向的核心指标。

### Gate D：结构解释

用 privileged HFSS complex `g` 构造：

\[
a_{\rm nominal}(q)=D_r^H(q)g(q).
\]

比较 `g` 与 `a_nominal` 的 nested filtration spectrum、图粗糙度和有效带宽。
这里验证的是 nominal analytic de-embedding 是否降低学习复杂度，不声称恢复了唯一
真实单元包络。SSH 只解释为 hemisphere-aware structured coordinate；Fourier 是
互补的可学习方向表示，不将两个 latent 分支认作唯一物理频带。

受控扰动至少验证：通道增益、相对相位与方向相关公共相位对 `Q` 的解析响应。

### Gate E：最终波束决策

在预测 `Q_hat` 上求四方向 phase-only max-min 权重，再放回 `Q_truth` 执行。报告
worst-case gain gap 与 relative regret。非凸 truth 求解必须注明是否为全局 oracle；
若没有全局证书，参考值取所有已找到可行解中的最大值，不得报告负 regret。

## 3. 误差账本

后续所有结果按四类拆分：

\[
\epsilon_{\rm total}
=f(\epsilon_{\rm physics},\epsilon_{\rm ident},
\epsilon_{\rm NN},\epsilon_{\rm noise}).
\]

只在 Gate A/B 有独立数据支撑后，才允许把 CNN 误差解释成端到端自由空间算子误差。

## 4. 后续鲁棒性曲线

物理闭环完成后再固定模型，分别扫描 measurement noise、direction sparsity、command
phase quantization、element gain/phase drift。每条曲线同时报告 operator error、梯度
alignment 与 four-point decision gap，从而确定失效边界，而不是继续堆网络结构。

## 5. Gate-B 执行更新（2026-09-12）

仓库只读审计未找到真实非相同重复。Gate B 因此保持
`ideal-synthetic-only / hardware-blocked`，没有把同源合成或 bit-identical repeat
升级为真实证据。

已完成的替代工作：

- 冻结 64 train / 16 validation / 16 external-test command 边界；规范化测量 package
  只允许前 80 条，external test 不进入导入数据；
- 建立 long CSV、no-pickle NPZ、provenance 和非相同重复的验证合同；
- 使用 4900 个 validation directions 的 privileged HFSS complex truth，扫描
  20/30/40 dB 的 additive、multiplicative 和 mixed power noise；
- 报告 operator NMSE、held-out validation power NMSE、Jacobian condition、最差角区
  和方向 bootstrap 95% CI。

结果见 [V2.13_GATE_B_NOISE_AUDIT_RESULTS_20260912.md](V2.13_GATE_B_NOISE_AUDIT_RESULTS_20260912.md)。
该结果只决定真实测量设计，不关闭硬件 Gate B。

### Hardware pilot 已冻结（2026-09-13）

已从 4900 个 validation directions 中冻结 240 个 pilot 方向：200 个来自五个互斥
分层的概率抽样，40 个为最远点空间覆盖诊断。正式计划使用 R=10、两个 session block，
总计 240×80×10=`192000` 条功率观测。整体估计只允许使用 200 个 core rows 及其
poststratification weights；40 个 coverage rows 必须单独报告。

统计设计与采集文件见
[`artifacts/gate_b_hardware_pilot_20260913/PILOT_STATISTICAL_DESIGN.md`](artifacts/gate_b_hardware_pilot_20260913/PILOT_STATISTICAL_DESIGN.md)。
该步骤只表示 measurement plan ready；没有真实回填数据时 Gate B 仍为 hardware-blocked。

## 6. 冻结 CNN 结构压力演练更新（2026-09-13）

在不训练、不打开 external test 的前提下，已对十个冻结候选种子和等参数 Fourier 对照
完成方向扰动、物理传播/包络因子拆分、逐阶/整分支移除、参数分配、输出饱和与误差相关
审计。结果见
[V2.13_CNN_STRUCTURE_STRESS_RESULTS_20260913.md](V2.13_CNN_STRUCTURE_STRESS_RESULTS_20260913.md)。

该结果将下一轮结构候选限制为小型可审计 fusion、去相位包络抖动约束及等参数容量
重分配；任何训练前需冻结 2x2 因子设计和最差角格指标。当前结果只是 validation-only
结构诊断，不授予新模型资格，也不改变 A-E 各 gate 的既有状态。
