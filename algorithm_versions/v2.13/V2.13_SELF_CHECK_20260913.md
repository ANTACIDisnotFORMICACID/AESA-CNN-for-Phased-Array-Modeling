# V2.13 阶段性自检（2026-09-13）

## 结论

此前 Gate A-E、Gate-B 数据审计/噪声演练/硬件 pilot 以及冻结 CNN 画像的总体路线合理，
没有发现数据泄漏、基线修改或把合成证据冒充硬件证据的问题。发现一项遗漏和两项措辞
过强，均已修正；在修正完成前不进入新结构正式训练。

## 机器一致性检查

- 十个种子使用相同 split；train/validation query 完全互斥。
- CNN 压力演练只使用 validation command indices `64..79`。
- 冻结 split 的真实规模为 22600 train / 4900 validation / 4900 test；Gate-D 报告中的
  5000 只是物理审计抽样数，不是训练集规模。
- factorized envelope×propagation 前向与原始前向的最大绝对闭环误差为 `0.0`。
- 0.25°、0.5°、1° 的前半球越界率为 `0`；2° 为 `0.01`。
- 所有结果记录 `external_test_used=false`；本轮 `training_performed=false`。
- V2.12 测试 `31/31`、V2.13 测试 `19/19` 通过。

## 是否可以进入下一步

可以进入独立的新结构实验，但不应修改 V2.13：V2.13 已定义为 validation-only 物理闭环
审计。下一步应在 V2.14 实验区先做小规模可行性筛选，预注册 `fusion on/off × dephased
envelope jitter regularization on/off`，保持 external test 封存；筛选结果只能决定是否扩展到
多种子正式实验，不能直接形成最终模型结论。
