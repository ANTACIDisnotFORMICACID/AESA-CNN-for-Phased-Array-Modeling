# V2.10 正半球 CNN 与四点优化受控实验

## 结论摘要

本轮把物理工作域严格限定为阵面正对发射的半球：

\[
q_x>0.
\]

地平线 `q_x=0` 与反半球 `q_x<0` 均不参与训练、验证、四点生成、局部邻域或最终统计。
本轮保持 16 端口阵列、HFSS 状态、A10 网络结构和恒模相位约束不变，只分别改变 CNN
损失和四点求解方法。

主要结论如下。

1. **前半球专训确实提高了固定 HFSS 状态上的正向预测。** 5,500 个前半球留出方向上，
   新模型的幅度 NMSE 约为 −27.1 dB、强信号 MAE 为 0.20–0.21 dB；旧的全球训练
   A10/21011 为 −26.52 dB 和 0.23 dB。
2. **整体 CNN 指标变好，没有稳定转化成四点端到端尾部提升。** 开发集按预注册规则选中
   FM，但留出集三 seed 平均 regret P95 是 15.05%（O0），而 FSM 是 14.08%；开发选择
   没有在留出集保持配方排序。选中代表 FM/21111 与旧 A10/21011 使用相同 O0 时分别为
   13.08% 与 13.10%，差异很小。
3. **低预算真实 HFSS 四点优化已经接近高预算数值参考。** O0 的留出 regret P95 为
   2.36%，优于 O1/O2 的 3.10%。Q 特征向量初始化未胜过旧的逐目标匹配初始化，当前坐标
   细化没有产生可测改善。
4. **四点不能同时接近各自单点峰值的主因是共享波束的物理不兼容。** 高预算可行解的
   归一化最小增益中位数仅 0.165；更重要的是，谱上界证明 95% 的四点组即使允许任意
   单位范数复权值、放宽恒模限制，也不可能同时达到各自数值单点上限的 70%，99% 不可能
   达到 90%。
5. **局部鲁棒优化存在清楚的 Pareto 交换。** O4 把邻域最坏增益 P5 从 O0 的 −0.68 dB
   提高到 0.41 dB，并把名义点到邻域的下降 P95 从 3.15 dB 压到 0.97 dB；代价是名义点
   regret P95 从 2.36% 增到 17.88%。在没有明确指向误差分布前，不应直接替代 O0。

本轮仍只使用同一已打开的 HFSS 状态，没有真实轨道、制造公差、温度、安装、实测或 OTA
数据。因此“正向预测合格”只指固定状态数值代理，不是实际系统验收。

## 1. A10、B10、C10 的含义

这三个名称属于上一轮**结构/训练路线**，不要与本轮 F0/FS/FM/FSM 混淆。

|名称|结构与损失|上一轮结果|
|---|---|---|
|A10|从 V2.9 精确迁移的 Cartesian 横向等效场模型；保留解析阵列传播相位，CNN 学习每端口平滑修正|被选为上一轮基线；28,854 参数|
|B10|预测 rank-2 因子 `L(q)`，以 `Q=LᴴL/60` 保证 Hermitian PSD；命令损失加 Q 损失|Q-NMSE/强场 MAE局部略好，但整体 NMSE和四点尾部未胜 A10|
|C10|B10 加训练轨迹 Huber 与“乐观高估尾部”CVaR 代理|整体和四点尾部明显退化，不应复用该 CVaR 形式|

上一轮留出均值为：A10/B10/C10 幅度 NMSE 分别 −24.635/−24.338/−22.127 dB，四点
regret P95 分别 18.77%/19.84%/28.19%。因此本轮固定使用 A10 结构，只研究前半球训练和
损失，不再混入结构变化。

## 2. 工作域与受控设计

### 2.1 前半球数据合同

|拆分|原方向数|`q_x>0` 方向数|反半球参与数|
|---|---:|---:|---:|
|train|36,000|18,000|0|
|validation|10,800|5,300|0|
|calibration|7,200|3,600|0|
|holdout|10,800|5,500|0|

四点集合按球面面积权重抽样。开发集 240 组、留出集 600 组，每组四点；留出集四种分层
各 150 组：15° 内聚集、点间至少 15°、点间至少 45°、以及 `q_x<0.25` 的掠射区。
所有四点及每点五个局部邻居都通过 `q_x>0` 断言。

### 2.2 CNN 轴

四种配方全部使用同一个 A10 网络、同一个数据、三组配对 seed、每组 2,600 epoch × 4 step、
同一优化器和同一验证集。相同 seed 的四种配方初始权重哈希一致。

|配方|唯一改变量|
|---|---|
|F0|前半球基础命令增益损失|
|FS|F0 + 相对谱误差 `||ΔQ||₂/λmax(Q)`|
|FM|F0 + 沿 `ΔQ` 最坏特征向量投影得到的恒模相位难例|
|FSM|同时加入 FS 与 FM 两项|

### 2.3 四点求解轴

该轴直接使用真实 HFSS 因子，不经过 CNN。

|方法|定义|
|---|---|
|O0|旧的逐目标匹配初始化，8 starts × 160 step soft-min|
|O1|Q 主特征向量与混合 Q 初始化，同预算 8×160|
|O2|O1 后做 40 sweep 坐标相位细化|
|O3|32 starts × 320 step，高预算可行参考，不宣称全局最优|
|O4|每点及五个同拆分前半球邻居的局部最坏情形优化|
|X1|四个单点波束加 O1 共五状态的分时平均功率，仅作探索|

CNN 配方比较固定使用同一 O1；冻结后另做 O0/O1 与高预算交叉诊断。这样 CNN 变化不会与
四点求解器变化混为一个因素。

## 3. CNN 正向预测

以下是完整 5,500 个前半球留出方向，而不是四点子集。

|模型|幅度 NMSE 均值|seed 标准差|全场 MAE|强信号 MAE|相对谱 RMS|
|---|---:|---:|---:|---:|---:|
|F0|−27.19 dB|0.27 dB|0.48 dB|0.20 dB|0.10|
|FS|−27.08 dB|0.08 dB|0.49 dB|0.20 dB|0.10|
|FM|−27.10 dB|0.18 dB|0.48 dB|0.21 dB|0.09|
|FSM|−27.18 dB|0.15 dB|0.48 dB|0.21 dB|0.09|
|旧 A10/21011（全球训练）|−26.52 dB|—|0.53 dB|0.23 dB|0.09|

就同一 HFSS 状态的数值代理而言，CNN 已接近并通过上一轮强信号 MAE ≤0.25 dB 的工程门槛；
前半球专训带来约 0.52–0.67 dB NMSE 和 0.02–0.03 dB 强信号 MAE 改善。FS/FM/FSM 相对

这不能称为实际应用标准：没有跨物理状态和实测数据，也没有接收极化、链路预算和真实轨迹
门槛。

## 4. CNN 对四点优化的影响

### 4.1 开发选择

|配方|开发 NMSE|强信号 MAE|四点 regret P95 均值|瓶颈高估 P95 均值|
|---|---:|---:|---:|---:|
|F0|−27.687 dB|0.210 dB|13.33%|0.904 dB|
|FS|−27.758 dB|0.202 dB|12.52%|0.731 dB|
|FM|−27.472 dB|0.212 dB|**11.98%**|0.750 dB|
|FSM|−27.482 dB|0.214 dB|12.00%|**0.727 dB**|

预注册规则在 F0+0.30 dB NMSE 与 F0+0.02 dB 强信号 MAE 守门内，以四点 regret P95
最低者选择 FM，代表 seed 为 21111。该选择在打开留出集前冻结。

### 4.2 留出集 CNN × 求解器交叉

|配方|O0 regret P95|O0 成功率 `regret≤10%`|O1 regret P95|O1 成功率|
|---|---:|---:|---:|---:|
|F0|15.08%|85.44%|16.12%|83.72%|
|FS|16.72%|84.17%|16.89%|82.44%|
|FM|15.05%|86.67%|15.52%|85.22%|
|FSM|**14.08%**|**87.39%**|**14.61%**|**86.22%**|

留出集上 FSM 平均最好，而开发集选中的 FM 不是最好，说明附加损失的排序仍有抽样不稳定性。
不能在看到留出结果后把选择改成 FSM。

同一 seed、同一求解器的公平比较如下。

|模型|O0 regret P95|O0 成功率|CNN 内高预算 regret P95|高预算成功率|
|---|---:|---:|---:|---:|
|选中 FM/21111|13.08%|90.17%|12.43%|91.67%|
|旧 A10/21011|13.10%|89.67%|12.74%|90.17%|

FM 的公平改善存在，但量级很小。把 CNN 内优化预算从 O0 提到 32×320 也只能将 P95 从
13.08% 降到 12.43%。相比直接用真实 HFSS 的 O0 仅 2.36%，剩余端到端误差主要不是
低预算求解器，而是 CNN 的局部 Q 误差会被优化器主动利用。留出集各配方的瓶颈点身份命中率
仅约 44%–48%，也说明平均 NMSE 很好时，四点中“谁是最差点”仍不稳定。

因此需要区分两个问题：

- “算法离当前阵列可找到的高预算解还有多远”：CNN 代理误差是主要因素；
- “四点能否都接近各自单点峰值”：共享波束的物理兼容性是主要因素。

### 4.3 “单点利用率”与“半球强场”必须分开

此前把 `G_i(w)/G_i^solo` 称为“真实强场”并不准确。它衡量的是同一个共享权向量对第 `i` 个
目标的**单点上限利用率/四点相容性**，而不是该点在本次完整波束图中的空间强弱。半球强场应定义为：

`rho_i(w) = G(q_i,w) / P_H(w)`，其中
`P_H(w) = max_{q_x>0} G(q,w)`。

本节的分母由训练、验证、校准和留出四个互斥集合合并得到的 32,400 个正半球 HFSS 真值方向
扫描，未使用反半球数据。它覆盖 1° 离散网格，因此是离散正半球结论，不是连续半球的严格证书。

|权向量来源|`min rho` P5/中位数/P95|四点均≥0.1|四点均≥0.2|四点均≥0.5|目标最小增益 P5/中位数|半球峰值中位数|
|---|---:|---:|---:|---:|---:|---:|
|真实 HFSS O0|0.037/0.124/0.421|64.33%|22.67%|3.17%|1.11/4.47 dB|13.91 dB|
|真实 HFSS O3|0.038/0.124/0.419|64.83%|23.17%|2.83%|1.15/4.50 dB|13.90 dB|
|FM/21111 + O0|0.036/0.120/0.408|62.00%|21.33%|2.50%|0.86/4.19 dB|13.87 dB|

因此，现有“只最大化四个目标中的最小值”的目标函数并没有保证四点同时处于本次半球波束图的
强区。FM/O0 只有 62% 的四点组全部处于半球峰值以下 10 dB 内，只有 2.5% 全部处于峰值以下
3 dB 内。把真实求解预算从 O0 提至 O3 几乎不改变这些比例，说明主要矛盾不是 CNN 或局部迭代
次数，而是**目标函数没有抑制非目标方向峰值，以及固定阵列的多方向空间相容性有限**。

全局半球峰值到最近目标的角距中位数约 49.2°，到最远目标约 94.7°；这表明许多优化结果仍有
远离目标的强旁瓣/栅瓣候选。FM/O0 的位置分层结果如下：

|四点类型|`min rho` P5/中位数|四点均≥0.1|四点均≥0.5|
|---|---:|---:|---:|
|聚集 clustered|0.036/0.196|76.00%|9.33%|
|掠射 grazing|0.040/0.091|47.33%|0%|
|中等 moderate|0.034/0.117|63.33%|0.67%|
|宽分离 wide|0.035/0.116|61.33%|0%|

`min rho` 与平均两点角距、最大两点角距、平均离轴角的 Spearman 相关系数分别为
−0.36、−0.33、−0.41；与“最远目标到半球峰值的角距”的相关性最强，为 −0.56。
四点越分散、越靠近半球边缘，尤其当某一点远离实际全局峰值时，越难让四点同时成为强点。

用户提出的误差判断则得到直接验证：按**真实半球 `rho`**筛选 FM/O0 结果时，四点均满足
`rho≥0.1/0.2/0.5` 的样本数为 372/128/15，CNN 点 MAE 依次为 0.165/0.137/0.110 dB，
四点最小增益绝对误差 P95 依次为 0.624/0.387/0.278 dB。四点确实越接近同一次波束图的强区，
CNN 越可靠；但严格条件当前很少由现有优化自动实现。

需要同时使用空间相对门槛和绝对门槛：`G(q_i,w) ≥ eta P_H(w)` 保证四点在本次半球图中都强，
`G(q_i,w) ≥ G_req` 保证不是通过整体压低或展平波束图来“刷高比例”。实际优化还应把目标点附近
允许形成的主瓣区域从非目标峰值惩罚中剔除。

## 6. 四点高值的物理可行性

### 6.1 优化后增益与坐标的关系

用 600 组留出四点计算坐标特征与 O3 结果的 Spearman 相关性：

|坐标特征|与绝对最小增益的相关性|与归一化可行度的相关性|
|---|---:|---:|
|四点中的最小两点角距|−0.28|**−0.67**|
|六对点的平均角距|−0.49|−0.44|
|四点中的最大两点角距|−0.48|−0.41|
|四点平均离轴角 `acos(q_x)`|−0.49|+0.15|
|四点平均 `q_x`|+0.49|−0.12|

因此需要区分两种坐标效应：

- `q_x` 越小、越靠近正半球边缘，绝对增益总体越低；平均离轴角从 0–30° 增至 70–90° 时，
  绝对最小增益中位数从 10.83 dB 降到 3.88 dB。这主要反映单元方向图、有效孔径和极化投影
  造成的单点上限下降。
- 四点彼此的角距越大，归一化可行度越低；最小两点角距的相关性达到 −0.67。归一化已经除去
  各点自身单点上限，因此这一关系主要反映四个远场相位/极化子空间不能由同一个权向量同时匹配。

绝对最小增益不是点间角距的简单单调函数：某些宽分离点可能恰好落在当前阵列的高增益瓣上，
其绝对值仍较高，但相对各自单点峰值的损失很大。因此判断四点算法时必须同时报告绝对 dB 与
归一化比例，不能只按坐标距离或绝对增益下结论。

### 6.2 数值可行解与谱上界

定义每个目标的数值单点上限为 `s_i`，并考虑归一化公平性

\[
r^*=\max_{|w_n|=1/4}\min_{i=1,\ldots,4}\frac{w^H Q_i w}{s_i}.
\]

O3 可行解的 `r` 分布为 P5/中位数/P95 = 0.054/0.165/0.571；达到 0.5、0.7、0.9 的比例
分别为 7.33%、1.67%、0%。0.7 相当于每点不低于各自单点参考约 −1.55 dB，0.9 相当于
约 −0.46 dB。

为了避免把局部优化失败误判成物理极限，对任意 `α_i≥0, Σα_i=1` 使用

\[
r^*\leq
\lambda_{\max}\!\left(\sum_i\alpha_i\frac{Q_i}{s_i}\right).
\]

这个上界对任意单位范数复权值都成立，因此也覆盖更严格的恒模相位权值；数值单点上限若被
低估，只会使上界更保守。选择一个数值优化后的可行 `α` 即可得到有效上界，不依赖该 α 是否
全局最优。

|统计|谱上界|
|---|---:|
|P5 / 中位数 / P95|0.306 / 0.375 / 0.688|
|被证明不可能达到 0.5|81.5%|
|被证明不可能达到 0.7|95.0%|
|被证明不可能达到 0.9|99.0%|

按分层看，聚集组仍有 80% 被证明不能达到 0.7；掠射、中等分离和宽分离组三者均为 100%。
远场中同一个端口权向量必须同时满足四个方向的相位/极化二次型。方向越分散，各方向主导
子空间越不一致；单个恒模 rank-1 波束无法独立匹配四套相位。前半球限制消除了无意义的背向
样本，但不会消除这种共享自由度冲突。

所以，“四点不能同时接近各自峰值”已有与 CNN 无关的物理上界证据；而 O3 实际值与谱上界
之间的间隙同时包含恒模限制、上界松弛和非凸优化误差，不能全部归因于任何一项。

## 7. 下一步建议

### 7.1 可靠、优先做

1. **把前半球变成生产数据合同。** 所有训练、验证、请求入口统一断言 `q_x>0`；反半球只可
   进入单独的压力测试，不可混入主指标。
2. **四点目标改为归一化公平。** 默认优化 `min_i G_i/s_i`，同时报告绝对最小增益；否则一个
   本来单点上限很低的方向会支配目标，无法区分“阵元覆盖弱”与“四点冲突”。
3. **先做可行性筛查。** 对请求四点计算上述谱上界；上界低于业务门槛时直接返回不可行或建议
   重选点，而不是增加 CNN/迭代预算。
4. **低预算求解继续以 O0 为基线。** 加入 Q 初始化只作为额外 starts，不替换四个逐目标匹配
   starts；用验证集自适应增加预算。移除当前无效的 O2，改试 Riemannian/MM 相位更新或 SDR
   随机化后再作同预算比较。
5. **CNN 用交叉拟合的优化器难例回放。** 由一个折上的模型产生最容易被其误判的相位权值，
   在另一个折的真实 HFSS Q 上监督；避免当前 FM 在同一批次自挖难例造成开发集排序不稳定。
6. **用三 seed 集成做下置信界优化。** 优化 `均值增益−β×模型间标准差`，并把瓶颈身份一致性
   纳入选择；这比继续压平均 NMSE 更直接对应四点尾部。
7. **把 O4 改为可调风险。** 用名义最小增益与邻域 CVaR/下降惩罚的连续权重扫 Pareto 前沿，
   等真实指向误差或轨道插值误差确定后再冻结工作点。

### 7.2 较创新或颠覆，但保持阵列结构不变

1. **高秩时域协方差波束。** 先用 SDP 优化 `R≽0, diag(R)=1/16` 的四点公平上界，再把 R
   分解/量化为多个恒模相位状态高速轮换。它改变的是波束时序而非阵列结构，有机会突破单个
   rank-1 权向量的兼容性；当前 X1 只用了五个手工候选状态，不能代表这一路线。
2. **方向域带限残差模型。** 保留解析阵列相位，把互耦/单元方向图残差用前半球球谐或平面波
   谱表示，并让 CNN 只预测低维系数。远场本身是方向域平滑/带限对象，可减少插值伪差和优化器
   对局部 CNN 纹理的利用。
3. **可认证的 Q 代理。** 预测 `Q_hat` 与方向相关误差半径 `ε(q)`，优化
   `wᴴQ_hat w−ε(q)||w||²`；再用谱上界给每个四点请求同时输出“可行、不可行、模型不确定”三态，
   而不是只返回一个可能被过估的波束。
4. **多频/多时隙联合照射。** 若链路允许接收端积分不同子载波或时隙，可为不同方向分配不同
   波束并优化平均 SNR。这会把单一瞬时四点问题变成资源分配问题，但必须明确时延、峰均比、
   EIRP 与接收积分合同。
