# V2.10 严格正半球单极化幅度训练与验证报告

日期：2026-09-08  
实验编号：`strict-ephi-positive-hemisphere-20260908`

## 1. 结论

本次重新训练严格满足“训练仅使用实际可测单极化幅度”的约束。训练程序可见的数据只有：

- 已知发射指令 `command_iq`；
- 观测方向 `direction/theta/phi`；
- 单极化标量幅度 `amplitude = |E_phi(q,w)|`；
- 指令族标签和测量元数据。

训练目录不含复数 HFSS 场、场相位、16 端口算子 H、二次型 Q 或 S 参数。HFSS 复场只在训练开始前的一次性转换程序中用于生成模拟的单极化测量表，转换后不再被训练程序读取。因此，本实验验证的是：若暗室能够提供相同语义的校准后 `|E_phi|` 或 `|S21|` 幅度表，当前幅度模型可以原样训练。

在完全未见的角块和指令上，内部测试幅度 NMSE 为 -17.90 dB，幅度 dB MAE 为 1.58 dB，方向图相关系数为 0.974。进一步在从未参与训练数据生成的 HFSS reserved holdout 上，幅度 NMSE 为 -19.05 dB，幅度 dB MAE 为 1.69 dB，相关系数为 0.984。

按每条指令在整个正半球中的真实峰值分层，峰值以下 10 dB 范围内的 MAE 为 0.536 dB、95% 误差为 1.574 dB；误差主要集中在峰值以下 20 dB 的弱场。这与“优化点若全部落在本次正半球强场区，则预测误差明显更小”的判断一致。

## 2. 数据契约

正半球被严格定义为阵列 +X 法向一侧：

\[
q_x>0.
\]

本实验选择局部球坐标 `Ephi` 极化，标签为：

\[
y(q,w)=\left|e_\phi(q)^T H_{\rm HFSS}(q)w\right|/r_{\rm ref},
\qquad r_{\rm ref}=1\ \mathrm{m}.
\]

保存到训练目录后只剩实数非负的 y，不保存括号内的复数值。训练目录文件严格为：

| 文件 | 含义 |
|---|---|
| `direction.npy` | 单位方向 q，形状 `[query,3]` |
| `theta_deg.npy`, `phi_deg.npy` | 转台或仿真的方向角 |
| `command_iq.npy` | 已知 4x4 发射指令，形状 `[command,2,4,4]` |
| `amplitude.npy` | 单极化幅度，形状 `[command,query]` |
| `command_family.npy` | 单阵元、DFT、随机相位指令分类 |
| `manifest.json` | 频率、距离、极化、端口参考面和终端条件 |

没有 `operator_iq.npy` 或 `s_parameters_iq.npy`。清单中 `phase_available=false`。

这与实际测量表的结构一致，但物理语义仍需一致：实际幅度必须来自同一接收极化、同一参考距离或经过距离换算、同一发射功率基准和同一校准参考面。若实物接收天线保持实验室固定极化而不是随扫描角旋转到局部 Ephi，应将接收投影定义替换为该实际极化，不能直接沿用本次 Ephi 标签。

## 3. 数据规模与无泄漏划分

- 训练数据源：原 campaign 的 `dev/train.npz` 与 `dev/validation.npz`；只提取 qx>0。
- 正半球方向总数：23,300。
- 指令总数：224，包括 16 条单阵元、16 条二维 DFT、192 条随机等幅相位指令。
- 幅度观测总数：5,219,200。
- 训练/验证/测试方向：16,300 / 3,500 / 3,500。
- 训练/验证/测试指令：158 / 33 / 33。
- 方向按 10°×10° 整块划分，而非逐点随机划分。
- 三个集合共享角块数均为 0，重复物理方向数为 0。
- 外部验证源：`reserved/holdout.npz` 中 qx>0 的 5,500 个方向。
- 外部源与建表源的原始方向 ID 交集为 0。

内部测试同时要求“方向未见”和“指令未见”，共有 3,500×33=115,500 个观测。外部测试使用 5,500×33=181,500 个观测。

## 4. 模型与训练设置

模型为 `v210_nominal_coupling_residual_1`，共 34,973 个参数。模型内部仍允许使用复数潜变量来表示16端口之间的相对相位，但这些潜变量完全通过幅度损失反向求得；它们不是测得的复场标签。

模型由四部分组成：

1. 不训练的理想阵列传播相位 `exp(+j k q·r_n)`；
2. 方向相关的名义单元方向图；
3. 方向无关、受结构约束的端口耦合；
4. 小容量方向相关残差。

命令 w 只在末端通过精确线性叠加进入，不进入 CNN。因此模型被迫学习一个与具体训练命令无关的等效单极化算子，再用该算子预测未见命令的幅度。

训练采用 joint 方案、120轮、每轮抽取8,192个训练方向、学习率 1e-3、随机种子28101。最佳验证状态出现在第118轮，保存的是该最佳状态。

损失只由预测幅度与目标幅度计算，包括线性幅度 NMSE、功率 NMSE 和幅度 dB Huber 项，外加不依赖HFSS复场的模型结构正则项。没有复场损失，也没有 Q 矩阵难例挖掘。

## 5. 结果

### 5.1 内部未见角块 × 未见指令测试

| 指标 | 结果 |
|---|---:|
| 幅度 NMSE | -17.903 dB |
| 全局幅度 NMSE | -17.977 dB |
| 功率 NMSE | -15.403 dB |
| 幅度 dB MAE | 1.579 dB |
| 平均指令方向图相关系数 | 0.9743 |

按未见指令族：随机相位29条的幅度 NMSE 为 -17.91 dB、MAE 1.53 dB；单阵元2条为 -18.73 dB、MAE 1.27 dB；DFT 2条为 -17.16 dB、MAE 2.57 dB。DFT 数量只有2条，单独数字不宜过度解释。

### 5.2 完全独立 HFSS reserved holdout

| 模型 | 幅度 NMSE | 功率 NMSE | 幅度 dB MAE | 相关系数 |
|---|---:|---:|---:|---:|
| 理想相位，未标定 | -0.871 dB | -0.047 dB | 15.384 dB | 0.152 |
| 理想相位，仅用训练幅度拟合一个全局尺度 | -3.393 dB | -0.867 dB | 7.055 dB | 0.152 |
| 严格幅度训练模型 | **-19.055 dB** | **-17.411 dB** | **1.687 dB** | **0.984** |

理想基线的全局尺度 5.2103 仅由训练指令×训练角块的幅度数据拟合，未读取外部 holdout 标签。尺度校准不能改善相关系数，而训练模型把相关系数从0.152提高到0.984，说明模型并非只学到一个整体幅度比例，而是从幅度干涉数据中学到了显著的方向—端口非理想关系。

这仍不能唯一证明模型分离并辨识出了“互耦”这一单独因果量。单极化幅度监督辨识的是能够解释该极化幅度的等效算子；互耦、嵌入式单元方向图和端口误差可能在参数中互相补偿。

### 5.3 按正半球真实相对场强分层

每条未见指令分别在外部正半球求自身峰值，然后按真实幅度相对该峰值分层：

| 真实相对幅度区间 | 占比 | dB MAE | 95%绝对dB误差 |
|---|---:|---:|---:|
| 峰值至 -3 dB | 2.60% | 0.407 dB | 1.092 dB |
| -3 至 -6 dB | 6.04% | 0.435 dB | 1.250 dB |
| -6 至 -10 dB | 14.30% | 0.603 dB | 1.758 dB |
| 合并：峰值至 -10 dB | 22.93% | **0.536 dB** | **1.574 dB** |
| -10 至 -20 dB | 45.60% | 1.224 dB | 3.825 dB |
| 低于 -20 dB | 31.47% | 3.197 dB | 10.363 dB |

这里的“强场”定义不再使用各方向各自的单点最优 w，而是使用同一条给定指令在整个正半球形成的方向图峰值，符合此前对强场定义的修正。

## 6. 能从本实验得出的结论

1. 严格幅度训练可行。无需向训练程序提供HFSS复场、相位或S参数，也能在未见相位编码指令上获得较高相关性。
2. 相位信息不是以标签形式提供的，而是由许多已知相位编码指令产生的幅度干涉约束间接恢复。对每个方向，16端口复数标量算子扣除不可观测的公共相位后约有31个实自由度；158条训练指令提供了过定约束，并由角向CNN平滑共享信息。
3. 强场预测已明显优于全场平均：正半球峰值以下10 dB内 MAE 约0.54 dB。因此，若后续优化能够用HFSS或实测复核确认四点都位于同一最终指令方向图的前10 dB区域，CNN误差通常不再是首要矛盾。
4. 当前模型只能解释所选 Ephi 接收通道。它不是双极化总场强模型，也不能直接等同于 `|Etheta|^2+|Ephi|^2` 的总增益。
5. 当前结果是无噪声HFSS幅度可行性上限，不等于真实暗室性能。实测中的噪声底、接收链漂移、幅相指令误差、转台角误差和温漂仍需进入训练/校准协议。

## 7. 实物复现要求

实际采集时应对每个方向和每条已知4x4指令保存一个非负标量幅度。可使用校准后的 `|S21|`，也可换算为 V/m；但训练与部署必须保持相同单位。至少应记录：

- 频率与参考距离；
- 接收极化和接收天线姿态定义；
- 发射功率/端口波定义；
- 未激励端口终端条件；
- 校准参考面；
- 阵列编号、测量批次、温度与时间；
- 仪器噪声底。

为了恢复端口间相对相位关系，不能只测16条单阵元指令；必须加入足够多的已知多端口相位编码指令。本实验使用单阵元+DFT+随机相位三类，共158条训练指令。若实测成本过高，下一步应专门研究最小相位检索码本，而不是直接减少随机指令后假定信息仍充分。
