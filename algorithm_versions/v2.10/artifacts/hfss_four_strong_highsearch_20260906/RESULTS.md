# V2.10 纯 HFSS 四点“四强点”基线

讨论入口见 [README.md](README.md)；完整算法定义见 [METHODS.md](METHODS.md)，原因判别见
[CAUSE_ANALYSIS.md](CAUSE_ANALYSIS.md)，复现和逐样本字段见 [REPRODUCTION.md](REPRODUCTION.md)。

## 1. 结论

在完全不读取 CNN checkpoint、不使用 CNN 预测的条件下，使用真实 HFSS 嵌入式方向图、固定
4×4 阵列、47 GHz、正半球 `q_x>0` 和 phase-only `|w_n|=1/4` 重新优化四点。

结果把“四点难以同时达高值”拆成了两个不同问题：

1. **旧目标函数确实漏解。** 旧 O3 只最大化四个目标点的最小增益；加入正半球峰值主动集后，
   在目标最小增益损失不超过 1 dB 时，`rho>=0.5` 的空间四强点由 17/600 提升到 40/600，
   新增 23 组且没有丢失旧成功组。配对成功率提升 3.83 个百分点，bootstrap 95% 区间为
   `[2.33, 5.50]` 个百分点。
2. **严格的“四强且高值”主要受固定阵列多方向相容性限制。** 600 组中有 489 组（81.5%）
   的有效谱上界低于 0.5；这些组合即使允许任意单位范数复幅权值，也不可能让四点同时达到
   各自单点上限的 −3.01 dB 以内。phase-only 只是这个更大可行集的子集。

因此，不能再把主要失败归因于 CNN。当前证据支持：空间峰值控制存在可优化余量，但对任意四个
正半球点同时实现严格高值，固定阵列本身通常不可行。

## 2. 指标和受控变量

对同一次权值 `w`：

- 正半球空间强度：`rho = min_i G(q_i,w) / max_{q_x>0} G(q,w)`；
- 单点上限利用率：`u = min_i G(q_i,w) / G_i^solo`；
- 严格四强点：`rho>=0.5` 且 `u>=0.5`，即同时满足空间峰值和各自单点上限的 −3.01 dB；
- 由于真实链路绝对增益门槛仍缺失，`u` 只是当前研究中的高值代理，不能替代 `G_req`/SNR。

所有比例在功率域计算。全场分母扫描合并后的 32,400 个 1° 正半球 HFSS 方向，反半球使用数为
0；因此这是离散正半球结论，不是连续角域证书。

唯一改变的是目标函数：

|方法|目标|
|---|---|
|H0|既有真实 HFSS O3，高预算四目标 max-min 控制组|
|H1|最大化目标最小增益与正半球峰值的 dB 差，不保持绝对目标增益|
|H2|同 H1，但目标最小增益不得比 H0 低 0.5 dB 以上|
|H3|同 H1，但目标最小增益不得比 H0 低 1.0 dB 以上|

H1–H3 均使用 12 个恒模起点、6 轮正半球峰值挖掘、每轮 300 步和每个候选 48 个活跃峰值。
每一轮后都回到完整 32,400 方向扫描，不以小方向子集作为最终结果。

验证集已经显示：H3更擅长提高空间比例，H2更能兼顾高值，H1会以明显目标损失换取比例。随后

|方法|最小增益 P5/中位数|`rho` 中位数|`rho>=0.1`|`rho>=0.2`|`rho>=0.5`|`u>=0.5`|严格四强点|目标损失中位/P95|

H1 说明只追求空间比例会明显牺牲真实目标增益：最小增益 P5 下降约 2.9 dB，严格四强点反而
更少。H2 是当前“严格四强且高值”较好的折中，但也只有 5/600；H3 更适合提高空间相对强度，
但 40 个空间 −3 dB 成功组中只有 4 个同时满足单点利用率 −3 dB。

相对H0，H2/H3的空间−3 dB成功率配对提升分别为2.50和3.83个百分点，bootstrap 95%区间分别为

0.50和0.33个百分点，对应区间为`[0,1.17]`和`[−0.50,1.17]`，尚不能证明严格成功率获得稳定净提升。

若把空间和单点门槛同时放宽，联合成功率为：

|共同门槛|H0|H2|H3|
|---|---:|---:|---:|
|0.1 / −10.00 dB|53.50%|56.50%|57.00%|
|0.2 / −6.99 dB|14.67%|19.33%|19.67%|
|0.5 / −3.01 dB|0.33%|0.83%|0.67%|

所以“四点可能达到四强点”必须附带门槛：−10 dB 条件约半数可达，−7 dB 约五分之一，严格
−3 dB 对随机四点几乎不可达。

## 4. 四点位置差异

H3 的分层结果：

|四点类型|`rho` 中位数|最小增益中位数|`rho>=0.5`|`u>=0.5`|严格四强点|
|---|---:|---:|---:|---:|---:|
|聚集 clustered|0.27|7.09 dB|23.33%|16.67%|2.67%|
|掠射 grazing|0.13|2.50 dB|0%|0%|0%|
|中等 moderate|0.17|3.86 dB|3.33%|0%|0%|
|宽分离 wide|0.16|3.60 dB|0%|0%|0%|

谱上界对 `u>=0.5` 的物理不可行证明比例分别为：聚集 32.0%、掠射 96.67%、中等 98.67%、
宽分离 98.67%。H2 找到的 5 个严格成功组全部属于聚集组；这些成功组的平均点间角距中位数
约 4.47°，最大点间角距中位数约 6.06°。它们本质上更接近同一个主瓣覆盖四个近邻点，而不是
四个彼此独立的高增益波束。

H3 的 `rho` 与平均点间角距、最大点间角距、平均离轴角的 Spearman 相关性分别为
−0.39、−0.36、−0.37；与最远目标到半球峰值角距的相关性最强，为 −0.56。

物理解释为：

- 聚集四点的 HFSS 响应向量相近，可以共享同一个主瓣；
- 宽分离四点需要相互冲突的相位匹配和功率分配；
- 掠射点除多波束冲突外，还叠加单元方向图、扫描损耗和极化投影造成的绝对上限下降；
- 非目标强峰仍普遍存在。H0/H3 的最近目标到半球峰值角距中位数约 48.4°/48.2°，说明新目标
  主要是在压低这些峰值，尚未普遍把全局峰移动到目标附近。

## 5. 原因分解

### 5.1 已确认的旧目标函数问题

H3 在不超过 1 dB 目标损失下新增 23 个空间 `rho>=0.5` 成功组，证明 target-only max-min 并非
正确的四强点目标。需要显式加入正半球峰值或目标掩模约束。

### 5.2 已证明的物理高值限制

489/600 的谱上界低于 `u=0.5`。该证明放宽了恒模约束，允许任意复幅权值，因此这些组不是
CNN误差、phase-only投影或局部优化不充分造成的；固定阵列在四个位置上的响应子空间本身不相容。

### 5.3 仍未完全分开的 111 组

剩余 111 组没有被 `u<0.5` 上界证明为不可能。其中：

- 4 组由 1 dB 保持方案实现严格四强点，归入旧目标漏解；
- 11 组只能由纯比例方案实现空间四强点且目标损失超过 1 dB，表现为高值与空间均衡的物理折中；
- 96 组仍未实现，需要 SDP/任意幅相松弛和更全局的 phase-only 搜索，才能继续区分松弛差距、
  恒模限制与非凸局部解。

## 6. 下一步决策

1. 将 H2 作为“严格四强且尽量保值”的 HFSS 基线，将 H3 作为“空间强点优先”的 Pareto 点，
   不用 H1 作为业务方案。
2. 对上述 96 个未决组做 SDP 可行性检查：加入 `G_i>=eta G(q)` 的正半球切平面约束，并分别
   测试 `eta=0.2/0.5` 与目标绝对下限。SDP 不可行才可进一步宣称物理不可行；高秩可行则测试
   多状态分时，秩一或可投影则继续改进 phase-only 求解器。
3. 真实轨道和链路门槛到位后，用 `G_i>=G_req` 替代当前 `u` 代理。没有这个门槛时，“高值”
   只能解释为相对各自单点能力，而不能解释为链路成功。
4. 连续正半球验证应在 1° 峰值周围自适应加密；本轮结果不得表述成连续方向的严格证书。
