# 纯 HFSS 四点优化讨论包

这套材料用于讨论：在固定 4×4 相控阵、47 GHz、正向半球和单一 phase-only 权值状态下，为什么
四个任意方向难以同时成为高增益强点。

## 讨论前必须统一的三个概念

1. **空间四强点**：四个目标相对同一次正半球方向图的最高峰都足够强，用 `rho` 衡量。
2. **相对单点高值**：共享权值下四点相对各自单点最优保留了多少，用 `u` 衡量。
3. **绝对业务可用**：四点是否超过真实链路所需 `G_req`、EIRP 或 SNR；当前任务合同没有该门槛，
   因此本包不能回答这一项。

只满足第一项可能是通过压低整个正半球场获得；只满足第二项也不保证四点是本次方向图的主要峰。
本包把 `rho>=0.5` 且 `u>=0.5` 暂定为严格“四强且高值”，但这是研究门槛，不是业务标准。

## 一页结论

- CNN 已被完全排除：协议中的 `cnn_files_loaded=[]`，所有增益来自 HFSS 复远场因子。
- H3 在目标最小增益损失不超过 1 dB 时新增 23/600 个空间 −3 dB 成功组，证明旧 target-only
  max-min 目标确实不完整。
- 489/600 组被谱上界证明不可能满足 `u>=0.5`，且该证明允许任意复幅权值，因此严格高值失败
  不能归因于 CNN、phase-only 投影或当前局部求解器。
- H2 只找到 5/600 个严格四强组，全部为聚集点；平均点间角距中位数约 4.47°。
- 掠射、中等分离和宽分离组分别有 96.67%、98.67%、98.67% 被证明无法达到 `u>=0.5`。
- 尚有 96/600 组无法仅靠现有证据区分恒模限制、非凸局部解和松弛差距，应进入 SDP 切平面实验。

## 证据等级

|措辞|含义|
|---|---|
|“实测/得到”|在冻结的1°正半球HFSS数据和数值算法上得到|
|“找到可行解”|存在一个经过全32,400方向复核的phase-only权值；不等于全局最优|
|“谱上界证明不可能”|必要上界低于门槛，对任意单位范数复幅权值均不可能|
|“未决”|上界没有排除，但现有phase-only搜索也没有找到；不能宣称物理不可行|

## 明确不应得出的结论

- 不能把1°网格结果称为连续正半球严格证书。
- 不能把单一HFSS电磁状态推广到制造、温度、频率、平台和天线罩变化。
- 不能把随机分层四点等同于真实轨道四站分布。
- 不能因为SDP或谱上界可行就断言phase-only秩一权值可实现。
- 不能因为空间 `rho` 提升就断言绝对链路增益提升。
