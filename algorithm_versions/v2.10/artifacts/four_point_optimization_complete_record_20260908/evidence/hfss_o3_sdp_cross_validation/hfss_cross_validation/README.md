# O3 四目标相位优化的 HFSS 交叉验证

## 结论

本目录使用 Ansys HFSS 2025 R2 / PyAEDT 0.9.6，对一组具有代表性的 `moderate` 四目标案例（holdout case 189）进行独立复核。验证过程中 CNN 不加载、不参与；16 个端口功率均为 0.0625 W，总输入功率固定为 1 W，仅改变端口相位。

主要结论如下：

1. HFSS API 能正确设置 16 路恒功率相位激励、读取复数远场并输出 `RealizedGainTotal`。
2. O3 离线远场模型给出的四点增益为 `[4.4969, 4.7748, 4.6781, 4.7321] dB`，`Gmin=4.4969 dB`。
3. 将同一组 O3 相位直接写入原 HFSS 已求解工程后，四点实现增益为 `[4.4556, 4.4515, 4.3965, 4.4759] dB`，`Gmin=4.3965 dB`。两种计算的 `Gmin` 相差 `-0.1004 dB`，四点中最大逐点绝对差为 `0.3233 dB`。
4. HFSS 电场分量按 `G=(|E_theta|^2+|E_phi|^2)/60` 复算，与 HFSS `RealizedGainTotal` 的最大差仅 `1.15e-5 dB`，证明 HFSS API 的读取、单位换算及增益口径一致。
5. 以 HFSS 为独立黑盒评价器，在 O3 解附近评估 24 个固定随机种子的相位候选后，最佳 `Gmin=4.4265 dB`，仅比 HFSS 中的 O3 起点提高 `0.0300 dB`。该结果说明 O3 相位在 HFSS 口径下仍可小幅微调，但本次邻域检查没有发现显著改善。

因此，这组交叉验证支持：当前 O3 结果不是由 CNN 造成，也不是明显的优化失败；离线完备远场与 HFSS 原生后处理之间存在零点几 dB 的小偏差，而在 HFSS 口径下对 O3 相位作有限邻域搜索只获得 0.03 dB 改善。

## 验证对象与指标

优化约束为

\[
\max_{|w_n|=1/4}\min_{i=1,\ldots,4}G_i(w),
\qquad \|w\|_2^2=1.
\]

本目录使用绝对实现增益 `RealizedGainTotal`，不是归一化方向图、相对增益或四点平均值。`Gmin` 是四个目标方向中最小的增益，直接对应四点公平性目标。

目标方向的 HFSS 角度为：

|目标|Theta/deg|Phi/deg|
|---:|---:|---:|
|1|36.5000|23.5000|
|2|115.5000|-0.5000|
|3|91.5000|42.5000|
|4|93.5000|87.5000|

## 数值对照

|结果来源|点1/dB|点2/dB|点3/dB|点4/dB|`Gmin`/dB|
|---|---:|---:|---:|---:|---:|
|离线 O3 完备远场|4.4969|4.7748|4.6781|4.7321|4.4969|
|HFSS 直接写入 O3 相位|4.4556|4.4515|4.3965|4.4759|4.3965|
|HFSS 邻域检查最佳候选|4.4265|4.5977|4.4455|4.4474|4.4265|

HFSS 最佳候选相对 HFSS O3 起点的提升为 0.0300 dB；相对离线 O3 报告值仍低 0.0704 dB。该差异量级远小于把典型四点最低增益从约 4.5 dB 提高到 8–10 dB 所需的 3.5–5.5 dB。

## HFSS 原生 Optimetrics 的验证边界

已验证 `edit_sources`、远场报告和数值查询 API 可用。也尝试把 16 个源相位映射为设计变量，并建立四个等权 `dB(RealizedGainTotal)` 目标的 Optimetrics Quasi Newton 设置。然而，本工程的阵元端口相位属于已求解场的后处理激励组合，不是驱动全波求解的普通设计变量；工程复制、另存为和含结果 `.aedtz` 恢复后均不能形成可查询的变量激励—远场数据链路，Optimetrics 因而没有产生有效优化结果。

这项失败不能作为性能数据，也不能说明 HFSS Optimetrics 算法本身优劣。它只说明：在当前工程和 API 路径中，不能把原生 Optimetrics 当作对 H0 精确 `max-min` 问题的独立实现。最终交叉验证采用的是“HFSS 原生场解 + 数值源相位 + HFSS `RealizedGainTotal` 查询”，目标值由 HFSS 直接给出。

此外，四个等权门限目标只是 `max-min` 的代理形式，并不等于显式的 `min` 运算。即使该 Optimetrics 设置能够运行，也只能作为辅助比较，不能替代 H0 数学合同。

## 复核范围与不能推出的结论

- 直接 HFSS 验证是确定性的，完整复核了指定 O3 相位在四个目标方向的增益。
- 邻域检查采用固定种子 `20260906`，共 25 次 HFSS 评估（1 个 O3 起点 + 24 个候选），扰动标准差依次为 20、10、5、2、1、0.5 度，每档 4 次。
- 邻域检查是局部反证测试，用于寻找明显遗漏的改进，不是全局最优证明，也不替代 600 组 O3/SDP 统计。
- 本案例只能证明代表性 `moderate` 案例的 HFSS 一致性；四目标总体能力边界仍应以主目录中的 600 组 holdout 与 SDP 上界统计为准。
