# 16阵元相控阵四目标同时增益优化：验证结果与能力边界

## 摘要

本实验评估一个固定4×4、16端口相控阵在47 GHz下，同时对四个指定远场方向进行增益优化时的可达性能。四个目标方向共用同一个恒模相位权值，阵列总输入功率归一化为1。优化目标是最大化四个目标方向中的最低增益：

\[
G_{\min}=\min_{i=1,\ldots,4}G_i(w),
\qquad
\max_{|w_n|=1/4}G_{\min}.
\]

结果表明：四目标最低增益对目标方向的空间分布高度敏感。目标集中时性能较高；目标分散或接近阵列掠射方向时性能明显下降。当前O3结果已接近恒模半正定规划（SDP）放松上界，因此在保持阵列、总功率和单权值相位控制不变的条件下，仅更换同类数值优化器难以获得数dB的普遍提升。

600组独立留出测试的主要结果为：

- 四点中最弱点的典型增益：**4.50 dB**；
- 四点最弱点达到5 dB：**39.67%**；
- 达到8 dB：**13.83%**；
- 达到10 dB：**9.00%**；
- O3距离恒模数学上界的典型差距：**0.26 dB**。

上述统计已与独立HFSS自动化复核整合。完整论证见 `INTEGRATED_EVIDENCE_REPORT.md`。证据由三个相互独立的层次组成：

1. 240组validation与600组holdout均采用同一O3算法和搜索预算，合计840组四目标案例；
2. 逐案例恒模SDP上界用于估计同一约束问题仍可能存在的数值空间；
3. 对holdout案例189直接调用HFSS 2025 R2，写入O3的16路恒幅相位并读取四点 `RealizedGainTotal`。

HFSS复核案例的离线 `Gmin=4.4969 dB`，正好位于600组holdout的第50百分位，在moderate组内约位于第46百分位，因此它是典型案例，不是从高增益案例中选择的有利样本。HFSS直接复核得到 `Gmin=4.3965 dB`，相对离线结果低0.1004 dB；随后进行的24候选HFSS邻域检查只将其提高到4.4265 dB，即提高0.0300 dB。该结果支持O3不存在明显的局部失效，但单案例HFSS检查不构成全部840组的全波重算，也不构成严格的全局最优证明。

## 实验问题与系统约束

本实验采用单权值、恒模、相位-only控制。权值写为：

\[
w_n=\frac{1}{4}e^{j\phi_n},\qquad n=1,\ldots,16.
\]

因此，每个阵元幅度固定为1/4，仅相位 `\phi_n` 可调，并满足：

\[
\|w\|_2^2=16\left(\frac14\right)^2=1.
\]

四个方向在同一时刻共用该16维权值，不具备四套相互独立的波束形成权值。目标集中时，单一方向图可以同时覆盖多个目标；目标方向相互分离时，同一个权值必须在多个方向之间进行折中。目标接近阵列切平面时，还会受到阵元方向图和阵列扫描能力下降的影响。

## 指标定义

|指标|定义与解释|
|---|---|
|`G_i(w)`|权值 `w` 下第 `i` 个目标方向的HFSS增益|
|`Gmin`|四个目标增益中的最小值，是本实验的主要优化指标|
|dB|功率比的对数表示，线性功率比为 `10^(dB/10)`|
|P5|有5%的测试案例低于该数值，用于描述较差案例|
|中位数|50%的案例低于、50%的案例高于该数值|
|P95|有95%的案例低于该数值，用于描述较好案例|
|恒模SDP上界|放宽单一物理权值的秩约束后得到的理论上界，不是保证可实现的增益|

例如，若某组四点增益为 `[6.0, 5.2, 4.5, 7.1] dB`，则该组 `Gmin=4.5 dB`。它不是四点平均值，也不是整个方向图的峰值。

## 分组对照的一致性

四类方向组合只是目标位置不同，**优化方法、功率、阵列、频率和搜索预算完全相同**：

|项目|所有分组统一设置|
|---|---|
|阵列|固定4×4，共16端口|
|频率|47 GHz|
|同时权值|四点共用一套|
|每阵元幅度|固定 `|w_n|=1/4`|
|总功率归一化|`||w||²=1`|
|可调参数|只调16个相位|
|目标|最大化四点中的最小绝对增益|
|算法|H0/O3：32起点、每起点320步Adam相位优化|
|CNN|不加载、不参与|

目标函数为：

\[
\max_{|w_n|=1/4}\min_{i=1,\ldots,4}G_i(w).
\]

因此，下表中 `clustered/grazing/moderate/wide` 的结果差异只反映目标方向空间关系的差异，不来自优化目标、算法或搜索预算的改变。

## 四类目标的结果

|四点类型|空间特征|案例数|`Gmin`中位数|达到5 dB|达到8 dB|达到10 dB|
|---|---|---:|---:|---:|---:|---:|
|clustered|四点靠得较近|150|8.05 dB|73.33%|50.00%|36.00%|
|moderate|中等分散|150|4.66 dB|44.00%|4.67%|0%|
|wide|分布较宽|150|4.48 dB|33.33%|0.67%|0%|
|grazing|包含接近阵列侧面的方向|150|3.27 dB|8.00%|0%|0%|

目标集中组的 `Gmin` 中位数为8.05 dB，而掠射组为3.27 dB。该结果说明，当前阵列并非对所有四目标组合都只能产生低增益；主要困难出现在方向分离度较大或包含大扫描角目标的组合中。

## 总体增益水平

600组holdout案例的 `Gmin` 分布为：

|统计位置|最差|P5|P25|中位数|P75|P95|最好|
|---|---:|---:|---:|---:|---:|---:|---:|
|`Gmin`/dB|-1.51|1.15|2.78|4.50|6.44|11.22|15.74|

4.50 dB对应约2.82倍的线性功率比。该数值表示典型案例中四个目标里最弱方向的阵列增益水平，不直接等同于链路是否可用。工程判定仍需结合发射功率、传播距离、路径损耗、极化、接收机噪声系数及灵敏度门限。

## 为什么说继续更换普通优化器作用有限

恒模SDP通过移除单权值矩阵的秩一约束，给出不低于任何可实现恒模相位权值的理论上界。600组测试中：

- O3与上界的差距中位数只有 **0.2613 dB**；
- 99.17%的案例差距不超过 **1 dB**；
- 56.67%的案例差距不超过 **0.3 dB**。

因此，同一相位-only优化问题中尚未利用的典型数值空间约为零点几dB，无法支持“仅通过替换普通优化器便可将典型4.50 dB普遍提高至8–10 dB”的预期。

注意：SDP只作为上界，不作为第五组优化方法；所有四类实测对照都只采用同一个H0/O3算法。

## 科学结论与适用边界

在本实验合同下，四目标性能主要由固定HFSS远场响应、四目标共用一个同时权值、恒模相位控制和固定总功率共同决定。CNN未参与H0/O3计算，因此本结果不能归因于CNN预测误差。

若工程目标要求相距较远的四个方向同时保持高增益，需要改变可行解集合，例如采用多RF链、数字波束形成、时分多权值、子阵划分或重新设计阵列。上述方案属于系统或阵列结构变化，不能由当前结果直接量化其改善幅度。
