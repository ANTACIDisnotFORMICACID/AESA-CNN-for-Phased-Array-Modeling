# V2.10 下一阶段优化分析与计划

> 2026-09-06 实施更新：P3 的 A10/B10/C10 受控训练已完成。Validation 冻结选择 A10；
> B10 未形成整体净收益，C10 的单侧尾部 CVaR 代理失败。完整证据见
> `artifacts/controlled_psd_20260906/RESULTS.md`。P0 的真实任务字段和 P2 的新物理状态数据
> 仍缺失，因此本轮不构成链路、外部泛化、FPGA 或 OTA 验收。

## 1. 总体判断

V2.9 已证明“物理传播主干 + 小型 CNN + 线性复权值收缩”能够学习固定 HFSS 状态下的
RealizedGainTotal，并支持四点 phase-only 优化。当前模型可作为研究基线，但距离实际卫星
应用仍有三个主要缺口：

1. 训练和验证仍来自同一个 HFSS 电磁状态，不能证明跨频率、制造、温度、器件误差和实测条件泛化；
2. 只监督总增益时，CNN 内部复场存在方向相关酉变换不唯一性，不能解释为真实
   \(E_\theta/E_\phi\)；
3. 最终任务尚未定义真实轨迹、路径损耗、接收极化、噪声和链路门槛，当前“峰值−10 dB”
   只能作为方向图研究指标。

因此，下一步不应优先扩大网络，而应依次解决任务定义、数据代表性、监督可辨识性和鲁棒四点优化。

## 2. 当前 CNN 结构评价

### 2.1 已验证的优点

- 参数量 28,854，低于 V2.9 原 34,973 参数预算；
- 方向 Fourier 特征与固定阵列几何共同进入共享 4×4 孔径 CNN；
- 固定 \(\exp(jkq\cdot r_n)\) 保留阵列传播相位；
- Cartesian 横向投影保证场与传播方向正交，并避免球坐标极点奇异；
- 权值 \(w\) 不进入任意非线性网络，远场严格通过 \(H(q)w\) 线性叠加；
- 完整 HFSS 嵌入式方向图只作离线监督，不要求随模型部署。

### 2.2 当前限制

总增益为

\[
G(q,w)=\frac{\lVert H(q)w\rVert_2^2}{60\lVert w\rVert_2^2}.
\]

若 \(U(q)\) 为任意方向相关酉矩阵，则 \(H(q)\) 与 \(U(q)H(q)\) 产生相同总增益。
因此，仅由总增益监督得到的内部复向量是等效因子，不能作为真实极化分量。

若最终只优化 RealizedGainTotal，这种不唯一性不妨碍总功率计算；如果接收站具有固定极化，
则必须加入 Jones 投影、复极化场或对应接收功率监督。

### 2.3 优先候选结构

下一次结构实验优先考虑直接预测

\[
Q(q)=\frac{H(q)^H H(q)}{60},\qquad
G(q,w)=\frac{w^H Q(q)w}{w^Hw}.
\]

建议用

\[
Q(q)=L(q)^H L(q)
\]

构造低秩 Hermitian PSD 输出，以保证预测增益非负并消除总功率任务中无意义的极化规范自由度。
该路线应在不大幅增加参数量的前提下，与当前等效场模型进行同预算对照。

如未来获得真实器件状态，可进一步采用

\[
Q_{\text{real}}(q,s)
=Q_{\text{HFSS}}(q)+\Delta Q_{\text{light}}(q,s)
\]

或低维增益、相位、耦合校准，而不是让 CNN 重新学习全部固定理想方向图。

## 3. 当前训练方式评价

### 3.1 已完成结果

V2.9 对 A–E 五种配方分别训练三个 seed，15 次运行均达到收敛规则。冻结候选 C / seed 29513
的保留角块误差表现为：

|参考强度|三 seed 平均 MAE|
|---|---:|
|强场，参考峰值−10 dB以内|0.214 dB|
|中场，−20至−10 dB|0.503 dB|
|弱场，−30至−20 dB|1.119 dB|
|深弱场，低于−30 dB|2.462 dB|
|全部区域|0.646 dB|

三 seed NMSE 样本标准差约 0.520 dB，超过 V2.9 暂定的 0.25 dB 稳定性门槛。

### 3.2 loss 实验结论

- A：基础幅度 NMSE、功率 NMSE 和 dB Huber；
- B：增加复算子监督；
- C：增加训练轨迹困难样本；
- D：增加瓶颈高估单侧惩罚；
- E：增加弱点排序项。

开发集选择了 C，但保留集上 C 的 phase-only regret P95 为 18.75%，基础 A 为 17.78%。
因此，当前结果不能证明困难样本 loss 稳健改善尾部。

现有顺序微调还缺少“相同父 checkpoint、相同新增训练步数、保持基础 loss”的控制组，
所以 C 相对 A 的变化不能完全归因于 loss。

### 3.3 下一轮训练原则

1. 每种方法固定相同初始化、batch、数据量和总更新步数；
2. 设置基础 loss 继续训练控制组；
3. 每次只改变一个因素；
4. 按轨迹整体划分，禁止相邻帧跨训练和测试；
5. 按电磁状态、制造批次、温度或日期划分外部测试，而不只按同一状态角度划分；
6. 最终保留集只打开一次，不依据保留结果重新选型；
7. 使用至少三个 seed；若种子方差仍大，再增加 seed，而不是只报告最佳运行。

### 3.4 候选训练目标

优先级从高到低为：

1. \(Q\) 或低秩 PSD 因子的直接监督；
2. 强场与瓶颈区域的功率误差；
3. 轨迹级 CVaR 或最差若干帧平均；
4. 瓶颈高估的方向相关单侧惩罚；
5. 深零陷区域采用受限权重，避免很小绝对场误差在 dB 域被无限放大。

不建议只靠提高深弱场 dB loss 权重。四点算法会主动寻找强场，更应控制“被优化器利用的局部高估”。

## 4. 当前四点优化评价

### 4.1 合成轨迹结果

V2.9 原保留轨迹包含聚集、前半球分散和全球压力三类。冻结模型 phase-only 结果为：

- 四点 gain MAE：0.219 dB；
- regret 中位/P95：3.07%/18.75%；
- 真实瓶颈高估 P95：1.020 dB；
- 前半球分散组 regret P95：约 9.81%；
- 全球压力组 regret P95：约 24.68%。

全球压力组包含实际卫星可能不可见的方向，只能用于数值压力测试。

### 4.2 新随机正半球实验

180 组四点均位于 +x 方向 60° 锥内，每组使用 phase-only \(|w_n|=1/4\)：

|方法|四点全部位于全空间峰值−10 dB内|最小增益P5/中位|四点均距局部峰不超过1 dB|
|---|---:|---:|---:|
|原 soft-min|92.2%|4.33/8.22 dBi|13.9%|
|特征向量多波束初值|92.8%|4.33/8.26 dBi|15.6%|
|2°邻域平顶|89.4%|3.53/7.62 dBi|27.8%|
|近似全局峰比例惩罚|91.7%|4.32/8.26 dBi|14.4%|
|允许坐标移动5°|97.8%|5.86/9.22 dBi|60.6%|

高预算 HFSS 数值 max-min 参考成功率为 93.3%。原 soft-min 相对该参考的最小增益 regret
中位/P95 为 3.08%/9.18%，说明固定合理坐标下，现有优化器已接近当前数值参考。

特征向量初值只多成功一组；平顶方法提高局部峰接近率，但使最小增益中位下降约 0.51 dB；
允许移动坐标只适用于站点选址或服务区规划，不能用于固定地面站。

### 4.3 四点目标应改为链路余量

相对波峰−10 dB可能通过降低全局峰而改善，不足以代表实际通信质量。最终应优化

\[
M_k(w)=P_{\text{tx}}+G_{\text{tx},k}(w)
-L_{\text{path},k}+G_{\text{rx},k}
-N_k-\mathrm{SNR}_{\text{required},k}.
\]

主问题为

\[
\max_{w\in\mathcal W}\min_k
\left[\widehat M_k(w)-\Delta_k(q_k,w)\right].
\]

其中 \(\Delta_k\) 必须随方向、权值和场强变化。统一减去常数只改变报告数值，不改变最优权值。

### 4.4 不重新训练时可继续探索的优化

近期保留原 soft-min 为固定基线，只探索以下受控变化：

1. 将四个 \(Q_k\) 主特征向量组合成额外初值，但保留原随机初值；
2. 先求每个方向的单点最大增益，再进行四点联合可行性检查；
3. 简单情况用固定预算，低可行性或低置信度情况启用更多起点和迭代；
4. 使用相位流形优化或 SDR 作为离线参考和初值，不把松弛上界误称为可实现结果；
5. 把邻域平顶改成约束而非等权目标：

\[
\max_w\min_kG(q_k,w),\qquad
G(q_k+\delta,w)\ge G(q_k,w)-\Delta_{\text{flat}};
\]

6. 连续轨迹使用上一帧权值作为额外起点，并对相位跳变、切换时间和量化码变化施加约束；
7. 若联合链路门槛不可行，明确返回不可行，并切换到时分波束、子阵划分或服务调度。

## 5. 建议实施顺序

### P0：冻结任务定义

需要确定或建立暂定范围：

- 卫星轨道、姿态与阵列法向；
- 四站坐标和同时可见条件；
- 允许的扫描角；
- 发射功率、路径损耗、接收天线增益和极化；
- 噪声、目标 SNR 和链路余量；
- phase-only 或幅相控制、相位位数、更新速率和切换限制。

输出：`MISSION_CONTRACT.md` 和机器可读配置。任务定义变化必须形成新版本。

### P1：冻结 CNN 的真实任务优化基线

在不训练 CNN 的情况下：

- 从轨道和地面站生成连续四点轨迹；
- 计算逐站链路余量，而不是仅计算相对增益；
- 运行原 soft-min、可行性检查、方向相关安全裕量和量化后再优化；
- 按轨迹统计四站同时成功率、最小余量P5和连续中断长度。

暂定起效标准：

- 相对原 soft-min 的配对成功率差异95%区间下界大于0；
- 最小链路余量P5不下降超过0.2 dB；
- 瓶颈高估P95不超过0.5 dB；
- 权值满足功率、恒模、相位量化和更新速率约束。

### P2：多状态数据

单一线性无源HFSS状态中，不同端口相位命令可由16个嵌入式方向图线性重组；继续导出大量同状态
相位组合不会增加新的电磁信息。下一批高价值数据应改变物理状态，例如：

- 多个相邻频点；
- 馈线、移相器或功放幅相误差；
- 制造公差与阵元偏移；
- 温度状态；
- 天线罩、安装平台或卫星结构影响；
- 少量实际复场、总增益或链路功率测量。

仍可保留少量直接HFSS多端口命令，用于验证线性重组的端口顺序、功率归一化和相位约定，
但不应将其误认为独立训练状态。

### P3：V2.10 CNN 对照实验

建议至少比较：

|实验|模型|主要目的|
|---|---|---|
|A10|V2.9结构继续训练|同预算控制|
|B10|低秩PSD \(Q\) 模型|可辨识总功率预测|
|C10|B10 + 轨迹CVaR|降低尾部四点损失|
|D10|B10 + 方向相关不确定性|降低瓶颈乐观高估|
|E10|HFSS基线 + 轻量状态残差|验证多状态校准路线|

每种至少三个seed，最终在未参与选择的新物理状态上一次性验收。

建议的暂定研究门槛：

- 强场 MAE 不高于 0.20–0.25 dB；
- 瓶颈高估 P95 不高于 0.5 dB；
- 三 seed NMSE 标准差不高于 0.25 dB；
- 四点最小增益 regret P95 不高于 10%；
- 新物理状态上的链路成功率不低于 V2.9 基线；
- 新方法相对基线的配对提升置信区间下界大于0。

这些数值是研发筛选门槛，获得实际链路合同后应换成任务指标。

### P4：量化、FPGA与OTA

只有硬件信息明确后再执行：

- 使用实际相位码本在优化环内求解，不只对连续相位结果直接取整；
- 加入通道幅相误差、功放限制、失效阵元和温漂；
- 验证模型量化后的强场误差和四点链路结果；
- 测量真实资源、吞吐、端到端时延和更新频率；
- 使用独立实测轨迹进行OTA闭环验证。

主机推理、PTQ或XModel生成不等于板上闭环通过。

## 6. 决策门

### 继续优化四点算法

只有当高预算HFSS或可信参考明显优于当前soft-min，且差距主要来自求解器时，才继续投入更复杂优化器。
当前随机正半球实验中差距较小，因此该方向优先级低于数据和模型监督。

### 修改CNN结构

只有当新物理状态下的强场误差、瓶颈高估或seed方差仍显著超标，且优化器参考证明存在可达增益时，
才修改CNN。优先改变输出物理量和监督方式，最后才考虑增加参数。

### 进入部署

必须同时具备：

- 真实任务链路合同；
- 独立物理状态验证；
- 实际相位/功率控制约束；
- 量化模型验证；
- 板上资源及时延证据；
- OTA或等价闭环结果。

## 7. 当前推荐

V2.10 的第一项实际工作应是 P0/P1：建立真实或参数化卫星轨迹与链路合同，并用冻结 V2.9 CNN
形成链路级四点基线。第二项是 P2：准备真正改变物理状态的数据。获得这些前置条件后，再实施
低秩 PSD \(Q\) 模型和受控训练对照。

在此之前，不建议简单增加CNN层数、重复导出大量同状态相位组合，或继续在已打开的V2.9保留集上调参。
