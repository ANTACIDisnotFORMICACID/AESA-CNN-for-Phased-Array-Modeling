# V2.11：HFSS-VSH 频谱审计与 SSH 方向编码受控实验计划

> 文档状态：计划版，2026-09-09  
> 上游基线：`algorithm_versions/v2.10`  
> 本轮边界：只形成分析与实验计划；尚未实现代码、生成频谱图、训练模型或改动 V2.10。  
> 术语说明：本文按上下文将“实测辐度数据”理解为“实测单极化幅度数据”。若原意是“角度以弧度保存”，则必须在数据清单中另设 `angle_unit = rad`；无论外部角度单位是什么，SSH/VSH 内部计算都统一使用弧度，且只转换一次。

## 1. 结论先行

本轮需要严格拆开两个问题：

1. **物理 VSH 阶数审计**：用完整球面的 HFSS 复矢量远场回答“表示当前天线远场需要多少个矢量球面模态”。其截断阶数记为 \(\Lambda_{\rm VSH}\)。
2. **CNN 的 SSH 方向编码**：只由方向 \(q\) 解析生成实值标量球谐特征，回答“哪一种方向特征更利于当前单极化幅度网络学习”。其编码阶数记为 \(L_{\rm enc}\)。

二者相关但不等价：

\[
\boxed{L_{\rm enc}\neq \Lambda_{\rm VSH}\ \text{是正常现象}}
\]

V2.11 的推荐主线是：

\[
\boxed{
\text{HFSS 完整复场做 VSH 审计}
\;\longrightarrow\;
\text{严格幅度训练做 SSH 编码消融}
}
\]

当前不应先把 HFSS 标签做球谐低通后再训练，也不应立即把“VSH 基线 + CNN 残差”解释成由实测幅度唯一恢复的物理复场。这样会混淆网络改进、标签简化和不可辨识的复相位自由度。

## 2. 论文原文与 V2.10 的对应边界

### 2.1 论文给出的事实

《[Multipath-Enhanced Measurement of Antenna Patterns: Theory](https://arxiv.org/pdf/2507.03639)》采用 2 端口 VNA 测量各探针耦合信号的**幅度和相位**，用 VSH 表示完整三维复矢量远场。论文式 (14)、(27)、(28) 给出远场展开和系数球面积分；式 (32) 给出同时包含 electric/magnetic 两族时的模式数：

\[
N_\Lambda=2\sum_{l=1}^{\Lambda}(2l+1)=2\Lambda(\Lambda+2).
\]

论文第 VII.A 节以包围辐射源的球半径 \(R\) 给出 \(l\gtrsim kR\) 后模态快速衰减的物理尺度，并强调实际阶数仍要随目标截断误差验证。其更保守的 \(-40\,\mathrm{dB}\) 近似只适用于相应假设和 \(kR\gg1\)，不能当作本项目的无条件精度证书。

### 2.2 当前活动基线不是完整矢量复场训练

V2.10 当前活动基线是 `v210_nominal_coupling_residual_1`，参数量 34,973。训练程序只能读取：

- 已知复 IQ 发射指令；
- \(q_x>0\) 的方向；
- 单极化非负标量幅度 \(|E_\phi(q,w)|\)；
- 指令族和测量元数据。

训练程序不得读取 HFSS 复场、测得相位、逐端口复算子、\(Q\) 矩阵或 S 参数。因此，VSH 系数审计只能作为**离线物理分析**；SSH 输入编码则可以合法进入幅度训练，因为它只依赖方向，不需要从幅度标签反演任何系数。

### 2.3 当前编码与网络接口

当前 `DirectionFourierEncoder` 对 \(q_x,q_y,q_z\) 分别计算

\[
q_d,\quad \sin(2^b\pi q_d),\quad \cos(2^b\pi q_d),
\qquad b=0,1,2,3,
\]

共得到

\[
3(1+2\times4)=27
\]

维方向特征。活动幅度模型中，这 27 维特征分别进入：

- `NominalElementPattern`：27 维方向特征 + 4 张几何图，保持 31 输入通道和 24 隐藏通道；
- `AngularOperatorResidual`：同样保持 31 输入通道，隐藏宽度为 12。

V2.11 的编码实验必须让这两个下游分支、理想传播相位、端口耦合、命令末端线性收缩和幅度损失全部保持不变。

## 3. 已核验的 HFSS 数据条件与物理先验

### 3.1 完整球面复场可用

V2.10 的四个冻结 HFSS NPZ 分区合并后具有：

- 64,800 个唯一方向 ID，恰好连续覆盖 `0..64799`；
- \(\theta=0.5^\circ,1.5^\circ,\ldots,179.5^\circ\)，共 180 点；
- \(\phi=-179.5^\circ,-178.5^\circ,\ldots,179.5^\circ\)，共 360 点；
- 每个方向保存 `h[Q,3,16]` 的 Cartesian 复矢量端口场；
- 方向单位范数最大误差约 \(5.96\times10^{-8}\)；
- 横向条件 \(|q^T h|/\|h\|\) 的 95% 分位约 \(3.89\times10^{-8}\)，最大约 \(1.18\times10^{-7}\)。

这个 1°、无极点重复的 cell-centred 网格适合以

\[
w_i=\sin\theta_i\,\Delta\theta\,\Delta\phi
\]

做完整球面积分。四个分区在 VSH 审计时仅用于恢复完整网格；其复场不得流回严格幅度训练入口。

### 3.2 \(kR\) 只确定搜索尺度

47 GHz 下：

\[
\lambda=6.37856\ \mathrm{mm}.
\]

只按 4×4 阵元中心计算，半径和尺度为：

\[
R_{\rm centre}=24.704\ \mathrm{mm},\qquad kR_{\rm centre}=24.335.
\]

HFSS 已审计实体包围盒为

\[
[-0.5,-3.4,-0.797]\ \mathrm{mm}
\quad\text{到}\quad
[5.0,23.8,45.289]\ \mathrm{mm}.
\]

以包围盒中心为球心，其半尺寸为 \([2.75,13.6,23.043]\,\mathrm{mm}\)，包围球半径约

\[
R_{\rm structure}=26.898\ \mathrm{mm},\qquad kR_{\rm structure}=26.496.
\]

论文的 \(-40\,\mathrm{dB}\) 近似给出连续值约 \(31.862\)。因此首轮应扫描

\[
\boxed{\Lambda=1,2,\ldots,40}
\]

而不是预先锁死在 25 或 32。空气盒不是辐射源包络，不能拿其尺寸计算 \(R\)；实体包围盒也只是当前几何上界，最终应结合表面电流有效支撑区域解释。

## 4. 工作包 A：HFSS 完整复场的 VSH 阶数审计

### A0. 数据与相位中心冻结

先生成只读审计清单，至少检查：

1. 四个 NPZ 的 SHA-256、方向 ID、端口顺序、频率和单位；
2. 64,800 点是否恰好组成 180×360 网格；
3. 复场是否有限、方向是否单位化、横向误差是否仍在上述数量级；
4. HFSS 相量约定、FFD 参考距离以及当前 `h` 是 \(E\)、\(rE\) 还是其他归一化量；
5. HFSS 远场相位原点、端口网格中心和实体包围盒中心之间的坐标偏移。

VSH 阶数会随展开原点改变。必须先把场平移到冻结的阵列参考中心，再计算频谱。平移因子的正负号不能凭印象决定，应通过以下两项测试确定：

- 解析平移偶极子或单元场的已知相位斜率；
- 16 端口相对相位与 \(kq\cdot(r_n-r_m)\) 的一致性。

主报告采用实体包围盒中心；同时以端口网格中心做一次敏感性对照。如果两者导致所选 \(\Lambda\) 明显变化，需先解决相位原点合同，不能继续做编码结论。

### A1. VSH 基与系数定义

物理审计采用论文的正交横向基

\[
\mathbf X_{lm},\qquad \hat{\mathbf r}\times\mathbf X_{lm},
\qquad l\ge1, -l\le m\le l.
\]

为避免把论文中的 \(j^{l+1}\)、\(\eta_0\) 和项目场归一化混入“频谱能量”，程序内部先保存正交展开系数：

\[
c^M_{n,lm}=\int_{S^2}\mathbf H_n\cdot\mathbf X_{lm}^*\,d\Omega,
\]

\[
c^E_{n,lm}=\int_{S^2}\mathbf H_n\cdot
(\hat{\mathbf r}\times\mathbf X_{lm})^*\,d\Omega.
\]

论文兼容的 multipole 系数作为带明确定义的派生量另存，不与上述系数混名。若 `h` 与论文的 modified field 只相差全方向共同复常数，则归一化阶谱和重构 NMSE 不受影响；绝对辐射功率则必须等单位、距离和 \(\eta_0\) 合同确认后再计算。

离散积分采用 cell-centred 球面积权重。先验证离散 Gram 矩阵的近似正交性；若高阶离散误差超过阈值，则改用加权 QR/LSQR，不使用不稳定的普通法方程。实现按 \(l\) 或方向分块，避免一次生成 64,800×3,360 的完整复设计矩阵。

### A2. 必须同时审计的两个对象

对每个端口 \(n\) 分析：

1. 相位中心校正后的完整复矢量场 \(H_n(q)\)；
2. 去除当前解析阵元传播相位后的包络

\[
A_n(q)=H_n(q)e^{-jkq\cdot r_n}.
\]

第二项用于回答“V2.10 的解析传播层究竟移除了多少角域高频复杂度”。它仍可做 VSH 展开，但不再直接服从原天线包围球的同一个 \(kR\) 截断解释，报告中必须称为**复杂度诊断**，不能称为新的物理辐射尺寸证明。

每阶能量定义为

\[
P_l^{(n)}=
\sum_{m=-l}^{l}
\left(|c^M_{n,lm}|^2+|c^E_{n,lm}|^2\right).
\]

端口聚合同时报告总和、中位数、P10/P90 和最坏端口，不只画 16 端口平均值。

### A3. 阶数判据

逐阶重构 \(\widehat H_n^{(\Lambda)}\) 与 \(\widehat A_n^{(\Lambda)}\)，至少计算：

\[
\mathrm{NMSE}_{\rm sph}(\Lambda)=
\frac{\sum_{i,n}w_i\|\widehat H_n(q_i)-H_n(q_i)\|_2^2}
{\sum_{i,n}w_i\|H_n(q_i)\|_2^2},
\]

\[
T(\Lambda)=
10\log_{10}
\frac{\sum_{l>\Lambda}P_l}{\sum_lP_l}.
\]

还要报告：

- 每端口 NMSE 和最坏端口；
- 复矢量误差、幅度误差、强场幅度 MAE/P95；
- 留出角格重构误差：在稀疏/棋盘角度子集求系数，在未参与拟合的方向上评价；
- \(\Lambda\) 增长时的条件数或正交误差。

不强行输出一个脱离精度目标的“唯一阶数”。最终至少给出

\[
\Lambda_{-20},\quad \Lambda_{-30},\quad \Lambda_{-40}
\]

三档结果，并说明它们分别由尾能量、全场重构和强场误差中的哪个约束决定。

### A4. 频谱图像交付

后续实现阶段至少生成以下图像：

1. `vsh_order_spectrum_H_vs_A.png`：\(H\) 与去相位 \(A\) 的逐阶功率谱，纵轴使用 \(10\log_{10}\)；
2. `vsh_cumulative_tail_energy.png`：累计保留能量/截断尾能量，标注 \(kR_{\rm centre}\)、\(kR_{\rm structure}\) 和目标阈值；
3. `vsh_reconstruction_error_vs_order.png`：重构 NMSE、强场 MAE 与 \(\Lambda\)；
4. `vsh_port_order_heatmap.png`：16 端口×阶数热图，暴露边缘/角落端口差异；
5. `vsh_lm_spectrum.png`：\((l,m)\) 模态能量分布，明确坐标轴选择；
6. `vsh_reconstruction_examples.png`：原场、截断重构和误差图，至少含中心/边缘/角落端口。

所有图必须同时保存生成数据表，避免只能从 PNG 读数。功率谱用 \(10\log_{10}\)，场幅度图才用 \(20\log_{10}\)，二者不得混用。

### A5. 数值验收测试

在真实 HFSS 数据前先通过：

- 实值/复值 SSH 的低阶解析关系与加法定理；
- VSH 的横向性和离散正交性；
- 单一已知 \((l,m)\) 模式的系数恢复；
- 解析偶极子或合成 VSH 场的重构；
- 坐标整体旋转后，逐阶总能量 \(P_l\) 保持不变；
- 分块与非分块小规模计算一致。

## 5. 工作包 B：面向单极化幅度训练的实值 SSH 编码

### B1. 坐标定义

物理 VSH 审计可沿用 HFSS 的标准 \(+Z\) 极轴，以便核对 \(E_\theta,E_\phi\)。CNN 输入编码则优先采用与阵列一致的局部球坐标：

\[
q=(q_x,q_y,q_z)
=(\cos\vartheta,\ \sin\vartheta\cos\varphi,\ \sin\vartheta\sin\varphi),
\]

\[
\vartheta=\arccos(q_x),\qquad
\varphi=\operatorname{atan2}(q_z,q_y).
\]

这样极轴是阵面法向 \(+X\)，\(\varphi=0\) 沿列方向 \(+Y\)，向行方向 \(+Z\) 增长。实现应尽量直接由单位向量和递推式求基，避免在极点显式除以 \(\sin\vartheta\)。所有三角函数接收弧度。

### B2. 实值 SSH 定义与维度

输入方向不是矢量电场，所以使用 real scalar spherical harmonics，而不是 VSH。固定 Condon-Shortley 相位、归一化和通道顺序：

\[
\Psi_L(q)=
[Y^R_{00},Y^R_{1,-1},\ldots,Y^R_{L,L}],
\qquad K=(L+1)^2.
\]

其中正负 \(m\) 分别由复 SSH 的实部/虚部构造。通道元数据必须逐项保存 `(l,m,kind,normalization)`，防止训练、导出和部署使用不同约定。

主实现先用全球正交归一化并乘固定尺度 \(\sqrt{4\pi}\)，使 \(Y_{00}\) 为 1 量级。由于训练域只有正半球，SSH 通道在该子域不再正交；先画训练集 Gram 矩阵与条件数。任何白化或按训练集标准化都必须只在训练方向上拟合，并作为独立实验记录，不能用验证/测试方向统计量。

### B3. 保持 27 维和下游 CNN 不变

纯 SSH 方案：

\[
z_{\rm SSH}(q)=P_{\rm SSH}\Psi_L(q)\in\mathbb R^{27}.
\]

混合方案：

\[
z_{\rm hybrid}(q)=\gamma_F(q)+\alpha P_{\rm SSH}\Psi_L(q),
\qquad \alpha_0=0.
\]

`P_SSH` 使用非零、方差受控初始化；若投影和 \(\alpha\) 同时初始化为零，二者会形成死分支。混合模型加载同一 V2.10 checkpoint 后在 \(\alpha=0\) 时必须逐位复现基线输出，并设置“同一 checkpoint 继续训练、但没有 SSH 分支”的更新预算控制组。

方向编码应由顶层模型计算一次，并共享给 nominal 与 angular-residual 两个分支，避免无意义地复制两套投影参数。两处分支仍接收 27 维方向特征，故其后均保持 31 输入通道；24/12 隐藏宽度和所有物理层不变。

### B4. 编码实验矩阵

第一阶段只比较最小而可解释的四组：

|编号|方向编码|目的|
|---|---|---|
|F27|当前 Fourier-27|冻结基线|
|FP27|Fourier-27 → Linear-27|控制“新增线性投影参数”的影响|
|S4-27|real SSH，\(L=4,K=25\) → Linear-27|与 27 维最接近的纯 SSH 主实验|
|H4-27|Fourier-27 + \(\alpha\)·SSH-25→27|从现有 checkpoint 零门控增量学习|

只有 S4/H4 至少一个显示稳定收益后，再扫描：

\[
L_{\rm enc}\in\{2,3,4,5,6,8\},
\quad K\in\{9,16,25,36,49,81\}.
\]

该扫描由幅度预测验证集决定，绝不直接取 \(L_{\rm enc}\approx kR\)。必要时增加“全局 +Z 极轴 SSH”作为坐标消融，但不与阶数消融同时改变。

## 6. 工作包 C：与原编码的公平比较协议

### C1. 数据隔离

所有 SSH/Fourier 训练继续只使用现有严格幅度目录中的：

`direction.npy`、`command_iq.npy`、`amplitude.npy`、`command_family.npy`、角度数组和 `manifest.json`。

VSH 审计读取的复场、中间系数和频谱文件放入单独 artifact，训练入口加入显式禁止路径/字段检查。不能把 VSH 截断重构当成新标签，不能把 HFSS 复相位作为 SSH 模型的辅助监督。

### C2. 配对控制

每组固定：

- 相同方向块、指令和外部评估集；
- 相同 seed，建议至少 `28101/28102/28103`；
- 相同 batch、抽样顺序、更新步数、优化器、学习率、早停和损失权重；
- 相同 nominal、coupling、residual 和解析相位结构；
- 同一模型选择规则，只在 validation 上选型。

F27 与纯 SSH 从配对随机初始化训练；H4 从当前 checkpoint 继续训练，同时运行等步数的 F27-continuation。FP27 用来判断收益是否仅来自新增投影容量。报告原始参数量、训练时间、推理时间和编码缓存开销，不用“后端维度仍为 27”掩盖新增参数。

### C3. 评价指标

保持 V2.10 已有指标：

- 幅度 NMSE、功率 NMSE、dB MAE、方向图相关系数；
- 每条指令相对峰值 0 至 -3、-3 至 -6、-6 至 -10、-10 至 -20 dB 分层误差；
- 强场（峰值前 10 dB）MAE/P95；
- 单阵元、DFT、随机相位指令族分层；
- 未见角块×未见指令测试；
- 独立 HFSS reserved 评估；
- 四点优化中的真实最小增益、regret P95 和瓶颈高估 P95；
- 三 seed 均值、标准差和配对 bootstrap 置信区间。

增加编码诊断但不作为最终任务替代指标：

- 特征 Gram 条件数和有效秩；
- 简单 ridge/linear probe 在未见角块上的误差；
- 混合模型 \(\alpha\) 轨迹、\(\|P_{\rm SSH}\|\) 和各阶投影能量；
- 误差随球面角距离、扫描角和 \(l\) 阶的分布。

### C4. 暂定决策门

SSH 只有同时满足以下条件才进入下一版默认候选：

1. 至少两个 seed 的验证与未见角块测试方向一致改善；
2. 相对 FP27，收益仍存在，说明不是单纯增加线性层；
3. 外部幅度 NMSE 不恶化超过 0.2 dB，强场 MAE 不恶化超过 0.05 dB；
4. 四点 regret P95 和瓶颈高估 P95 不恶化；
5. 置信区间和逐指令配对结果不由少数样本驱动；
6. 没有出现高阶特征数值爆炸、网格纹理过拟合或明显推理负担。

这些门槛是本轮受控筛选规则，不是最终 OTA 指标。若 S4/H4 都未通过，就保留 Fourier-27，不再因为“球谐更物理”而强推结构变更。

## 7. 方案 2 的处理：先诊断，后决定是否实现

“VSH/SSH 基线 + CNN 残差作用于 \(\widetilde A\)”在完整复场监督下具有清晰形式：

\[
\widetilde A_n(q)=A_n^{\rm SH}(q)+\Delta A_n^{\rm CNN}(q).
\]

但当前实测合同只给出

\[
y(q,w)=|h_p(q)w|,
\]

并不能唯一确定完整矢量复场、每个方向的公共复相位或论文意义下的 electric/magnetic VSH 系数。因此 V2.11 首轮不把方案 2 纳入活动幅度基线。

后续只有两条合规路线：

1. **HFSS 复场 oracle 支线**：用完整复场验证 SH/VSH 基线是否真的降低残差阶数和 CNN 容量，但明确标注为诊断实验，不冒充实测幅度可训练方案；
2. **幅度任务支线**：对等效单极化复标量算子设置 SSH 参数化，再由多条已知相位编码指令的幅度干涉约束训练。最终只解释幅度预测和优化性能，不把学到的复系数宣称为唯一真实 VSH multipoles。

只有工作包 A 证明 \(A\) 的谱显著低阶集中，且工作包 B 证明 SSH 输入编码稳定获益后，才为方案 2 建立独立实验协议。

## 8. 实施顺序与阶段产物

### 阶段 1：VSH 审计工具

计划新增只读数据装配、SSH/VSH 基、分块投影、重构和绘图工具；产物包含协议 JSON、系数 NPZ、逐阶 CSV、图像和验证报告。不得改写四个冻结源 NPZ。

### 阶段 2：SSH 编码接口与单元测试

计划增加统一 direction-encoder 接口、real SSH 编码和 Fourier/SSH/hybrid 配置；先证明 F27 数值回归和 H4 的 \(\alpha=0\) checkpoint 等价性，再允许训练。

### 阶段 3：最小四组受控训练

完成 F27、FP27、S4-27、H4-27 的三 seed 配对实验，先在 validation 选型，再一次性形成测试与外部报告。

### 阶段 4：有条件的阶数扫描

只有最小实验通过趋势门槛才运行 \(L_{\rm enc}\) 扫描；否则停止并保留 Fourier 基线。

### 阶段 5：方案 2 决策

综合 \(P_l^H/P_l^A\)、重构阶数、编码实验和幅度可辨识性，决定是否建立新的“SH 基线 + CNN 残差”研究版本。
