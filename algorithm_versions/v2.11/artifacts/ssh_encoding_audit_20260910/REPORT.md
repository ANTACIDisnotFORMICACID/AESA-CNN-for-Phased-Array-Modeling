# V2.11 SSH 输入尺度与正半球相关性审计

## 数据边界

- 仅使用训练查询索引，共 16300 个方向；验证集和测试集未参与统计。
- 所有训练方向均满足严格 `q_x > 0`。
- 实 SSH 采用 degree-major、`m=-l..l` 排列，本次拟合到 L=8，共 81 个通道。

## 输入尺度

- V2.10 Fourier：范围 [-1.000000, 1.000000]，逐通道标准差范围 [0.280221, 0.728436]。
- SSH 原值：范围 [-1.091384, 1.161513]，非常量通道标准差范围 [0.136917, 0.405839]。
- 使用训练集 `mu_lm/std_lm` 标准化后，非常量通道标准差范围 [0.999993, 0.999998]。
- `Y_0_0` 在任意方向恒定，标准化后为零；Linear 层偏置承担等价常量自由度。

## 正半球相关性

- 标准化后最大非对角绝对相关系数为 0.839561：`Y_1_-1` 与 `Y_2_-2`。
- 经验相关矩阵条件数为 1.056349e+11。
- 首轮候选的条件数：L=4 为 6.904317e+04，L=5 为 2.505632e+06；高阶前缀的病态性明显增强。
- 因此保留 `Linear K->27`：它既统一 CNN 输入通道，又允许在 `q_x>0` 上重新组合相关模态。

## 实验设置

- `fourier`：原 V2.10 的 27 通道严格对照。
- `ssh_l4`：25 个标准化 SSH 通道，经 Linear 25->27。
- `ssh_l5`：36 个标准化 SSH 通道，经 Linear 36->27。
- `fourier_plus_ssh_l4`：`Fourier + alpha * Linear(SSH)`，`alpha=0` 初始化，初始输出与 V2.10 完全一致。

物理 VSH 的 L=30 是复矢量远场带宽判据，不直接作为 CNN 的 SSH 输入阶数；SSH 编码先比较 L=4/5，再根据验证集结果扩阶。
