# V2.11 Fourier/SSH 幅度训练消融报告

## 结论

在本轮相同 CUDA 环境、相同数据划分和三个配对种子下，`Fourier + SSH L=4` 是最稳定的候选：

- 验证 NMSE：-17.981 ± 0.259 dB；
- 复用内部测试 NMSE：-16.872 ± 0.206 dB；
- 复用 HFSS reserved holdout NMSE：-17.802 ± 0.330 dB；
- 外部强场前10 dB MAE：0.648 ± 0.041 dB。

相对同种子 Fourier，混合编码在三次外部评估中全部获胜，配对 NMSE 改善 1.318 dB；外部 NMSE 的种子标准差由 1.013 dB 降至 0.330 dB。

但它尚不能替换历史 V2.10：历史 checkpoint 的内部测试/外部 NMSE 为 -17.903/-19.055 dB，仍优于混合模型三种子均值。当前结论是“混合编码在本轮受控重训中有效且更稳”，不是“已经刷新 V2.10 最佳结果”。

## 解释

1. 纯 SSH-L4 的低阶角向带宽不足，验证/内部测试均值逊于 Fourier；不建议作为下一基线。
2. SSH-L5 在两个种子上优于 Fourier，但均值提升小于种子波动，且参数更多、正半球条件数更差。
3. 混合编码保留了 Fourier 高频坐标映射，同时让 SSH 提供平滑全局修正。两处分支的 alpha 均明显离开零，说明网络实际使用了 SSH，而非保持初始 Fourier。
4. 混合编码总参数仅比 Fourier 增加 4.02%，但训练耗时增加约 51.2%。
5. 所有模型在低于峰值20 dB的弱场误差最大；混合编码的主要收益也包含强场区域改善，而不仅是低幅度点。

## 与同种子 Fourier 的配对差值

差值定义为“候选模型 NMSE - 同种子 Fourier NMSE”，负数表示改善。

| 编码 | 验证差值 dB | 内部测试差值 dB | 外部差值 dB | 外部获胜种子数 |
|---|---:|---:|---:|---:|
| SSH L=4 | +0.543±1.300 | +0.394±0.922 | +0.141±1.264 | 2/3 |
| SSH L=5 | +0.003±1.558 | -0.043±1.249 | -0.312±1.425 | 2/3 |
| Fourier + SSH L=4 | -1.161±1.046 | -0.808±0.727 | -1.318±0.852 | 3/3 |

混合编码还把外部幅度 dB MAE 从 2.263 降到 1.956 dB（下降 13.6%），把强场前10 dB MAE 从 0.793 降到 0.648 dB（下降 18.2%），平均相关系数从 0.97034 提升到 0.97855。按真实相对场强分层，五个区间的 MAE 均下降，因此收益不是由某个单独幅度区间造成。

## 与历史 V2.10 checkpoint 的边界

混合模型相对历史 checkpoint 的内部测试 NMSE 仍差 1.031 dB，外部 NMSE 仍差 1.253 dB；外部 MAE 高 0.269 dB，强场前10 dB MAE 高 0.112 dB。历史结果与本轮重训并非同一训练数值轨迹，所以这里只用它判断“能否替换既有基线”，不把差值归因于编码本身。

## 可复现性边界

- 本轮使用当前 PyTorch/CUDA 环境重新训练。相同 Fourier 结构和种子没有复现历史 checkpoint 的最佳轨迹，当前 CPU 复核也未消除差距，因此存在未完全定位的训练栈/数值轨迹差异。
- 三种子配对比较可支持本轮编码排序，但测试集和 HFSS reserved holdout 都已在 V2.10 阶段打开，不能作为新的无偏盲测。
- 若要正式升级基线，应先冻结混合编码方案，再建立全新的未见角块或实测幅度盲测集。
