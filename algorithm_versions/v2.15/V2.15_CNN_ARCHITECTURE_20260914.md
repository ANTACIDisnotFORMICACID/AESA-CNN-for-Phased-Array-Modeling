# V2.15 CNN 结构说明与 V2.12 对比

日期：2026-09-14。本文依据当前仓库代码、V2.15 冻结训练配置和实际 checkpoint 逐参数核算，说明正向预测器的完整数据流、每个可学习层、固定物理层和参数量。本文只解释已经完成的 V2.15，不修改模型、checkpoint、gate 或 external-test 结论。

文中的“论文批注”紧邻对应设计，表示该层的理论来源或最接近的参考思想；若项目实现并非论文结构的原样复现，会在批注中明确指出。

## 1. 一句话概括

V2.15 没有推翻 V2.12 的相干物理算子，而是保留

\[
\text{解析阵列相位}+	ext{逐阵元复增益}+	ext{L=4 filtration SSH}+	ext{Fourier 方向编码},
\]

把原来 width=24、depth=2 的普通 3×3 残差 CNN，改为 width=32 的

\[
\boxed{
\text{一个局部残差块}
+
\text{方向门控的行/列/S 图消息块}
}
\]

并继续通过 zero-start IQ head 只预测物理 envelope 的复残差。V2.12 结构共 `28,789` 个可训练参数，V2.15 graph 结构共 `29,977` 个，相差 `1,188`，即 `+4.126%`。

## 2. 输入、输出与共同物理骨架

### 2.1 输入与最终输出

令 batch 大小为 \(B\)，一次计算的观察方向数为 \(Q\)，阵元数固定为16。输入包括：

- 单位观察方向 \(q\in\mathbb R^3\)，张量形状 `[B,Q,3]`；
- 复阵列命令 \(w\in\mathbb C^{16}\)，IQ 形状 `[B,2,4,4]`。

模型先预测逐方向复端口算子 \(g(q)\in\mathbb C^{16}\)，再严格执行相干叠加：

\[
E(q,w)=g(q)^T w,
\qquad
\hat y(q,w)=|E(q,w)|.
\]

因此 CNN 不是直接输出某一条命令的幅度，而是生成16阵元复算子的方向相关残差；同一个 \(g(q)\) 可以与不同命令进行解析组合。

### 2.2 去相位复 envelope

第 \(n\) 个阵元位置为 \(r_n\)，47 GHz 波数为 \(k=2\pi/\lambda\)。两版共同采用

\[
g_n(q)=a_n(q)e^{jkq^Tr_n},
\]

其中

\[
a_n(q)=s\left[
b_n+
\sum_{l=1}^{4}\alpha_l
\sum_{\mu=1}^{2l+1}
\phi_{l\mu}(q)\beta_{l\mu n}
+\delta_n(q)
\right].
\]

这里：

- \(s\) 是固定 `envelope_scale` buffer；
- \(b_n\) 是逐阵元复基准增益；
- \(\phi_{l\mu}\) 是 train-measure 下构造的 filtration real SSH；
- \(\beta_{l\mu n}\) 是复 SSH 系数，\(\alpha_l\) 是每个阶次的实 gate；
- \(\delta_n(q)\) 是 V2.12 或 V2.15 CNN 输出的复 IQ 残差。

L=4 的 filtration ranks 实测为 `(1,3,5,7,9)`，即25个模式全部保留；常数阶由基准增益承担，CNN骨架使用24个非恒定 SSH 模式。

### 2.3 共同可训练参数

| 模块 | 参数张量 | 数量 | 说明 |
|---|---:|---:|---|
| 基准增益 anchor | `b0_raw` | 1 | 第1阵元实部经 softplus 保持为正，固定其虚部为0以消除全局规范自由度 |
| 其余基准增益实部 | `b_real_rest[15]` | 15 | 阵元2–16 |
| 其余基准增益虚部 | `b_imag_rest[15]` | 15 | 阵元2–16 |
| SSH 复系数实部 | `ssh_beta_real[24,16]` | 384 | 24个非恒定模式×16阵元 |
| SSH 复系数虚部 | `ssh_beta_imag[24,16]` | 384 | 同上 |
| SSH 阶次 gate | `ssh_alpha[4]` | 4 | 对应 \(l=1,2,3,4\) |
| **共同小计** |  | **803** | 两版完全相同 |

解析传播相位、复数相干求和、绝对值、25×25 filtration 变换、阵元坐标和 `envelope_scale` 都是固定计算或 buffer，不计入可训练参数。

## 3. 共同的31通道 CNN 输入

两版的 residual CNN 都先将方向编码成27维：

\[
\Gamma(q)=
\left[
q_x,q_y,q_z,
\{\sin(2^b\pi q_d),\cos(2^b\pi q_d)\}_{d\in\{x,y,z\},b=0}^{3}
\right],
\]

因此通道数为

\[
3(1+2\times4)=27.
\]

这27个方向特征被复制到4×4阵元平面，再拼接4张固定几何图：

1. 归一化 row coordinate；
2. 归一化 column coordinate；
3. edge indicator；
4. corner indicator。

最终 CNN 输入为 `[BQ,31,4,4]`。Fourier 映射用于缓解低维坐标网络学习高角频变化时的谱偏置；V2.15 沿用了 V2.12 的确定性四频带版本，而不是随机 Fourier features。[2]

> **论文批注｜[2] Tancik et al., Fourier Features（NeurIPS 2020）**：对应“先把低维方向坐标映射到多频正弦/余弦，再交给神经网络”的逻辑。V2.15 使用手工固定的 \(2^b\pi\) 频带，不是论文中的随机频率采样或其完整 NTK 配置。

## 4. V2.12 residual CNN：逐层设计

记 \(N=BQ\)。卷积参数按

\[
P_{\mathrm{conv}}=C_{out}(C_{in}k^2+1)
\]

计算，最后的 `+1` 表示每个输出通道的 bias。

| 顺序 | 层/操作 | 输入 → 输出 | 初始化或作用 | 参数量 |
|---:|---|---|---|---:|
| 0 | Fourier encoder | `[B,Q,3] → [B,Q,27]` | 固定频率 buffer | 0 |
| 1 | 拼接 geometry maps | `[B,Q,27] → [N,31,4,4]` | 4张固定图 | 0 |
| 2 | stem `Conv2d(31,24,3,pad=1)` | `[N,31,4,4] → [N,24,4,4]` | 普通初始化 | `24(31×9+1)=6,720` |
| 3 | SiLU | 不变 | \(x\sigma(x)\) | 0 |
| 4 | block-1 conv1 `24→24,3×3` | `[N,24,4,4] → 同形` | 普通初始化 | `5,208` |
| 5 | block-1 SiLU | 不变 | 非线性 | 0 |
| 6 | block-1 conv2 `24→24,3×3` | 同形 | weight/bias 全零 | `5,208` |
| 7 | block-1 skip add | \(h\leftarrow h+F_1(h)\) | 初始严格恒等 | 0 |
| 8 | block-2 conv1 `24→24,3×3` | 同形 | 普通初始化 | `5,208` |
| 9 | block-2 SiLU | 不变 | 非线性 | 0 |
| 10 | block-2 conv2 `24→24,3×3` | 同形 | weight/bias 全零 | `5,208` |
| 11 | block-2 skip add | \(h\leftarrow h+F_2(h)\) | 初始严格恒等 | 0 |
| 12 | head `Conv2d(24,2,3,pad=1)` | `[N,24,4,4] → [N,2,4,4]` | weight/bias 全零 | `434` |
| 13 | componentwise bounded tanh | `[N,2,4,4] → [B,Q,2,4,4]` | \(2\tanh(z/2)\) | 0 |

V2.12 CNN 小计：

\[
6720+4\times5208+434=27,986.
\]

加上共同物理/SSH参数：

\[
27,986+803=\boxed{28,789}.
\]

两个 residual block 都使用恒等 shortcut。残差学习的基本思想来自 ResNet；本项目进一步把每个 block 的第二个卷积和最终 IQ head 置零，使初始 CNN 修正严格为零。该具体初始化是项目实现，不应被等同为原论文的标准配置。[1][5]

> **论文批注｜[1] He et al., ResNet（CVPR 2016）**：对应 \(h\leftarrow h+F(h)\) 的恒等 shortcut 和残差学习。**[5] Zhang et al., Fixup（ICLR 2019）**：对应“通过初始化控制残差支路初始扰动”的相关思想；本项目直接把第二卷积和 IQ head 置零，不是 Fixup 的缩放与偏置方案。

## 5. V2.15 graph residual CNN：逐层设计

### 5.1 主干与局部残差块

| 顺序 | 层/操作 | 输入 → 输出 | 初始化或作用 | 参数量 |
|---:|---|---|---|---:|
| 0 | Fourier encoder | `[B,Q,3] → [B,Q,27]` | 与V2.12相同 | 0 |
| 1 | 拼接 geometry maps | `[B,Q,27] → [N,31,4,4]` | 与V2.12相同 | 0 |
| 2 | stem `Conv2d(31,32,3,pad=1)` | `[N,31,4,4] → [N,32,4,4]` | width由24增至32 | `32(31×9+1)=8,960` |
| 3 | SiLU | 不变 | 非线性 | 0 |
| 4 | local conv1 `32→32,3×3` | `[N,32,4,4] → 同形` | 普通初始化 | `9,248` |
| 5 | local SiLU | 不变 | 非线性 | 0 |
| 6 | local conv2 `32→32,3×3` | 同形 | weight/bias 全零 | `9,248` |
| 7 | local skip add | \(h\leftarrow h+F(h)\) | 初始严格恒等 | 0 |

局部主干小计为

\[
8,960+2\times9,248=27,456.
\]

### 5.2 三类固定图

将 `[N,32,4,4]` reshape 为 \(H\in\mathbb R^{N\times32\times16}\)。三张16×16邻接矩阵为：

- \(A_r\)：同一列、行索引相差1的上下邻居；
- \(A_c\)：同一行、列索引相差1的左右邻居；
- \(A_s\)：第三图，随反事实 arm 改变。

所有非零图都使用对称归一化

\[
\bar A=D^{-1/2}AD^{-1/2}.
\]

这与局部图卷积常用的归一化传播形式有关，但 V2.15 不是标准两层 GCN：它在固定4×4孔径上并行使用三张图、使用有符号方向 gate，且三路消息共享后续1×1投影。[3]

> **论文批注｜[3] Kipf & Welling, GCN（ICLR 2017）**：对应 \(D^{-1/2}AD^{-1/2}\) 的归一化局部图传播思想。V2.15 没有照搬 GCN 分类网络，而是把阵元视为节点、把固定物理邻接用于复 envelope 残差的消息传递。

第三图的构造为：去除 S 矩阵对角线，对每一行按 \(|S_{ij}|\) 保留最强4个邻居，取有向 mask 与其转置的并集，再用 \(\max(|S_{ij}|,|S_{ji}|)\) 对称化和归一化。

| arm | 第三图 \(A_s\) | 可训练参数是否变化 |
|---|---|---|
| `graph_geometry` | 全零，仅使用行/列图 | 否 |
| `graph_s_true` | 真实47 GHz `abs(Sij)` top-4图 | 否 |
| `graph_s_shuffled` | 用固定 seed=21500 置换节点后的真实S图 | 否 |

三张图均注册为 buffer，每张含256个固定标量，合计768个；它们不是参数，也不参与梯度更新。三种 graph arm 的参数量因此完全相同。

### 5.3 方向 gate 与图消息

由原始27维方向编码生成三个有符号 gate：

\[
\gamma(q)=\tanh(W_g\Gamma(q)+b_g)\in[-1,1]^3.
\]

`Linear(27,3)` 的参数量为

\[
3(27+1)=84.
\]

对每个隐藏通道，图传播为

\[
M(q)=
\gamma_r(q)\bar A_rH(q)
+\gamma_c(q)\bar A_cH(q)
+\gamma_s(q)\bar A_sH(q).
\]

这里 gate 可以为负，因此不是概率或 attention softmax，而是随方向改变符号和强度的三算子线性组合。它在思想上属于输入条件化的特征调制；与 FiLM 的共同点是由外部条件改变中间计算，但 V2.15 调制的是三个图消息分支，不是标准 FiLM 的逐通道 affine layer。[4]

> **论文批注｜[4] Perez et al., FiLM（AAAI 2018）**：对应“由外部条件动态调制中间特征计算”的逻辑。这里外部条件是观察方向 \(q\)，被调制对象是 row/column/S 三个图算子；没有使用标准 FiLM 的逐通道 scale-and-shift。

### 5.4 图投影、融合与输出头

| 顺序 | 层/操作 | 输入 → 输出 | 作用 | 参数量 |
|---:|---|---|---|---:|
| 8 | direction gate `Linear(27,3)` + tanh | `[N,27] → [N,3]` | 生成三路有符号系数 | `84` |
| 9 | 三图传播与加权和 | `[N,32,16] → 同形` | 固定邻接，无边参数 | 0 |
| 10 | graph projection `Conv2d(32,32,1)` | `[N,32,4,4] → 同形` | 图消息通道混合 | `32(32+1)=1,056` |
| 11 | residual fusion | \(h\leftarrow h+\Delta h_{graph}\) | 保留局部主干 | 0 |
| 12 | SiLU | 不变 | 融合后非线性 | 0 |
| 13 | IQ head `Conv2d(32,2,3,pad=1)` | `[N,32,4,4] → [N,2,4,4]` | weight/bias 全零 | `578` |
| 14 | componentwise bounded tanh | `[N,2,4,4] → [B,Q,2,4,4]` | \(2\tanh(z/2)\) | 0 |

V2.15 CNN 小计：

\[
27,456+84+1,056+578=29,174.
\]

加上共同物理/SSH参数：

\[
29,174+803=\boxed{29,977}.
\]

最终 head 全零意味着即使 stem、gate 和 graph projection 已随机初始化，初始时仍有

\[
\delta_n(q)=0,
\]

所以 graph 三臂在相同 seed 下初始正向输出严格一致，并从共同物理基线开始学习。

> **论文批注｜[1] ResNet + [5] Fixup 的相关思想**：zero-start 的目的，是让新增结构在初始化时不破坏既有物理基线，并使“无修正”成为显式起点。此处是项目特定的零输出头实现，不应声称为两篇论文中的原始初始化算法。

## 6. 完整正向数据流

```text
direction q [B,Q,3]
    ├─ Fourier-4 encoding ───────────────> 27 direction channels
    ├─ real filtration SSH L=1..4 ──────> complex SSH envelope
    └─ analytic phase exp(j k q^T r_n) ─> fixed propagation

27 direction channels + 4 geometry maps
    └─ [BQ,31,4,4]
         └─ 3×3 stem, width 32
              └─ one local residual block
                   ├─ row graph message × direction gate
                   ├─ column graph message × direction gate
                   └─ third graph message × direction gate
                        └─ sum → 1×1 projection → residual fusion
                             └─ SiLU → zero-start 3×3 IQ head
                                  └─ complex residual δ_n(q)

baseline b_n + SSH envelope + CNN residual
    └─ multiply analytic phase → g_n(q)
         └─ coherent sum Σ_n g_n(q)w_n
              └─ absolute value → predicted amplitude
```

逐阵元 EEP/AEP 复响应进行线性组合是相控阵建模的经典物理路径，active-element pattern 可把互耦和平台影响包含到阵元响应中；V2.15 的解析相干合成与这一思路一致，但网络内部的 S 图只是一种额外归纳偏置，不能据此直接解释为真实互耦算子。[6]

> **论文批注｜[6] Pozar, The Active Element Pattern（IEEE TAP 1994）**：对应“逐阵元 active/embedded pattern 在统一端口约定下线性合成阵列场”的物理依据。V2.15 的解析相干求和与这一框架一致；静态 `|S|` 图是项目新增的学习先验，并非 Pozar 论文给出的神经网络结构。

## 7. 与 V2.12 的逐项变化

| 项目 | V2.12 结构 | V2.15 graph 结构 | 变化性质 | 对应论文批注 |
|---|---|---|---|---|
| 物理输出 | 复 \(g(q)\) 后相干求和取模 | 相同 | 不变 | [6] AEP线性合成框架 |
| 解析阵列相位 | 保留 | 保留 | 不变 | [6]提供物理背景；具体相位层为项目实现 |
| filtration SSH | L=4，24个非恒定模式 | 相同 | 不变 | V2.12项目既有设计，本文未额外归因 |
| 方向编码 | Fourier-4，27维 | 相同 | 不变 | [2] Fourier Features；固定频带为项目改写 |
| 几何输入图 | row/column/edge/corner | 相同 | 不变 | 项目几何编码 |
| CNN width | 24 | 32 | 增宽 | 工程容量选择，无特定论文 |
| 普通 residual blocks | 2个 | 1个 | 减少1个 | [1] ResNet |
| 显式图消息 | 无 | 行图+列图+第三图 | 核心新增 | [3] GCN归一化局部传播；非原样复现 |
| 方向条件化 | 方向只作为CNN输入 | 另生成3个graph gates | 核心新增 | [4] FiLM条件调制思想；非标准FiLM层 |
| S 参数 | 不进入网络 | 仅 true/shuffled arm 作为固定 `abs(S)` 图 | 新增反事实 | 项目反事实；[6]只给出S/AEP物理边界，不给出该图结构 |
| 自由16×16矩阵 | 无 | 无 | 继续禁止 | 项目可识别性与过拟合约束 |
| 输出 | 2通道 IQ，componentwise tanh | 相同 | 不变 | 项目复残差接口 |
| zero-start head | 是 | 是 | 不变 | [1][5]相关思想；具体零头为项目实现 |
| 总参数 | 28,789 | 29,977 | `+1,188 / +4.126%` | 由实际代码核算 |

参数变化可以进一步分解为

\[
\begin{aligned}
\Delta P
&=(8,960-6,720)
+(18,496-20,832)\\
&\quad+84+1,056+(578-434)\\
&=1,188.
\end{aligned}
\]

即 stem 增宽增加参数，少一个普通残差块抵消大部分增量，再增加 gate、1×1 图投影和较宽 head。

## 8. 为什么引入 graph 与 gate：决策回溯

### 8.1 引入 graph 的直接证据

V2.14 先对去除解析相位后的复算子残差 \(R(q,n)\) 做物理归因。可将阵元间残差协方差写成

\[
C_{ij}=
\sum_q\omega_q
R(q,i)^*R(q,j),
\]

再比较 \(|C_{ij}|\) 与几何邻接、\(|S_{ij}|\) 的关系。实际结果为：

- residual covariance 与阵元邻接的相关：`0.638`；
- residual covariance 与 `|Sij|` 的相关：`0.631`；
- `L≤12` SSH 只能投影约 `59.5%` 残差能量，仍有 `40.5%` 尾部；
- 静态两系数 S 多项式 P3 只改善 `0.011 dB`，未通过；
- train-only 低秩 P5 为 `-0.637 dB`，外推反而恶化；
- corner/edge/interior 只有弱梯度，单独分三类不足以解释误差。

这些证据共同排除了两个过于简单的解释：

\[
R(q,n)\ne
\text{固定低阶 S 矩阵混合},
\qquad
R(q,n)\ne
\sum_{k=1}^{K}u_k(q)v_k(n)
\quad(K\text{ 很小}).
\]

但较高的邻接相关又表明残差不是完全无结构。因此当时选择的不是继续加深普通 CNN，也不是拟合自由16×16矩阵，而是将假设改为

\[
R_i(q)\approx
F_\theta\!\left(
h_i(q),
\{h_j(q):j\in\mathcal N(i)\}
\right),
\]

即用局部、共享、非线性的消息函数表达阵元相关性。Graph 的作用是把“哪些阵元允许直接交换信息”写成可审计的拓扑约束，同时通过共享参数避免自由16×16矩阵的至少256个实边权；若使用无约束复矩阵则是512个实自由度，并带来更高的过拟合与归因风险。

> **论文批注｜[3] Kipf & Welling, GCN（ICLR 2017）**：为“根据图邻接聚合局部节点特征”提供通用方法依据。V2.15 选择 graph 的直接原因仍是本项目 V2.14 的残差证据，而不是从通用图任务直接迁移结论。

### 8.2 为什么普通3×3卷积还不够

V2.12 的3×3卷积已经具有局部感受野，但它把4×4孔径当作规则图像，只能通过卷积核位置间接学习上下、左右和非局部 S 邻接的区别。V2.15 将三种传播显式拆开：

\[
A_rH,\qquad A_cH,\qquad A_sH.
\]

这样做的目的不是单纯增加容量，而是让“垂直几何关系、水平几何关系、候选互耦关系”成为可以分别关闭和反事实替换的模块。`graph_geometry / graph_s_true / graph_s_shuffled` 三臂正是由此产生。

不过，V2.15 graph 比 control 仍多 `4.126%` 参数，因此当前只能说“完整图结构优于 V2.12 结构族”，还不能严格排除全部容量解释；这也是后续需要 capacity-matched CNN 的原因。

### 8.3 引入方向 gate 的物理理由

固定邻接 \(A\) 只说明阵元之间存在关系，却不能说明该关系在某个观察方向上应有多大影响。对于阵元位移 \(\Delta r_{ij}=r_j-r_i\)，解析相位差为

\[
\Delta\varphi_{ij}(q)=kq^T\Delta r_{ij}.
\]

若阵列的两个主轴位移分别近似为 \(d\hat x\) 与 \(d\hat y\)，则

\[
\Delta\varphi_x(q)=kdq_x,
\qquad
\Delta\varphi_y(q)=kdq_y.
\]

扫描方向变化时，行向和列向阵元之间的相干关系会以不同方式变化；固定的

\[
M= A_rH+A_cH+A_sH
\]

无法表达这种角域各向异性。因此 V2.15 使用

\[
M(q)=
\gamma_r(q)A_rH+
\gamma_c(q)A_cH+
\gamma_s(q)A_sH,
\]

让方向编码决定三种传播的有符号强度。使用 tanh 而不是 softmax，是因为复 envelope 的残差修正可能需要抑制或反向补偿某一传播分量，而不是只能做非负凸组合。

> **论文批注｜[4] Perez et al., FiLM（AAAI 2018）**：为“条件变量控制中间网络运算”提供参考。V2.15 把条件从 FiLM 原文中的任务/问题表示替换成物理方向 \(q\)，并把调制对象换成三个固定图算子。

### 8.4 当时形成的完整假设链

| 决策阶段 | 已有证据 | 导出的结构选择 |
|---|---|---|
| V2.14 残差阶梯 | 邻接和 `abs(S)` 相关较高 | 保留局部/耦合拓扑先验 |
| V2.14 失败模块 | 低阶 S、多类分支、低秩外推均不足 | 使用非线性局部消息，不使用固定低阶公式 |
| 物理安全边界 | 自由16×16矩阵难解释且易过拟合 | 固定稀疏图+共享投影 |
| 扫描物理 | \(q^T\Delta r\) 决定方向相关相位差 | 用方向 gate 分配行/列/S消息 |
| 稳定训练 | 新分支不应初始破坏物理骨架 | zero-start IQ head |
| 机理验证 | S 图的价值不能只看最终精度 | geometry/true-S/shuffled-S 反事实 |

对应的事前假设已冻结在 [V2.15 预注册](V2.15_PREREGISTRATION.md)，其前序数据依据见 [V2.14 物理残差阶梯](../v2.14/V2.14_PHYSICS_ATTRIBUTION_RESULTS_20260913.md)。

### 8.5 结果对原动机的反证与保留

V2.15 结果表明，validation 总改善 `1.433 dB` 中约 `90.5%` 已由 `graph_geometry` 取得，而 true-S 相对 shuffled-S 仅改善 `0.043 dB`。因此原假设被拆成两部分：

- **得到支持**：显式局部阵元消息传递是有效归纳偏置；
- **未得到支持**：当前静态 `|S|` top-4 图提供了不可替代的真实互耦拓扑；
- **尚未单独验证**：方向 gate 本身优于固定等权图。V2.15 没有设置 `ungated-graph` 对照，因此 graph 与 gate 的贡献仍部分绑定。

下一步若要确认 gate 的独立价值，应在新版本中加入严格等参数的

\[
\text{fixed-gate},\quad
\text{direction-gate},\quad
\text{direction-shuffled-gate}
\]

三组对照；旧 V2.15 external test 已开启，不能再用于这项结构选择。

## 9. 哪些结论可以由结构对照支持

V2.15 的同数据、同种子、同训练预算比较表明 graph 模型相对 control 在 validation、coverage_probe 和 external test 上均为3/3正向，最终 test 平均改善 `1.334 dB`。但解释时必须区分：

1. `graph_s_true > control` 支持“完整图结构比 V2.12 结构族更好”；
2. `graph_geometry` 已取得绝大多数提升，支持行/列局部消息是主要有效部分；
3. `graph_s_true - graph_s_shuffled = 0.043 dB` 未通过机理门槛，不能说网络识别了真实 S 拓扑；
4. graph 与 control 参数仍差 `4.126%`，因此尚未完成“严格等容量普通 CNN”反事实；
5. V2.15 control 使用的是 V2.12 **结构**，但在 V2.14 exchange 数据上重新从头训练；历史 V2.12 checkpoint 与 V2.15 graph 的差异不能被纯粹归因于结构。真正的结构证据来自 V2.15 内四臂配对实验。

## 10. 实现边界与容易误解之处

- 当前第三图只使用 \(|S_{ij}|\)，没有使用 S 参数相位，也没有复数 edge kernel。
- `graph_s_shuffled` 是单个固定节点置换，不等价于对随机图分布的完整统计。
- 图邻接是固定 buffer；唯一可学习的图相关层是27→3 gate 和共享32→32的1×1 projection。
- 三个 gate 是 signed tanh 系数，不是归一化 attention 权重。
- 输出 tanh 对实部和虚部分量分别限幅到 `(-2,2)`；它不等价于把复数模长严格限制为2。
- 4×4空间卷积的 padding 会包含边界效应；显式 row/column 图的度归一化也使边缘与内部节点不同。
- 模型没有 BatchNorm、LayerNorm、pooling、dropout、全连接幅度头或自由16×16耦合矩阵。
- CPU forward 延迟和参数量只描述当前主机软件实现，不是 FPGA、OTA 或硬件 Gate-B 证明。
