# V2.15 完整训练与无泄漏测试结果（2026-09-13）

## 最终状态

V2.15 已完成四臂、三种子、每臂 240 epochs 的从头训练以及一次性 external test。预注册主候选 `graph_s_true` 状态为 `v215_candidate_qualified`。test 已打开并冻结，禁止继续在 V2.15 内依据 test 调参；后续结构变化必须建立新版本。

## 结构与预算

control 保留 V2.12 的解析几何相位、逐阵元复增益、`L=4` SSH 和 width=24/depth=2 普通 3×3 residual CNN。新网络使用 width=32 的 stem、一个普通 residual block、一个方向条件化图块和 zero-start IQ head；图块分别传播行邻接、列邻接与稀疏 S 图消息。

- control：28789 参数；graph 三臂：29977 参数，完全匹配；增量 `4.126%`。
- control/主候选 CPU forward 中位延迟约 `20.61/20.91 us/方向`，差约 `1.46%`；该数字只代表当前主机批量正向，不是 FPGA 延迟。
- 12 个 run 总训练时间约 `64.43 min`；全部从随机初始化训练，最佳 checkpoint 只由 validation 线性 NMSE 决定。

## validation 与 coverage_probe

| 结构 | validation NMSE，mean±sd | coverage_probe NMSE，mean±sd |
|---|---:|---:|
| control | `-25.994 ± 0.249 dB` | `-26.109 ± 0.230 dB` |
| graph_geometry | `-27.291 ± 0.329 dB` | `-27.376 ± 0.324 dB` |
| graph_s_true | `-27.427 ± 0.245 dB` | `-27.497 ± 0.247 dB` |
| graph_s_shuffled | `-27.384 ± 0.394 dB` | `-27.482 ± 0.383 dB` |

主候选相对 control：validation 平均改善 `1.433 ± 0.056 dB`，coverage_probe 平均改善 `1.388 ± 0.109 dB`，两者均为 3/3 正向。复算子 diagnostic NMSE 均值由 `-20.063 dB` 改善至 `-21.205 dB`，约 `1.142 dB`。

但 true-S 相对 shuffled-S 在 validation 只改善 `0.043 ± 0.162 dB`，虽然 2/3 正向，却未达到预注册 `0.10 dB`。因此：

- “方向条件化局部图 CNN 提高预测性能”成立；
- “提升由真实 S 参数拓扑带来”不成立；
- 不能把性能提升解释成已经学会了可识别的真实互耦。

## 一次性 external test

test 仅在 12 个训练、forward audit、结构固定和 checkpoint 冻结后，由独立程序读取。只评估预先声明的 control 与 `graph_s_true`。

| seed | control NMSE | graph_s_true NMSE | 改善 |
|---:|---:|---:|---:|
| 21501 | `-23.101 dB` | `-23.640 dB` | `+0.539 dB` |
| 21502 | `-23.009 dB` | `-24.823 dB` | `+1.813 dB` |
| 21503 | `-22.948 dB` | `-24.598 dB` | `+1.650 dB` |

平均 test 改善 `1.334 ± 0.694 dB`，3/3 正向，超过 `0.30 dB` 预注册门槛；平均 NMSE 从 `-23.019 dB` 提升至 `-24.354 dB`，平均 MAE 从 `0.905 dB` 降至 `0.719 dB`。

三种子的 Student-t 95% 区间为 `[-0.389, 3.057] dB`，仍跨零。因此本结论是“达到预注册工程门槛且方向一致”，不是大样本统计显著性证明。

按场强分层，`-20~-10 dB` 和 `<-20 dB` 区域平均改善约 `1.89/2.04 dB`，`-10~-3 dB` 改善约 `1.24 dB`；最强 `-3~0 dB` 区域平均变化 `-0.32 dB` 且种子不一致。新结构的主要收益来自中弱场预测，强主瓣仍需单独约束。

## 无泄漏证据与结论边界

- 训练程序只接收 `train_exchange.npz` 与 `validation.npz`，没有完整数据集参数；两包不含 test 字段、复场或 test 索引。
- coverage_probe 未参与训练或 checkpoint 选择；所有 checkpoint 均记录 `test_split_opened=False`。
- `TEST_OPENING_RECORD.json` 在读取 test 前记录预注册候选、评估臂和 forward-summary fingerprint。
- test 只读取 4900 个 test 方向和 16 个 test commands，未用于再次选模型。
- 完成全量回归：V2.12 `31/31`、V2.13 `19/19`、V2.14 `16/16`、V2.15 `7/7`，全部通过。

V2.15 证明该图 CNN 在当前 HFSS Ephi 幅度分布上具有稳定预测收益；不证明 S 参数的因果贡献，也不代表真实硬件、OTA 或 FPGA 部署通过。Gate-B 仍需真实、非相同的硬件重复。
