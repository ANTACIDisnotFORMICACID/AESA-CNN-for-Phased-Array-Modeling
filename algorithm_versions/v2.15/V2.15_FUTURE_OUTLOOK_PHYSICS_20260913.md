# V2.15 后续展望：从有效图归纳偏置到可验证电磁算子

日期：2026-09-13。本文是基于 V2.15 已冻结结果形成的 **post-hoc 研究展望**，不是新的预注册，也不改变 V2.15 的资格结论。V2.15 external test 已经开启；本文不得被用来继续调整 V2.15，且该 test 不再具备验证 V2.16 新假设的独立性。

## 1. 当前证据究竟缩小了什么问题

V2.15 在 validation、coverage_probe 和一次性 external test 上均稳定优于 V2.12 control，主候选的平均改善分别为 `1.433/1.388/1.334 dB`，均为 3/3 种子正向。这足以支持“方向条件化局部图 CNN 是有价值的预测结构”。但是，validation 上

\[
\begin{aligned}
\Delta_{\mathrm{geometry}}
&=(-25.994)-(-27.291)=1.297\ \mathrm{dB},\\
\Delta_{\mathrm{trueS|geometry}}
&=(-27.291)-(-27.427)=0.136\ \mathrm{dB}.
\end{aligned}
\]

因此，总改善 `1.433 dB` 中约

\[
\frac{1.297}{1.433}\approx90.5\%
\]

已经由行/列几何图取得。coverage_probe 上相应分解为 `1.267+0.121 dB`，几何部分约占 `91.3%`。真实 S 图相对 shuffled-S 又只有 `0.043±0.162 dB`，未达到预注册机理门槛。

当前严格结论是：

1. 方向条件化的局部阵元消息传递有效；
2. 当前“静态 `|Sij|`、top-4、对称归一化”的第三图没有表现出可识别的真实拓扑价值；
3. 还没有证明图归纳偏置优于 **严格等容量** 的普通 CNN，因为 control 与图网络仍有 `4.126%` 参数差；
4. 不能由 shuffled-S 结果推出“S 参数或互耦无用”，只能否定当前 S 参数注入方式的附加解释力。

## 2. V2.15 正向模型的物理对象

令观察方向为 \(q\in\mathbb S^2\)，第 \(n\) 个阵元位置为 \(r_n\)，复端口算子为 \(g_n(q)\)。V2.12/V2.15 保留解析传播相位，把算子写成

\[
g_n(q)=a_n(q)\exp\!\left(jkq^Tr_n\right),
\]

其中 \(a_n(q)\) 是去相位后的复 envelope，由逐阵元基准、SSH 项和 CNN 残差共同给出。对复命令 \(w\in\mathbb C^{16}\)，预测为

\[
E(q,w)=\sum_{n=1}^{16}g_n(q)w_n=g(q)^T w,
\qquad y(q,w)=|E(q,w)|.
\]

幅度监督只能直接约束

\[
y^2=w^H Q(q)w,
\qquad Q(q)=g(q)^*g(q)^T.
\]

任意公共方向相位 \(g(q)\mapsto e^{j\psi(q)}g(q)\) 都不会改变 \(Q\) 和幅度。因此，有限命令集下学习的是一个具有 gauge 不唯一性的相干算子；内部某条图边是否代表真实互耦，并不能仅由最终幅度改善自动识别。这也是继续使用 gauge-invariant 的 \(Q\) 诊断、而不把内部特征直接当作物理量的原因。

## 3. 为什么纯几何图可能已经有效

当前图块在普通 3×3 residual block 后，对隐藏孔径特征 \(h(q)\) 计算

\[
m(q)=\gamma_r(q)A_rh(q)
+\gamma_c(q)A_ch(q)
+\gamma_s(q)A_sh(q),
\]

其中三个有符号 gate 由方向 Fourier 编码产生，\(A_r,A_c\) 是规则阵列行/列邻接，\(A_s\) 是可选 S 图。消息经 1×1 通道投影后再进入 zero-start IQ head。

对规则阵列内部节点，设阵元间距为 \(d\)。一维对称邻域平均满足 Taylor 展开

\[
\frac{h(x+d)+h(x-d)}{2}
=h(x)+\frac{d^2}{2}\frac{\partial^2 h}{\partial x^2}
+\mathcal O(d^4).
\]

二维行/列图的组合于是近似

\[
m(q)\approx
(\gamma_r+\gamma_c)h
+\frac{d^2}{2}
\left(
\gamma_r(q)\partial_{rr}h+
\gamma_c(q)\partial_{cc}h
\right).
\]

忽略边界度数归一化的修正后，它本质上是一个由观察方向控制的 **各向异性孔径差分/平滑算子**。这与规则 4×4 阵列的空间组织天然匹配，即使边并不等于真实电磁耦合，也能比普通卷积更有效地表达“扫描方向改变水平与垂直孔径关联”的规律。这是解释

\[
\mathrm{geometry}\approx\mathrm{trueS}\approx\mathrm{shuffledS}
\]

的首要待验证假设，而不是已经确认的机理。

## 4. 先做冻结 checkpoint 机理审计

在重新训练前，应只用现有 checkpoint 对 validation 与 coverage_probe 做探索性审计；不得再次读取 test，也不得改变 V2.15 选择结果。

### 4.1 分支干预

推理时分别关闭 row、column、third-graph 消息，记录

\[
\Delta\mathcal E_r,\quad
\Delta\mathcal E_c,\quad
\Delta\mathcal E_s.
\]

由于三个分支在后续非线性层中相互作用，单分支退化量不可假设可加。应执行完整 \(2^3\) 开关组合，并用 factorial effect 或三分支 Shapley value 区分主效应和交互效应。指标至少包括 amplitude NMSE、\(Q\)-NMSE、场强分区误差和逐方向 P95。

### 4.2 gate 的方向规律

保存

\[
\gamma_r(q),\quad\gamma_c(q),\quad\gamma_s(q)\in[-1,1],
\]

并与真实阵元位移方向 \(\Delta r_{ij}\) 构造的

\[
u_{ij}(q)=q^T\frac{\Delta r_{ij}}{\|\Delta r_{ij}\|}
\]

比较，而不是先验假定某个 gate 必然对应 \(q_x\) 或 \(q_y\)。建议统计 Spearman、低阶 SSH 回归 \(R^2\)、角域热图、均值/方差和饱和比例。若较差 seed 出现某分支长期接近零或单分支占优，应进一步检查初始化到 gate 塌缩再到性能的链条。

### 4.3 审计性质

这轮审计只能形成机理假设。因为 V2.15 test 结果已经被观察，它不能成为新的确认性证据；任何由本审计启发的结构必须在 V2.16 使用新的冻结 holdout 验证。

## 5. V2.16：严格拆解图归纳偏置

V2.16 应保持 SSH/Fourier、训练方向、命令、优化器和更新预算不变，优先比较：

| 模型 | 需要回答的问题 |
|---|---|
| `C0-capacity` | 与图模型严格匹配参数量和感受野的普通 CNN，排除容量解释 |
| `G-geometry` | 行/列局部拓扑是否稳定有效 |
| `G-random-k` | 多个固定随机图是否也能取得相同收益 |
| `G-distance` | 连续距离核是否优于二值行/列邻接 |
| `G-Scomplex` | 复数 S 边特征是否提供真实增量 |
| `G-learned` | 几何初始化、稀疏受约束的可学习边是否有效 |

`C0-capacity` 与图模型的参数差应压至 `<0.5%`，最好完全相同。随机图不能只使用一个置换；应在预注册中固定多个图种子，将“训练随机种子”和“图拓扑随机种子”作为两层变异来源。核心比较变为

\[
\boxed{
\text{graph inductive bias}
>\text{严格等容量普通 CNN}
}
\]

以及

\[
\boxed{
\text{geometry/complex-S graph}
>\text{同稀疏度随机图分布}
}.
\]

建议最终采用至少 5–10 个 paired training seeds；若预算允许，固定 8 个。统计以 seed 级配对改善为主，并补充按 10° 空间块的 block bootstrap，不能把高度相关的“方向×命令”样本错误地当作独立样本扩大显著性。

## 6. S 参数需要从 adjacency 升级为复数网络物理

当前 \(A_s\) 仅由 \(|S_{ij}|\) 的 top-4 边构成，丢弃了 \(\angle S_{ij}\)。可将边特征改为

\[
e_{ij}=
\left[
\Re S_{ij},\Im S_{ij},
\|r_i-r_j\|,
\Delta x_{ij},\Delta y_{ij}
\right],
\]

并令消息为

\[
m_i(q)=\sum_{j\in\mathcal N(i)}K_\theta(q,e_{ij})h_j.
\]

若 \(h_j\) 含 IQ 对，复数核应显式保持复乘法结构：

\[
K_{ij}=
\begin{bmatrix}
a_{ij}&-b_{ij}\\
b_{ij}&a_{ij}
\end{bmatrix}
\Longleftrightarrow
(a_{ij}+jb_{ij})h_j.
\]

这比让普通实值通道自行学习复旋转更可解释。还应约束互易性、稀疏性和谱范数，避免退化为自由 16×16 矩阵。

但必须区分 S 参数与辐射基函数。以共同实参考阻抗 \(Z_0\) 的功率波约定为例，端口入射/反射波满足

\[
b=Sa,
\]

从而

\[
v=\sqrt{Z_0}(a+b)=\sqrt{Z_0}(I+S)a,
\qquad
i=\frac{a-b}{\sqrt{Z_0}}=rac{(I-S)a}{\sqrt{Z_0}},
\]

并得到

\[
Z=Z_0(I+S)(I-S)^{-1}.
\]

因此 S 矩阵主要描述端口网络关系；它不是无需约定即可直接左乘远场的“互耦真值”。若命令 \(w\) 表示源电压而 EEP 按单位入射波导出，就必须先完成源阻抗和波变量换算。反之，如果 EEP 已在同一端口归一化和终端条件下导出，再额外施加一个 S mixing 可能造成互耦重复计入。

## 7. EEP 应成为物理审计主线

IEEE 的经典 AEP 工作给出了利用 active-element pattern 预测相控阵扫描性能并从散射参数关系推导该概念的框架；近期工作也直接学习含 mutual-coupling 效应的 embedded element pattern。对本项目更关键的是：现有 HFSS 导出脚本调用 `get_antenna_ffd_solution_data(...).eep_files`，V2.14 又把16个单端口 FFD 作为复场基底并通过 Gate-A 组合场抽查。这说明现有 FFD **已经是 EEP 数据路径**，不是未来才需要新增的一类标签。

在 HFSS 所用线性端口约定下，令

\[
F^{\mathrm{EEP}}(q)=
\begin{bmatrix}
E^{\mathrm{EEP}}_1(q)&\cdots&E^{\mathrm{EEP}}_{16}(q)
\end{bmatrix},
\]

则组合场应满足

\[
E(q,a)=F^{\mathrm{EEP}}(q)a.
\]

下一步不是简单“再导一份 EEP”，而是完成以下合同审计：

1. 明确每个 FFD 的单位激励变量、幅相归一化和未激励端口终端条件；
2. 确认训练命令 \(w\) 与 HFSS 入射波 \(a\) 是否同义；
3. 在更多 train/validation 命令上复核 EEP 线性叠加，不使用旧 test；
4. 比较 CNN 学到的 \(Q(q)\) 与 EEP 构造的 \(Q_{\mathrm{EEP}}(q)\)；
5. 判断 CNN 的实际任务究竟是学习额外互耦算子，还是插值 EEP envelope 的方向依赖。

若 EEP 叠加已经解释 HFSS 组合场，则 V2.15 的合理物理解读是：图块帮助学习阵元 EEP 在孔径上的相关角域变化；静态 S 图只是增加了一个局部混合通道。这个解释目前与结果一致，但仍须由上述合同和冻结审计验证。

## 8. 强场退化为何需要单独处理

令预测复场误差为 \(\delta E\)，\(E=|E|e^{j\phi}\)。幅度的一阶扰动为

\[
\delta |E|
\approx
\frac{\Re(E^*\delta E)}{|E|}
=\Re(e^{-j\phi}\delta E).
\]

相对幅度误差则近似

\[
\frac{\delta|E|}{|E|}
\approx
\frac{\Re(e^{-j\phi}\delta E)}{|E|}.
\]

在旁瓣和零陷附近，\(|E|\) 很小，微小的阵元相位/幅度误差会因相消而被放大；局部图改善相关 envelope，因而优先改善弱场是物理上合理的。V2.15 test 中 `<-20 dB`、`-20~-10 dB`、`-10~-3 dB` 分别改善约 `2.04/1.89/1.24 dB`，而 `-3~0 dB` 平均变化 `-0.32 dB` 且种子不一致。不过，仅凭分区结果还不能判定强场退化来自系统性低估还是方差增大。

应先在 validation/coverage_probe 分解强场误差：

\[
\mathrm{MSE}=\mathrm{Bias}^2+\mathrm{Variance}+\text{不可约项},
\]

并查看复场径向误差 \(\Re(e^{-j\phi}\delta E)\) 与切向相位误差。若是统一低估，可做受限 calibration；若是方差或分支竞争，应调整融合与正则，而不是简单增大主瓣 loss。

后续目标更适合写成约束优化：

\[
\min_\theta\ \mathcal L_{\mathrm{global}}(\theta)
\quad\text{s.t.}\quad
\Delta_{\mathrm{strong}}\ge -0.05\ \mathrm{dB},
\qquad
\Delta_{\mathrm{weak}}>1.0\ \mathrm{dB}.
\]

也可在训练阶段使用仅由 train 定义分区的 Lagrangian

\[
\mathcal L=
\mathcal L_{\mathrm{global}}+
\lambda_{\mathrm{strong}}
\max\left(0,
\mathcal L_{\mathrm{strong}}-\tau_{\mathrm{strong}}
\right),
\]

但 \(\lambda\)、阈值和选择规则必须在新的 confirmatory holdout 开启前冻结。

## 9. 从 forward NMSE 转向波束形成任务指标

最终任务不是单独拟合每个方向，而是利用预测器求解多点最弱增益：

\[
w_{\mathrm{CNN}}^*
=\arg\max_{w\in\mathcal W}
\min_{k=1,\ldots,K}\hat y(q_k,w).
\]

真正的下游误差应在独立 HFSS/EEP 参考上计算

\[
\Delta G_{\min}
=
\min_k y_{\mathrm{HFSS}}(q_k,w_{\mathrm{CNN}}^*)
-
\min_k y_{\mathrm{HFSS}}(q_k,w_{\mathrm{HFSS}}^*).
\]

还应记录最优命令 regret、最弱点身份是否改变、可行率和运行时。一个模型即使只改善 `0.3 dB` forward NMSE，只要显著降低 \(\Delta G_{\min}\) 的绝对值，对课题的价值也可能高于继续追求平均 NMSE。

## 10. 推荐路线与决策门

### V2.15-F：冻结解释性审计

- 仅 validation/coverage_probe；不训练、不读取 test；
- 完成三图分支 \(2^3\) 干预、gate 角域图、seed 稳定性和 EEP 端口合同核对；
- 输出探索性机理假设，不产生新模型资格。

### V2.16：Graph Mechanism Isolation

- 严格等容量 control；
- geometry、多个 random/shuffled、distance、complex-S、受约束 learned graph；
- 5–10 个 paired seeds，seed 统计为主、空间块 bootstrap 为辅；
- 使用新的冻结 confirmatory holdout，旧 V2.15 test 只作为历史结果。

### V2.17：Physics-Structured Coupling

- 明确 `S/Z -> 端口波/电流 -> EEP -> 复远场` 的归一化链；
- 用 Etheta/Ephi 全矢量和复 \(Q\) 作 audit-only 物理约束；
- 只有 complex-S/EEP 模型稳定胜过拓扑反事实，才声称真实互耦贡献。

### V2.18：Beamforming-Oriented Objective

- 冻结 forward predictor 后评价多点 max-min 优化；
- 以 \(\Delta G_{\min}\)、regret 和最弱点稳定性作为主要指标；
- 最后再进入真实硬件 Gate-B，不能把 HFSS、host latency 或软件回归当作 OTA/FPGA 证明。

## 11. 当前优先级

1. **严格等容量 control + 多随机图**：确认收益来自规则阵列图归纳偏置，而不是容量或任意混合通道；
2. **冻结 checkpoint 的 row/column/third gate 审计**：解释局部图为什么有效及 seed 21501 为何收益较弱；
3. **把现有 FFD 明确纳入 EEP 合同，随后测试 complex-S 边核**：先避免互耦重复计入，再判断 S 的复相位和端口网络是否提供独立价值；
4. **约束强场不退化并加入下游 max-min regret**：把预测精度提升转化为真正的波束优化收益。

这一路线的目标不是立即把 CNN 变得更深，而是把已验证有效的局部图归纳偏置逐步变成可干预、可反事实检验、并与端口网络和 EEP 一致的电磁算子。
