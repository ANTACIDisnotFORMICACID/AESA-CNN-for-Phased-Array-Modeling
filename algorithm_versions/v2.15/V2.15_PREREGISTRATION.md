# V2.15 完整 CNN 结构与无泄漏测试预注册

日期：2026-09-13。V2.15 是新版本，不修改 V2.12–V2.14 的代码、数据和结论。

## 目标与固定假设

V2.14 已确认：补齐角域覆盖有效；残差与阵元邻接、`|Sij|` 显著相关，但静态两系数 S 多项式、全局低秩、阵元类别和简单 branch fusion 均未通过。V2.15 因此只检验一个预先指定的结构假设：

> 在去除解析几何相位后的复 envelope 内，使用方向条件化、局部且受 S 参数约束的阵元消息传递，可比普通 3×3 CNN 更好地预测未见方向/命令幅度。

禁止自由 16×16 矩阵、逐方向查表、增加可学习相位中心，以及根据 test 选择结构。

## 数据与泄漏隔离

- 训练采用 V2.14 已通过的 exchange 配置：固定移除 490 个原 train 方向，加入 490 个整数网格 acquisition，总数保持 22600。
- `train_exchange.npz` 只含 64 个 train commands；`validation.npz` 只含原 4900 个 validation 方向和 16 个 validation commands。
- 4380 个 coverage_probe 只在训练结束后的 forward audit 使用，不参与 checkpoint 或结构选择。
- 数据准备与训练输出均不包含 test 方向、命令或幅度。训练程序不接受完整数据集路径。
- 所有结构、种子、超参数和主候选在 test 开封前写入机器配置；最终程序只评估预注册的 control 与 `graph_s_true`，且不得反向修改 V2.15。

## 完整结构

共同骨架保留 V2.12 的解析相位、逐阵元复基准增益、`L=4` filtration SSH 和 Fourier 方向编码。control 保持原 width=24、depth=2 的普通 3×3 residual CNN。

新 residual CNN 用 width=32：stem 3×3、一个普通 residual block、一个方向条件化图残差块、zero-start 3×3 IQ head。图块包含行邻接、列邻接和第三个耦合图；三个方向 gate 由 27 维 Fourier 方向编码产生。S 图去除对角线，每行保留最强四个耦合并对称归一化。

完整训练四臂：

- `control`：冻结 V2.12 结构；
- `graph_geometry`：第三图为零，仅行/列邻接；
- `graph_s_true`：第三图为真实 47 GHz `|Sij|`；这是 test 前预先指定的唯一新候选；
- `graph_s_shuffled`：节点置换后的 S 图，保持权重分布和参数量，用作机理反事实。

三个 graph 臂参数量必须完全一致；相对 control 参数量差不超过 5%。所有输出 head 零初始化，graph 三臂同随机种子在初始化时必须严格等价。

## 训练、选择和评估

- 种子固定：21501、21502、21503；全部从头训练，不载入 V2.12 权重。
- 每臂 240 epochs，AdamW，batch 512，LR `1e-3`，第 181 epoch 降至 `3e-4`。
- 使用 `lambda_separation=0.001`，固定 train-only 分层方向；损失只读取幅度标签。
- 每个 checkpoint 只按旧 validation 的线性 NMSE 选取。
- 训练后对 validation、coverage_probe、复算子诊断、参数量、有限数和正向延迟作统一 forward audit。

test 开封 gate 只检查协议完整性：12 个训练均完成且有限、主候选已预注册、训练包无 test、checkpoint 标记 test 未开、forward audit 完成。它不根据性能更换候选。

## 判定门槛

结构机理 gate：

- `graph_s_true` 相对 control 的 validation 平均改善至少 0.30 dB，3/3 正向；
- `graph_s_true` 相对 shuffled-S 平均改善至少 0.10 dB，至少 2/3 正向；
- coverage_probe 相对 control 平均改善至少 0.30 dB，3/3 正向；
- 参数差不超过 5%，全部预测有限且非负。

最终 test qualification：

- `graph_s_true` 相对 control 的 test NMSE 平均改善至少 0.30 dB，3/3 正向；
- test 的任何命令/方向/幅度均未用于训练、checkpoint 选择或结构选择；
- 若失败，结果仍完整归档，但不得继续在 V2.15 上针对 test 调参。

所有结论限于当前 HFSS Ephi 幅度和仿真分布；不替代 Gate-B 硬件验证。
