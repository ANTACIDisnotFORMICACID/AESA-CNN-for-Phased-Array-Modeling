# V2.12 冻结计划

## 物理目标与边界

V2.12 从单极化幅度学习自由空间阵列算子：

\[
a(q)\rightarrow g(q)=D_r(q)a(q)\rightarrow
Q(q)=g^*(q)g^T(q)\rightarrow
\hat y(q,w)=\sqrt{w^HQ(q)w}.
\]

当前 observation 是 HFSS `E_phi`，环境算子固定为 identity。未来实测只有在
探头和环境均完成复数校准后才允许标记 `free_space_operator`；否则只能标记为
`environment_effective`。V2.12 不同时辨识接收探头、环境和自由空间天线。

本版本不引入 Spherical CNN、Transformer、GNN 或 SFNO；无暗室多径校准不在
主训练范围内。MEAP 路线需要参考天线先校准多径测量矩阵。

## Stage 1：Filtration SSH 编码

在训练 loss 对应的离散测度 `W` 下，逐阶构造：

\[
P_{<l}=\Phi_{<l}\Phi_{<l}^{H}W,\qquad
R_l=(I-P_{<l})\Psi_l,
\]

\[
W^{1/2}R_l=U_l\Sigma_lV_l^H,\qquad
\Phi_l=R_lV_{l,r}\Sigma_{l,r}^{-1}.
\]

丢弃满足 `sigma_i^2 < 1e-4 sigma_max^2` 的模式。该基保持的是可稳定辨识的
filtration prefix span，而不是正交化后的纯 `l` 阶函数。训练经验测度与物理
实体角测度 `W_Omega` 分开保存和使用。

冻结消融矩阵为：`E0`、`E0-M4`、`E0-M5`、`E-S4`、`E1-R4`、
`E2-F4`、`E2-F5`、`E3-I`。所有编码仍输出 27 维；E0-M 与对应 E2 使用相同
实际保留秩、投影参数量和门控数量。E2 的 `alpha_l=0`，因此初态严格等于 E0。
E3 只解释为 input feature-space residualization。

每项使用 10 个配对种子，只以 validation 选择模型。报告 paired bootstrap
95% CI、双侧 sign-flip permutation、胜率和 Holm 校正，并在四个相对场强区间
报告 linear NMSE、dB MAE、bias 与 P95。E2 必须同时优于 E0 和等容量 Fourier
对照，且主瓣 MAE 平均恶化不超过 0.05 dB。E2-F5 对 E2-F4 改善不足 0.2 dB
时采用 L4。

## Stage 2：相干 rank-1 operator

冻结 96 条单位二范数命令：16 singles、24 条最近邻边的 0/90 度 pair 命令
共 48 条，以及 32 条固定种子恒模命令。train/validation/test 命令数固定为
64/16/16，训练 pair 图连通。归一化 pair 的恢复约定为：

\[
\Re Q_{ij}=p_{ij}^{(0)}-(p_i+p_j)/2,
\quad
\Im Q_{ij}=(p_i+p_j)/2-p_{ij}^{(90)}.
\]

非学习审计先以 singles/pairs 做图相位同步初始化，再分别拟合 rank-1 与 rank-2
PSD 因子，并在 held-out commands 上比较。Jacobian 删除一个由最大幅度阵元
确定的 `U(1)` 零空间坐标，同时报告最小非零奇异值、条件数和三次重复测量的
不确定度。

- `G0`：同环境 V2.10 amplitude baseline。
- `G1`：`a_n=s_a(b_n+Delta a_F,n)`。
- `G2`：`a_n=s_a(b_n+a_SSH,n+Delta a_F,n)`，其中 SSH 仅使用 `l>=1`。
- `G3`：架构同 G2，只增加 train-command-only 的 lifted-Q supervision。

`s_a` 是只由 `q_train` 上 16 条 single-element command 幅度中位数得到的固定
正实单位尺度，不使用 validation/test。这样 `b_n(0)=1` 仍表示无量纲单位阵元
基线，同时避免让 SSH 或受限 residual 分支承担 HFSS 数据的绝对量纲缩放。

G2 的 SSH 门控与 Fourier residual head 均零初始化，因此初态严格等于 G1。
模型不包含显式 coupling matrix；有效互耦、馈线和安装效应可被 `g` 吸收，但
不得解释为独立 RF calibration。方向相关 gauge 会改变 latent complex `a` 的
SSH 频谱，因此 V2.12 删除对 latent SSH coefficient 的按阶谱正则。

`a(q)` 不从分析中删除，而是明确定位为去传播相位后的 latent representation：
它用于解释网络结构、分支分工与需要学习的包络复杂度，但不被宣称为幅度数据唯一
恢复出的真实复场。关于“数据实际支持了什么”的核心结论必须放在 gauge-invariant
的 `Q_tilde=a* a^T` 上。即：

\[
a:\ \text{latent representation},\qquad
\widetilde Q:\ \text{identifiable physical operator}.
\]

训练只使用 `q_train x w_train`。最终必须分开报告 A（seen/seen）、B
（seen/unseen）、C（unseen/seen）和 D（unseen/unseen），主结果为 D。

## Gauge-invariant 审计与诊断实验

主要物理审计量为：

\[
\widetilde Q=D_rQD_r^H=a^*a^T.
\]

用 `W_Omega` 和 raw SSH L12 报告 L4/L5/L10 累计能量、逐阶矩阵 Frobenius
能量与归一化球面梯度能量。第一版只报告，不进入 loss。Fourier residual 的
低阶泄漏同样只作 decomposition diagnostic。

G3 的 `Q_hat` 只能由每个训练方向的 64 条训练命令得到，工件必须保存 query
和 command 索引，加载时严格比对。`lambda_Q` 只在 validation D 中从
0.01/0.1/1 选择；G3 不替换 G2 主模型。

O1 固定 singles 与 pairs，只优化 32 条恒模命令。5 个固定初值、每个 2000
步、Adam 1e-2，并按 validation 的最小非零 Jacobian 奇异值 P05、随后平均
log-det 选取。只有同时达到条件数与噪声反演改善门槛，才建议未来测量采用。

Slepian/HSH 仅保留为半球数值基诊断，不替换 filtration SSH 的标准球面谱
解释。
