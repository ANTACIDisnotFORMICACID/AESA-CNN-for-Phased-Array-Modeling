# V2.12 最终结果分析与下一步展望（2026-09-12）

## 1. V2.12 回答了什么问题

V2.12 的起点不是简单替换方向编码，而是将 amplitude-only 正向预测写成：

\[
a(q)
\rightarrow
g(q)=D_r(q)a(q)
\rightarrow
Q(q)=g^*(q)g^T(q)
\rightarrow
\hat y(q,w)=\sqrt{w^HQ(q)w}.
\]

其中 `a(q)` 是网络学习的去传播相位 latent representation；`D_r(q)` 是解析阵列传播；`Q(q)` 是单频、相干、标量、LTI 测量合同下的 rank-1 operator；幅度是最终监督量。关于真实数据支持了什么的物理结论，不建立在不可唯一辨识的复 `a(q)` 上，而建立在：

\[
\widetilde Q(q)=D_r(q)Q(q)D_r^H(q)=a^*(q)a^T(q)
\]

及幅度预测上。

围绕 SSH，V2.12 实际检验了三个不同命题：

1. SSH 是否比相同参数量的 Fourier 扩展更有预测价值；
2. SSH 与 Fourier 是否能形成稳定且可解释的内部功能分工；
3. 这种分工是否使可辨识物理 operator 的全局平滑性更接近 HFSS truth。

将三个命题分开，是 V2.12 最重要的方法论结果。

## 2. 冻结实验结论

### 2.1 SSH 的预测价值成立

软分离候选相对等参数 G1-M5：

- validation-D NMSE 平均改善 0.640 dB；
- paired bootstrap 95% CI 为 [0.358, 0.977] dB；
- 10/10 种子获胜；
- Holm 校正 `p=0.00390625`；
- 主瓣 MAE 由 0.311 dB 降至 0.279 dB。

因此收益不能由“增加了参数”解释。允许的结论是：在相同可学习参数预算下，filtration SSH 比单纯扩展 Fourier 字典提供了更有效的方向坐标。

### 2.2 软分工成立，严格分离失败

硬输入 residualization、硬分阶段训练及其组合分别造成明显预测损失；较强的 separation penalty 也开始恶化 NMSE。只有 `lambda_sep=0.001` 在保持预测非劣的同时降低 Fourier 的低阶占用。

机制审计显示：

- Fourier low-order energy 下降 45.0%；
- Fourier high-order energy 仅下降 1.1%；
- SSH energy 上升 42.6%；
- SSH/Fourier-low 相干交叉项下降 35.1%；
- 尺度归一化 Jacobian index `S_J` 从 0.617 降至 0.485。

因此该损失的主要作用是：

\[
\boxed{\text{low-order overlap suppression + redundancy reduction + symmetry breaking}.}
\]

它鼓励分支专门化，但不能被描述成严格 frequency separation。

### 2.3 SSH 被联合模型真实使用，但贡献不可相加

逐阶关闭 `l=1..5` 都在 10/10 种子上造成退化，其中 `l=1` 的 post-hoc NMSE 退化为 16.744 dB，表现出最强的层级敏感性；关闭整条 SSH/Fourier 分支分别退化 16.942/12.058 dB。

这证明 frozen model 功能上依赖两种表示，但不证明每个分支能独立完成相应频带，也不意味着 `l=1` 提供了某个可计算的“性能百分比”。虽然 `a(q)` 的参数化是加性的，后续相干叠加、二次 operator、幅度观测与联合优化使性能归因高度非线性。SSH 与 Fourier 应被视为协同的多尺度方向表示。

### 2.4 收益是全域表示收益，不是距离触发型收益

候选在十个训练距离分位中均保持平均优势，且优势能够延续到最远 Q4 和 spatial-gap；但连续趋势斜率为 `-0.131 dB/degree`，95% CI 完全为负，最近方向的收益反而最大。

所以 spatial-gap 的正确用法是证明“优势没有在稀疏角域消失”，而不是证明“方向越稀疏，SSH 越有优势”。当前证据更支持全域性的坐标表示和优化条件改善。

### 2.5 物理 operator 平滑性没有成立

软分离候选的 gauge-invariant 指标没有形成一致改善：

- `D_spec` 相对 G1-M5 恶化约 1.9%；
- `R_grad^Q` 误差恶化约 15.5%；
- graph roughness 虽平均改善约 14.2%，但仅 5/10 种子同方向；
- 距离收益不随训练距离增加。

因此 Level 3 在 V2.12 内冻结为失败。latent smooth specialization 与 physical operator smoothness improvement 是两个不同命题，后续不得混用。

## 3. V2.12 的最终定位

三级判定最终为：

| 层级 | 结论 | 状态 |
|---|---|---|
| Level 1 | SSH 具有不能由等参数 Fourier 解释的预测价值 | 通过 |
| Level 2 | SSH/Fourier 形成稳定的慢变—快变 latent specialization | 通过 |
| Level 3 | SSH 改善 gauge-invariant operator 的全局物理平滑性 | 不通过 |

最终研究结论不是“SSH 恢复了真实低频物理场”，而是：

\[
\boxed{\text{SSH 是低复杂度、相对慢变、优化友好的结构化方向坐标。}}
\]

与 Fourier residual 联合使用时，它改善了同参数预算下的预测，并能通过很弱的 overlap penalty 形成更清晰的内部尺度分工。该结论已足以支持将 SSH 作为后续模型的有效编码器，不需要继续通过压低 leakage 来证明其价值。

## 4. 不再继续的 V2.12 路线

以下方向在 V2.12 内停止：

- 继续把 leakage 从 0.679 压到更低；
- 增大 `lambda_sep` 或恢复硬 residualization；
- 将 latent complex SSH coefficient 当作唯一物理谱；
- 用 spatial-gap 单独证明物理平滑性；
- 为追求新颖性引入大型 Spherical CNN、Transformer、GNN 或 SFNO；
- 在既有冻结结果之后修改 external-test 准入规则。

这些方向要么已有负面实验，要么会混淆预测价值与物理解释。

## 5. 推荐下一步：V2.13 结构化多尺度编码

下一版本应接受已经得到的 representation 结论，将 SSH 作为结构化编码器，而不再要求它等于真实物理低频分量。建议保持物理链路不变，仅修改方向表示与融合：

\[
z(q)=[z_{\rm SSH}(q),z_F(q)]
\rightarrow
\text{small learned fusion}
\rightarrow
a(q)
\rightarrow D_r\rightarrow Q\rightarrow |z|.
\]

具体原则：

1. SSH 与 Fourier 保持独立归一化、独立投影和可审计输出；
2. 使用小型线性或 `1x1` 融合层允许共享，不做硬正交；
3. `lambda_sep=0.001` 仅作为已验证的弱 specialization bias，并与无约束 joint control 配对；
4. 保留逐阶 branch-off、`S_J`、Fourier-low occupancy 和等参数 Fourier control；
5. 物理层继续使用解析 `D_r`、rank-1 `Q` 和 amplitude observation，不改变测量合同；
6. 不用 latent `a` 的复相位或 SSH 系数提出可辨识物理结论。

V2.13 在实验开始前应将两道 gate 分开冻结：

- predictive acceptance：相对等参数 baseline 的配对统计与主瓣非劣；
- physical interpretation acceptance：只由 `Q_tilde` 的 gauge-invariant 指标决定。

Level 1+2 可以获得预测模型资格；Level 3 只决定能否声称物理平滑性。当前 V2.12 已冻结规则不追溯修改，external test 仍保持封存。

## 6. 可选物理研究：转向 `Q_tilde` 的 operator modes

若后续仍希望寻找真实的低阶物理结构，研究对象应从 latent branch 转向 `Q_tilde`。由于当前 `Q_tilde(q)` 在每个方向本身是 rank-1，对每个方向重复做普通特征分解信息有限；更合适的是分析其跨方向 operator field：

1. 对每个 `Q_tilde_nm(q)` 分别做 nested filtration spectrum，定位哪些端口对和角区稳定低阶；
2. 将 Hermitian `Q_tilde(q)` 向量化，对方向集合做加权 operator PCA/SVD：
   \[
   \widetilde Q(q)\approx\sum_s h_s(q)M_s,
   \]
   再分析标量模态 `h_s(q)` 的 filtration spectrum；
3. 分主瓣、弱场和空间 gap 报告 operator-mode 误差，检查全局 `D_spec` 是否掩盖局部结构；
4. 所有 basis、权重、截断和区域划分只由 train/validation 冻结，test 不参与发现；
5. 第一轮仅审计，不加入 loss。只有发现跨种子稳定、可迁移的低阶 operator modes 后，才预注册 gauge-invariant regularization 实验。

这条路线能够回答“物理 operator 的哪些部分确实低阶”，且不会重新落入 latent gauge-dependent spectrum 的问题。

## 7. 下一步优先级

推荐顺序为：

1. 结束并冻结 V2.12-S/S2，不追加 separation sweep；
2. 设计 V2.13 的双 gate、等参数对照与小型 SSH/Fourier fusion；
3. 并行开展只读 `Q_tilde_nm` / operator-PCA 物理审计；
4. 在 validation 完全冻结模型和结论资格后，再依预注册协议决定 external test；
5. O1 codebook 与 G3 operator distillation 继续作为独立诊断，不与编码收益混为一个实验因素。

这一安排把 V2.12 已经证明的表示价值直接转化为后续模型设计，同时把尚未证明的物理平滑性留给真正 gauge-invariant 的 operator 分析。
