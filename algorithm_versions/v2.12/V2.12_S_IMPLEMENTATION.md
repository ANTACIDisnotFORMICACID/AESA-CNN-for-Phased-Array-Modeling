# V2.12-S SSH–Fourier Separation

V2.12-S tests whether SSH provides a low-order angular inductive bias that cannot be explained by additional Fourier capacity. External test data remains sealed until the validation protocol freezes one final candidate.

## Implemented contracts

- Fourier residualization uses the general weighted projector. The implementation solves the Gram system and uses the orthonormal fast path only when the spectral identity error is below `1e-6`.
- `fourier_input_mode` supports `raw` and `filtration_residualized`.
- Operator recipes support equal-budget joint training, SSH/Fourier/joint staged training, matched-Fourier capacity control and SSH-only capability control.
- Checkpoints record the input projector diagnostics, training phase schedule, learning-rate phases, train/validation direction indices and separation settings.
- `terms_iq` exposes `ssh_l1_iq` through `ssh_l5_iq`, the total SSH contribution and the Fourier residual.
- Post-hoc branch reliance is reported separately from retrained branch capability.

## Fixed separation constraint

The optional separation loss uses 960 directions selected only from q_train: 40 deterministic samples from each of 24 equal-area hemisphere cells. Cell weights preserve the original empirical training measure. The loss is evaluated every eight optimizer steps from epoch 61 onward and is explicitly an architectural decomposition constraint, not a physical regularizer.

## Physical audit

The identifiable quantity remains

\[
\widetilde Q(q)=a^*(q)a^T(q).
\]

Nested filtration energy is computed by stable, weighted, filtration-incremental projections. Reports include cumulative and shell energy, spectral distance to HFSS truth, shell-wise operator error, L12 tail error, normalized gradient energy and six-neighbor graph roughness. Legacy raw-SSH coefficient spectra remain available only for comparison with earlier artifacts.

The latent quantities \(a_{\rm SSH}\), \(\Delta a_F\), per-degree RMS and Fourier leakage describe model decomposition. They are not interpreted as uniquely identifiable field components.

## Validation-only experiment matrix

The three-seed screen uses seeds 21201–21203 and 240 epochs for `G1-LR240`, `G1-M5-LR240`, `G2-J-LR240`, `G2-I-LR240`, `G2-T`, `G2-TI` and `SSH-only`. Historical constant-learning-rate G1/G2 remain references. Screening, nested-operator audits, angular-distance quartiles and spatial-gap diagnostics do not access the external test split.
