# V2.12-S2 冻结表征审计（2026-09-12）

## 审计边界

- 复用 V2.12-S 已冻结的 G1-M5、G2-J 与 `G2-J + lambda_sep=0.001` 十种子 checkpoint；没有重新训练或更新任何权重。
- 仅使用 train/validation directions 与 validation commands，external test 未打开。
- `a(q)`、SSH/Fourier 分支及其 Jacobian 只用于解释 latent representation；可辨识物理结论仍以 gauge-invariant `Q_tilde=a* a^T` 为准。
- Jacobian 使用 validation directions 的 23 个非空半球格，每格固定抽取 20 点，共 460 点；空格不由训练方向回填。

## 1. 逐阶 post-hoc reliance

在软分离候选上逐独立关闭一个 filtration block，不重训：

| 关闭块 | validation-D NMSE 退化 | 95% CI | 最远 Q4 退化 | 10 种子方向 |
|---|---:|---:|---:|---:|
| l=1 | +16.744 dB | [16.357, 17.096] | +14.080 dB | 10/10 |
| l=2 | +4.304 dB | [3.992, 4.628] | +2.651 dB | 10/10 |
| l=3 | +3.054 dB | [2.805, 3.292] | +2.011 dB | 10/10 |
| l=4 | +2.471 dB | [2.213, 2.704] | +1.571 dB | 10/10 |
| l=5 | +1.933 dB | [1.807, 2.053] | +1.212 dB | 10/10 |

整条 SSH 分支关闭时平均退化 16.942 dB，整条 Fourier 分支关闭时平均退化 12.058 dB，均为 10/10 同方向。

解释边界：当前 frozen solution 对两条分支和全部五个 filtration block 都有强功能依赖，且贡献随阶数总体下降；这支持“模型实际使用了低阶 SSH 坐标”，但巨大的退化也说明分支间存在联合拟合与相消，不能将 zero-out 数值解释为可独立相加的贡献，更不能据此声称任务必须使用 SSH。任务层面的能力结论仍来自已重训的 G1-M5 与 SSH-only 对照。

## 2. 收益与最近训练方向距离

定义每个 validation direction 的命令聚合误差改善：

`Delta(q) = NMSE_dB(G1-M5,q) - NMSE_dB(candidate,q)`。

十个距离分位的平均改善从最近到最远依次约为：

`1.56, 1.12, 0.75, 0.98, 0.52, 0.82, 0.62, 0.68, 0.62, 0.54 dB`。

线性趋势为 `-0.131 dB/degree`，paired bootstrap 95% CI `[-0.209,-0.051]`，只有 2/10 个种子斜率为正；平均 Pearson/Spearman 分别为 -0.069/-0.050。

因此，候选在各距离段普遍优于 G1-M5，但优势并未随离训练样本的距离单调增大，反而在最近方向最大。早先最远 Q4 的 +0.620 dB 和 spatial-gap 的 +0.37 dB 仍然成立，但它们不能再被解释为“距离越远，SSH 优势越强”的连续证据。SSH 的收益更像全域的结构化坐标/优化优势，而不是只在稀疏区域启动的插值先验。

## 3. SSH 与 Fourier 的局部方向 Jacobian

在球面切平面的两个正交方向上，以 `1e-3 rad` 中心差分估计 branch Jacobian Frobenius norm。

正式定义尺度归一化的 branch specialization index：

\[
S_J=
\frac{\|J_{\rm SSH}\|_F/(\|a_{\rm SSH}\|_2+\epsilon)}
{\|J_F\|_F/(\|\Delta a_F\|_2+\epsilon)}.
\]

当 `S_J<1` 时，只表示 SSH 分支相对于自身尺度比 Fourier 分支慢变，不代表 SSH 是唯一的物理低频分量。

| 模型 | SSH/Fourier 原始 Jacobian 比 | SSH/Fourier 尺度归一化比 | SSH 较慢点占比（归一化） |
|---|---:|---:|---:|
| G2-J | 0.409 | 0.617 | 70.7% |
| 软分离候选 | 0.473 | **0.485** | **82.4%** |

两个模型中 SSH 都明显比 Fourier 慢变。软分离后，SSH 分支幅度变大，所以原始导数比略升；但按各分支自身幅度归一化后，SSH/Fourier 比从 0.617 降到 0.485，且 SSH 较慢的方向占比从 70.7% 升到 82.4%。

这提供了清晰的 latent branch specialization 证据：软约束增强了“相对慢变 SSH + 相对快变 Fourier”的内部组织。它支持 Level 2，不改变 `Q_tilde` 物理平滑性的 Level 3 失败结论。

## 4. 协同而非可独立相加的贡献

四项结果必须联合解释：SSH-only 明显不足；G1-M5 弱于联合模型；关闭 SSH 或 Fourier 都造成 10 dB 以上退化；软分离后两条分支呈现不同的相对角域尺度。

模型的包络参数化仍然是显式加性的：

\[
a(q)=b+a_{\rm SSH}(q)+\Delta a_F(q).
\]

但预测还要经过解析传播、相干阵元求和、二次 operator 和幅度观测；两条分支也由同一个 amplitude loss 联合优化。因此 post-hoc 性能贡献不是加性的，各阶/各分支的退化不能求和或解释为独立贡献比例。更准确的结构结论是：

\[
\boxed{z_{\rm SSH}(q)\ \text{与}\ z_F(q)\ \text{构成协同、互补且不可独立归因的联合方向表示。}}
\]

SSH 不是可有可无的低频补丁，但这仍是 frozen model 的内部表示结论，不是物理唯一性结论。

## 5. 低阶信息重新分配

软分离候选相对无约束 G2-J 的 train-measure 能量变化：

| 项 | G2-J 均值 | 候选均值 | 变化 | 相对变化 |
|---|---:|---:|---:|---:|
| SSH energy | 195.923 | 279.287 | +83.363 | +42.6% |
| Fourier total | 279.431 | 179.243 | -100.187 | -35.9% |
| Fourier low-order | 221.417 | 121.863 | -99.554 | **-45.0%** |
| Fourier high-order residual | 58.014 | 57.380 | -0.634 | **-1.1%** |
| SSH/Fourier-low cross term | 133.460 | 86.598 | -46.862 | -35.1% |
| combined low-order | 550.801 | 487.748 | -63.052 | -11.5% |

每阶 SSH 输出 RMS 都上升，最大变化在 l=1：2.280 -> 2.769；l=2..5 也均为正。

这说明 `lambda_sep=0.001` 的主要作用确实集中在低阶重分配：Fourier low-order 减少约 99.6，而 Fourier high-order 几乎不变，同时 SSH energy 增加约 83.4。它不是严格的一对一搬运，因为 SSH 与 Fourier-low 的相干交叉项也下降，combined low-order 总能量减少约 11.5%。因此最准确的称呼仍是：

`soft branch specialization / low-order overlap suppression`，而不是严格 frequency separation。

## 冻结结论

V2.12-S2 进一步回答了 SSH 为什么有用：

1. 五个 filtration blocks 在 frozen joint solution 中全部具有稳定功能作用，且 l=1 最强；
2. SSH branch 的局部方向变化显著慢于 Fourier branch，软分离进一步强化了这种尺度归一化分工；
3. 软约束主要压低 Fourier 的低阶占用，并将大部分表征能量转向 SSH，而没有明显压低 Fourier 高频残差；
4. 但预测收益不随训练距离单调增强，且此前 `Q_tilde` 频谱/梯度并未更接近 HFSS truth。

Level 3 在 V2.12 内正式冻结为失败，不再尝试通过继续降低 leakage 或调大 separation loss 改写。否定证据包括：`D_spec` 没有改善、`R_grad^Q` 没有改善、距离收益没有随距离增加；graph roughness 仅 5/10 同方向，不能推翻前三项。

所以当前最强且不越界的结论是：

> SSH 为联合网络提供了低复杂度、慢变且优化友好的结构化方向坐标；soft overlap suppression 能让该坐标与 Fourier residual 形成稳定的功能分工。现有证据仍不足以把 SSH branch 解释为唯一低阶物理场，或声称其改善了 gauge-invariant 物理算子的整体平滑性。

论文式英文结论冻结为：

> SSH does not act as an independently sufficient low-frequency physical branch. Instead, it provides a low-complexity and relatively slowly varying angular coordinate system that is jointly exploited with Fourier residual features. Soft overlap suppression primarily reduces redundant low-order Fourier occupancy and strengthens branch-wise scale specialization, while preserving high-order Fourier content. These effects explain the stable predictive gain of SSH under equal parameter budgets, but they do not establish that the SSH branch corresponds to a unique low-order physical field or that it improves the global smoothness of the gauge-invariant operator.

中文压缩结论：

\[
\boxed{\text{SSH 的意义从“物理低频分量”收敛为“慢变、低复杂度、多尺度联合表示中的结构化坐标”。}}
\]

当前 external-test 冻结协议不追溯修改。后续版本可预先把 predictive acceptance（Level 1+2）与 physical-interpretation acceptance（Level 3）拆成两道独立 gate。
