# V2.8 HFSS 幅度合同与首版 CNN 基线

日期：2026-09-03

## 结论

当前 16 个逐端口 FFD 可以用于幅度信息 CNN 的可行性训练，但只能作为 HFSS 阶段的
算法验证数据。首版 CNN 相比未训练理想阵列有明确改善，尚未达到可用于四目标权值求解的
精度。HFSS checkpoint 不得迁移到实物部署；实物阶段须按相同合同重新采集并重新训练。

## 原始数据审计

- 16 个 `exportelement_*.ffd` 均为 47 GHz；每个文件含 181×361 个样本；
- `exportelement.txt` 明确映射 `1:1` 到 `16:1`；
- HFSS 工程审计给出的端口顺序为 `port_id = 4*row_z + col_y + 1`；
- HFSS +Y 为列轴（6.8 mm），+Z 为行轴（15 mm），+X 为名义主波束方向；
- 当前算法的 `[row_z,col_y]`、Y-Z 阵面和 +X 主波束与工程一致，因此本次采用单位坐标旋转；
- FFD 解析按 HFSS 的“固定 theta、扫描 phi”行序；旧的相反展开顺序已修正并加入测试；
- 数值全部有限，原始复场仅在离线合成步骤使用。

极化统计：全空间 `Ephi/Etheta` 能量比为 +3.32 dB；在 +X 法向为 +9.95 dB。因此首版
暂用 `Ephi` 作为共极化接收通道。暗室接收天线若采用不同极化或不同 roll 规则，必须修改
合同并重新采集，不能直接替换标签。

## 幅度合同

训练目录：`data/processed/hfss_47ghz_ephi_amplitude`

```text
direction.npy        [64440,3]
theta_deg.npy        [64440]
phi_deg.npy          [64440]
command_iq.npy       [128,2,4,4]
command_family.npy   [128]
amplitude.npy        [128,64440]
manifest.json
```

幅度标签由 FFD 离线执行“接收极化投影 → 已知 4×4 控制命令复数叠加 → 取绝对值”得到。
训练目录不包含 `operator_iq.npy`、`s_parameters_iq.npy` 或任何测量相位。`command_iq` 是
已知控制设置，不是接收相位标签。

64,440 个方向来自删除 theta=0/180 的球坐标极点及重复的 phi=+180° 接缝。这样避免
局部 Etheta/Ephi 在极点的定义歧义，也避免同一物理方向跨集合泄漏。

## 预训练划分

划分目录：`data/splits/hfss_47ghz_ephi_seed28001`

- 数据 SHA-256：`a53084dd96b2b24a9694b4b0692d79ea0f28c89477f02a10aae702c17f59e009`；
- 方向训练/验证/测试：45,110 / 9,660 / 9,670；
- 命令训练/验证/测试：92 / 18 / 18；
- 角度以 10°×10° 整块划分，三组共享角度块数均为 0；
- 三组重复物理方向数为 0；
- 每个命令族分别留出验证和测试命令；
- 模型训练样本是训练命令与训练角块的笛卡尔积抽样，验证/测试两侧都不进入训练。

## 训练与结果

checkpoint：`artifacts/checkpoints/hfss_47ghz_ephi_baseline.pt`

- GPU：NVIDIA GeForce RTX 5060 Laptop GPU；
- 20 epochs；每轮随机抽取 131,072 个训练组合；batch size 4096；
- AdamW，learning rate 1e-3；
- 最后一轮抽样训练 NMSE 0.2486，幅度 MAE 4.65 dB；
- 验证集：NMSE -4.16 dB，幅度 MAE 5.92 dB；
- 测试集（18 个未见命令 × 9,670 个未见角度点）：174,060 个组合。

| 模型 | 测试 NMSE | 测试幅度 MAE | 绝对误差 P50 | 绝对误差 P95 |
|---|---:|---:|---:|---:|
| 未训练理想阵列 | -1.06 dB | 14.16 dB | 2.764 | 11.443 |
| 幅度 CNN，20 epochs | -2.92 dB | 6.14 dB | 1.819 | 9.075 |

CNN 已显著降低幅度 dB 误差，说明“由幅度观测学习相对复响应、再预测幅度”的路线可行；
但测试 NMSE 仍高，特别是 P95 误差，不应直接进入四目标 max-min 优化。

## 下一步约束

1. 后续训练轮数、学习率和层级修订只看 validation，不反复查看 test；
2. 先按命令族、角区、强信号/零陷区拆解验证误差，再决定是否启用 multihop 或增强方向头；
3. 暗室前冻结接收极化、云台坐标、距离、幅度单位、噪声底、参考面及硬件可实现的相位码；
4. 实物转换后仍输出同七个文件并重新生成指纹划分；HFSS 数据和 checkpoint 均不混入；
5. 只有实物模型在盲测角块和未见命令上通过门槛后，才允许进行四目标权值优化。
