# V2.8 HFSS 单极化幅度模型冻结微调

日期：2026-09-03

## 结论

从 `hfss_47ghz_ephi_physics_v2_200ep.pt` 继续训练，冻结逐阵元复增益和 3×3 局部耦合，
只微调单极化方向图、方向残差和边缘分支。冻结完全生效，但 validation 改善很小：全局
幅度 NMSE 仅改善 0.085 dB，dB MAE 降低 0.025 dB，功率 NMSE 基本不变。

这说明低维增益/耦合参数已经不是当前主要优化障碍；在保持现有结构不变的情况下，继续冻结
并增加 epoch 的边际收益很低。剩余误差更可能来自单极化方向图、方向相位和边缘响应仍由多个
复数残差分支共同表示，物理分解不充分，而不是优化器尚未找到当前参数的局部最优。

本实验只使用 validation 选优，没有读取 test。

## 物理解释

当前有效标量通道可写成：

```text
z(q,w) = [f_co(q) .* s(q)]^T C_local D_g w
A(q,w) = |z(q,w)|
```

其中固定的 `s(q)` 是几何 steering，`D_g` 是逐端口复增益，`C_local` 是局部有效耦合，
`f_co(q)` 是当前固定接收极化下的逐阵元方向响应。

增益与局部耦合在 120--200 epoch 已经只变化约 1%，本次冻结它们后输出也没有明显恶化，
说明这两组参数已较稳定。然而方向图、方向残差和边缘分支都能同时改变有效复信道，幅度-only
监督只约束最终 `|h(q)^T w|`，不能保证三个分支得到唯一物理解。因此继续微调这些分支只能
取得很小的重新分配收益。

## 下一步判断

当前实验已经回答了“是否先冻结稳定参数继续训练”：这种做法安全、略有改善，但不是突破
当前误差的平台方案。下一步应优先进行受控结构修订，而不是继续扩大冻结微调轮数：

1. 将单极化方向图拆成独立的 `log-amplitude` 头和相对相位头；
2. 用单阵元幅度训练或拟合幅度头，不要求其学习不可观测的复相位；
3. 用 DFT 和随机相位命令约束相位头及局部耦合；
4. 减少方向图、方向残差和边缘分支之间重复的表达能力；
5. 加入随机幅度+随机相位命令，覆盖最终四目标优化会产生的非等幅权值；
6. 在新的未读取命令/角块上评估，并增加四目标 HFSS 闭环 regret。
