# V2.8 实施计划

## 0. 幅度信息合同修订（高于后文早期复场监督描述）

实际暗室只能取得标量幅度，因此正式训练接口冻结为：已知阵元命令
`command_iq[N,2,4,4]`、球面坐标 `direction[Q,3]` 和唯一测量标签
`amplitude[N,Q]`。HFSS 的复数 FFD 只能在离线转换器中按指定接收极化生成同类幅度
观测；复相位和 S16P 不得进入正式训练目录、损失或 checkpoint 输入合同。

网络保留潜在复数逐阵元信道，并通过固定复数张量收缩与绝对值产生幅度，以便用多组
已知相位码的幅度观测恢复对优化有意义的相干关系。由于仅有 16 个单端口幅度不能确定
阵元间相对相位，HFSS 与暗室必须执行同一组单阵元、二维 DFT 和随机多阵元相位码。

HFSS 模型只验证架构可行性；实际部署模型仅由目标实物阵列幅度数据从头训练，不使用
HFSS 样本、HFSS checkpoint 或 HFSS 拟合参数。后文涉及复场直接监督的内容仅保留为
HFSS 审计/消融路线，不再代表正式部署训练入口。

## 1. 计划结论

V2.8 应从“1×4 逆向残差控制器”转为以下链路：

```text
4×4 AEDT/未来 OTA 原始观测
        ↓ 统一数据合同
复激励 + 查询坐标 → 正向复场/接收功率模型
        ↓ 固定功率与硬件约束下的外部优化器
四目标 max-min 权值 → 独立 HFSS/OTA 复验
```

CNN 只承担正向预测或物理模型残差，不直接充当未经验证的 oracle，也不负责宣称突破
固定阵列的栅瓣和自由度上限。

## 2. 当前证据基线

### 2.1 可直接确认的事实

| 项目 | 当前证据 | V2.8 用法 |
|---|---|---|
| 源 AEDT | 原始母版不纳入本仓库；当时记录的 SHA-256 为 `D647839C...B350` | 只读母版；仅在独立 HFSS 工作区使用 |
| 原阵列 | 47 GHz、4 端口，HFSS `+Y` 方向 6.8 mm 间距 | 作为每一条 1×4 子阵 |
| 原板参数 | `w_board=6.8 mm`、`h_board=0.254 mm` | 用于检查四排复制后的几何冲突 |
| 已有 HFSS 数据 | 4 个端口的全球面 `ETheta/EPhi` 复场和 4×4 S 参数 | 仅用于 1×4 回归和导出流程参考 |
| 线性重组 | 旧 1×4 的 4 组直接 HFSS 重组已通过 | 方法可复用；4×4 必须重新验证 |
| 旧理想 4×4 | V2.5 数学合同使用 6.83 mm 与 15 mm，输入 `[B,2,4,4]` | 仅作索引/形状和理想基线参考 |
| 根目录历史数据 | 1000 个 1×4 输入，仅 1 个 4×4 输入；方向图来自理想阵列计算 | 不得作为 4×4 HFSS 训练真值 |
| 4×4 HFSS 真值 | 当前不存在 | 必须新建完整 16 端口模型并导出 |

### 2.2 必须保留的怀疑

- 47 GHz 自由空间波长约为 6.38 mm，15 mm 排间距约为 `2.35 λ`；原列内 6.8 mm
  也约为 `1.07 λ`。4×4 增加了自由度，但两个方向的周期大间距仍可能产生强栅瓣。
  间距是已冻结结构参数，本计划不修改它；是否可用于四目标公平发射必须由 4×4 全波
  结果重新判断。
- 旧 4×4 结果是理想阵列因子或合成测试，不包含四排之间的全波互耦，不能替代新
  AEDT。
- 对固定、线性、无器件误差的 HFSS 模型，16 个嵌入式阵元场的线性叠加应比 CNN
  更精确。CNN 的 HFSS 阶段价值是验证“统一数据接口、可学习性和可微优化链路”；其
  真正增量预计来自后续 OTA 残差、环境变化和硬件非线性，而不是重复学习已知线性式。

## 3. 阶段 A：建立 4×4 AEDT

### A1. 保护母版与建立工程来源

批准实施后：

1. 对源 AEDT 记录路径、大小、SHA-256、AEDT/HFSS 版本和已有求解设置；
2. 复制成 V2.8 专用工程，绝不原地修改母版；
3. 在工程和外部清单中增加 `geometry_id`、`source_project_hash`、`row_pitch=15mm`、
   `frequency=47GHz` 与坐标变换版本。

### A2. 四排复制规则

推荐在保持名义波束方向 `+X` 的前提下，将完整 1×4 子阵沿 `+Z` 复制：

```text
r = 0..3, c = 0..3
HFSS 原始坐标：position[r,c] = (0, 6.8*c, 15*r) mm
逻辑张量索引：[row_z=r, col_y=c]
```

工程内应将单排的介质、铜、馈线、辐射体和端口作为一个受控整体复制；原有公共空气
盒、辐射边界、观察面和后处理对象不得跟着复制。四排完成后重新建立覆盖整个阵列的
公共空气区域和辐射/PML 边界。

如果实际机械坐标要求旋转，应旋转**完整 4×4 阵列及其端口/边界关系**，同时保存
`R_algorithm_from_hfss[3,3]` 和原点平移。不得只旋转远场数组或只交换 `theta/phi`
来伪装坐标一致。

### A3. AEDT 审计门槛

- 恰好 16 个独立端口，端口名、积分线方向、参考阻抗及功率归一化明确；
- 四列 `Y` 坐标间隔为 6.8 mm，四排 `Z` 坐标间隔为 15 mm；
- 无实体重叠、悬空端口、重复边界或漏选辐射体；
- 47 GHz 自适应网格收敛，并保存每步最大 `Delta S`、网格数量和资源消耗；
- S 参数完整为 16×16，检查有限值、互易性和异常强耦合；
- 单端口激励、全同相激励和两个二维相位坡度的主瓣方向符合坐标预期；
- 在未通过这些门槛前，不进入批量数据导出。

## 4. 阶段 B：HFSS 原始数据导出

### B1. 首选导出方式

对固定 47 GHz、线性无源 16 端口模型，不应为每组随机幅相重新做一次全波自适应求解。
首选流程是一次收敛求解后导出完整嵌入式阵元基底：

1. 逐端口以统一的 `1 W / 0°` 或明确的 incident-wave 归一化激励，其他端口匹配；
2. 导出 16 组复数 `ETheta`、`EPhi`，保留绝对幅相和完整坐标轴；
3. 导出同一变分点的复数 16×16 S 参数；
4. 导出端口表、阵元三维坐标、阵元朝向、频率、球坐标定义、单位、参考阻抗、
   HFSS setup、mesh/convergence 与源工程哈希；
5. 原始导出只追加、不覆盖，并为每个文件保存 SHA-256。

嵌入式阵元场来自完整 16 端口耦合模型，因此保留该模型内的互耦影响。任意源激励的
方向图可以由 16 个基底线性重组，但这种线性只适用于同一几何、频率、材料和线性边界。

### B2. 独立重组验证

另选至少 8 组不参与任何拟合的 16 端口源设置，包括：

- 全同相、二维 DFT 相位坡度；
- 随机相位、随机幅相；
- 稀疏激励和低幅度边界样本。

每组都在 HFSS 中直接 `Edit Sources` 导出，再与 16 基底重组结果比较复场 NMSE、
绝对增益、目标点功率和峰值方向。暂定门槛为复场 NMSE 不高于 `-40 dB`、主要增益
差不超过 `0.1 dB`、峰值方向差不超过一个导出网格；门槛应在首批数据观察数值噪声后
冻结，不能事后为通过而放宽。

### B3. 远场与“位置点”的边界

当前 `Infinite Sphere` 数据只描述远场方向，不能仅凭 `(x,y,z)` 距离坐标证明有限距离
接收功率。统一接口必须支持两种查询，但标签不得混用：

- `far_field_direction`：位置换算为阵列坐标系中的方向和距离；HFSS 提供复远场，距离
  衰减与接收天线模型单独定义；
- `cartesian_channel_point`：直接预测阵列端口到有限距离接收点的复传输系数，需要
  HFSS 近场/接收天线模型或未来暗室相干测量。

在确认四个目标属于远场前，V2.8 只能宣称“方向点四目标验证”，不能宣称任意三维位置
点的接收功率已经成立。

## 5. 阶段 C：HFSS/OTA 统一数据合同

### C1. 逻辑样本

建议把存储后端与训练接口分离。原始数据使用 `JSON manifest + NPZ shards` 起步，训练
加载器统一返回如下逻辑字段；未来即使改用 HDF5/Zarr，字段语义也不改变。

| 字段 | 形状/含义 | HFSS 与 OTA 共同规则 |
|---|---|---|
| `schema_version` | 整数 | 不兼容修改必须升级 |
| `source_kind` | `hfss` / `ota` | 不能省略或改写 |
| `array_id, geometry_id` | 稳定字符串 | 指向端口/坐标清单 |
| `solve_or_session_id` | 求解或实测会话 | 用于分组切分，防止泄露 |
| `frequency_hz` | 标量 | 初始为 47 GHz |
| `coordinate_type` | direction / Cartesian | 决定标签物理含义 |
| `query_xyz_m` | `[Q,3]` | 使用算法坐标系，并附变换版本 |
| `command_iq` | `[4,4,2]` | 阵元命令复数 I/Q，固定端口映射 |
| `realized_port_iq` | `[4,4,2]`，可选 | 只有部署时也能测量时才可作为输入 |
| `response_iq` | `[Q,2]` 或 `[Q,2,2]` | 复接收量或 `ETheta/EPhi` 标签 |
| `response_power` | `[Q]` | 从未归一化复响应一致计算 |
| `valid_mask` | `[Q]` | 缺测、低信噪比和无效点显式标记 |
| `provenance` | 哈希、单位、归一化等 | 可追溯到原始文件 |

`Q` 可以是单点、四点或网格。四目标顺序不应改变模型输出含义，查询头应共享参数并按
输入顺序返回结果。

### C2. 防泄露规则

- 训练特征白名单只包含部署时可得到的命令、坐标和经批准的校准量；
- `response_iq/power`、HFSS 嵌入式场、oracle 权值和全局峰值不得进入输入通道；
- 标准化器、功率尺度、相位参考和任何 PCA/降维只在训练集合拟合；
- train/validation/test 按 `solve_or_session_id`、激励族和空间块分组，不能随机拆散同一
  扫描序列；未来 OTA 必须按日期、装配、温度或校准会话整组留出；
- HFSS 合成样本必须记录所用基底哈希和激励种子。训练时按需线性生成标签可以节省
  空间，但固定测试集必须物化、只读并带哈希；
- 绝对功率不可被逐样本峰值归一化抹去。若另存归一化方向图，只能作为辅助标签。

### C3. 激励与查询覆盖

分阶段建立数据，而不是一次生成巨大数据集：

1. `basis`：16 个单端口嵌入式场和 S 参数；
2. `smoke`：约 256 组正交、相位-only、幅相和稀疏激励；
3. `pilot`：约 4096 组分层激励，评估模型容量、归一化和误差分布；
4. `full`：若 pilot 达标，再按需扩展到数万组；全方向图尽量由基底在线重组，避免
   重复保存相同线性算子产生的数百 GB 数据；
5. 查询坐标同时覆盖均匀角域、边界、峰值附近、近零陷和四目标困难组合。

## 6. 阶段 D：正向模型结构

### D1. 必须保留的基线

1. **HFSS 线性基底层**：`H(q,row,col)` 与 `w(row,col)` 的二维复张量收缩，无训练
   参数，是固定 HFSS 模型的精确参考；
2. **旧理想阵列因子**：只用于量化互耦/单元方向图带来的差异；
3. **理想物理层 + 算子修正 CNN**：以理想近场 Green 矩阵或远场传播矩阵为主值，
   CNN 只预测随查询坐标变化且保留 `[4,4]` 索引的复响应修正，最后显式计算二维复
   张量收缩；
4. **纯数据驱动 2D CNN**：仅作消融，用于判断网络是否能学习 4×4 复激励到复场映射，
   但必须额外通过齐次性、叠加性和全部阵元影响测试；
5. **HFSS 物理层 + 小适配器**：用于检验低秩修正接口和未来 OTA 路线。固定 HFSS
   本身已有完整基底时，其适配器应保持零或接近零，不能凭增加参数制造虚假收益。

若纯 CNN 在 HFSS 上仍显著差于线性基底，则不得用它替代物理层进行最终权值验收。

### D2. 对“理想阵列结果 + CNN 误差”的重新判断

该思路**有条件地合理**，但残差定义和网络结构必须受物理约束。

固定几何、固定频率、线性材料与端口条件下，HFSS 的任意复激励响应满足
`y_HFSS(q,w) = sum_(r,c) H_HFSS(q,r,c) * w(r,c)`。因此理想模型与 HFSS 的差异也
可写为 `delta_y(q,w) = sum_(r,c) delta_H(q,r,c) * w(r,c)`。互耦、有限地板/介质、嵌入式阵元方向图和边缘阵元
差异会使 `delta_H(q)` 具有二维局部性与全局性，CNN 可能有效提取这些结构；但若让
一个非线性 CNN 直接学习 `delta_y(w,q)`，它也可能记忆激励分布、违反复数叠加，并在
后续权值优化器搜索训练分布之外时产生虚假高值。

所以 V2.8 的首选形式不是“理想方向图 + 任意 CNN 输出误差图”，而是：

```text
查询坐标 q + 16 个理想逐阵元响应
        ↓ 4×4 二维局部编码 + 可选 4×4 全局卷积上下文
逐阵元复算子修正 delta_H(q)
        ↓ 保留 row/col 索引的显式二维复张量收缩
目标复场 y(q,w)
```

这样 CNN 学习的是空间算子偏差，而最终响应对 `w` 仍严格线性。若已导出完整
`H_HFSS(q)`，它仍是固定 HFSS 场景的精确计算层和最终验收层；CNN 的作用是做紧凑
插值、架构验证及为未来 OTA 修正预留接口，不应宣称优于已知 HFSS 基底。

### D3. 冻结的分层架构

#### D3.1 第 0 层：坐标、端口与复数合同

- 输入阵元轴固定为 `[row_z, col_y] = [4,4]`，端口按
  `port_id = 4 * row_z + col_y + 1` 排列；禁止先展平后凭长度猜测二维位置。
- 复数统一用 I/Q 表示；相位只作为派生诊断量，不把 `-180°/180°` 跳变直接交给网络。
- 查询编码必须区分远场方向与有限距离 Cartesian 点，并使用冻结的
  `R_algorithm_from_hfss` 和原点变换。

#### D3.2 第 1 层：近场/远场物理主干

- **近场头**：使用 `G_nf(q,row,col) ∈ C^(Q×4×4)` 表示各二维阵元到有限距离查询点
  的 Green/通道张量，通过对 `row,col` 两轴做复数张量收缩得到 `y_nf`；只有取得 HFSS
  近场或接收端口标签后才训练和验证该头。
- **远场头**：使用 `H_ff(theta,phi,row,col) ∈ C^(P×4×4)` 表示逐阵元远场响应，
  其中 `P` 可包含 `ETheta/EPhi` 两个极化分量；同样只对二维阵元轴做显式复数张量收缩。
- 两个头可共享同一 4×4 有效孔径/端口表示 `w_eff`，但不得把远场方向图标签当作近场
  Cartesian 点标签，也不得在缺少近场测量时训练“近场反演”。
- 谨慎参考 V2.5 `physics_initialized_frontend.py` 的分层方式：复矩阵通过
  `[[Re,-Im],[Im,Re]]` 写成显式 I/Q 线性层，主值可固定或物理初始化，修正支路采用
  零初始化低秩适配器。该文件中的 `G` 伪逆是“近场测量到孔径”的反演前端，只在未来
  确有近场测量输入时适用，当前不能直接复制为正向预测器；V2.8 若采用其思想，也必须
  将阵元维改写为显式 `[4,4]` 张量，不沿用长度 16 的线性层表示。

#### D3.3 第 2 层：固定二维 `3×3` 局部编码

- 阵元特征固定为 `[B,C,4,4]`，所有阵元域卷积固定使用二维 `3×3`、步长 1，并采用
  保持 4×4 尺寸的 padding；不再使用沿 16 阵元展平序列的一维卷积。
- 一个 `3×3` 感受野同时覆盖中心阵元、同排相邻阵元、相邻排及对角邻居，使横向
  6.8 mm 邻接和纵向 15 mm 邻接保持为两个明确的空间轴。必要时使用两个轴的位置编码
  或各向异性通道，但卷积核尺寸仍为二维 `3×3`。
- 输入特征至少包含每个阵元的理想复响应、二维坐标和边缘/角点身份；是否包含命令
  I/Q 取决于候选模型。首选算子修正模型的非线性卷积支路不读取 `w`，以保持最终对
  激励严格线性。
- 初版的方向与边角支路均由 `3×3 stem + 1 个双卷积残差块 + 3×3 head` 构成，
  已具有覆盖 4×4 阵面的理论感受野；独立的复耦合层同样使用 `3×3`。额外 multihop
  支路默认禁用，只在远端组合误差消融给出证据后启用，不得无证据继续加深。
- `3×3` 只是正确表达二维邻接关系的结构条件，并不自动证明学到了真实互耦。必须用
  单端口和成对端口扰动，检查同行、跨排和对角响应是否与 HFSS 的误差结构一致。

#### D3.4 第 3 层：不展平的全阵元响应汇聚

- 旧结构把阵元排成长度 16 的序列，或对阵元轴做全局平均后再进入普通全连接层，都会
  破坏或丢失 `[row_z,col_y]` 的二维身份，V2.8 均禁止沿用。
- 局部编码输出在整个主干中保持 `F ∈ R^(B×C×4×4)`。普通 `Linear/MLP` 只能作用于
  每个二维位置的通道维或查询维，等价于逐位置共享的通道变换；不得把 `[4,4]` reshape
  成 16 后输入全连接层。
- 若局部主干仍不能描述远距离阵元关系，可增加一个核覆盖整个阵面的二维 `4×4` 全局
  卷积分支形成全局上下文，再广播回保留的 4×4 主支路；该分支只作辅助，不能取代逐
  阵元响应图。是否启用由跨排/远端组合误差消融决定。
- 网络最终输出保留二维索引的逐阵元复响应张量，例如
  `H_eff ∈ C^(B×Q×P×4×4)`；命令保持 `w ∈ C^(B×4×4)`。所谓“全连接包含每一个
  阵元响应”落实为拓扑保持的复数张量收缩
  `y[b,q,p] = sum_(r,c) H_eff[b,q,p,r,c] * w[b,r,c]`，而不是展平后的普通 FC。
- 上述求和对 16 个位置逐项显式执行，每项都能追溯到端口清单。二维 `3×3` 主干负责
  局部与逐层全局关系，张量收缩负责确保全部阵元响应进入最终复场。

#### D3.5 第 4 层：共享查询头与输出

- 查询坐标使用共享参数的坐标编码/查询头，使一个模型可按输入顺序一次评估四个目标，
  也可分块生成方向图；不得为四个目标建立四个带位置含义的固定输出槽。
- 输出为未归一化复 I/Q，再由唯一的物理函数计算幅度、圆周相位和接收功率。
- 比较“实数 I/Q 2D 算子 CNN”“复数 2D 算子 CNN”“HFSS 固定层 + 零初始化低秩
  适配器”和“直接激励到场 CNN 消融”；按独立测试误差、线性守恒与优化闭环误差选型。
- FP32 正向闭环通过后才讨论量化和 Vitis 兼容，不能提前为算子限制牺牲物理正确性。

### D4. 训练约束与正向验收

训练不使用旧 oracle 权值。损失由直接 HFSS/OTA 标签构成：

- 复场 I/Q 的归一化 NMSE；
- 保留绝对尺度的目标功率误差；
- 高于噪声门限点的幅度 dB 与圆周相位误差；
- 四目标集合上的最小接收功率预测误差；
- 必要时使用相干参考或全局相位对齐，但不能把每个空间点独立对相位而破坏场结构。

首批 pilot 后冻结门槛。建议至少报告：复场 NMSE、幅度误差 p50/p95、有效点相位误差
p50/p95、四目标最小功率误差、不同激励族和空间区域的最坏值，以及相对 HFSS 线性层
的误差。仅报告平均 MSE 不构成“正向预测完备”。

还必须加入以下结构验收：

1. **16 路脉冲测试**：逐次仅激励一个端口，确认 16 个预测响应都与对应 HFSS EEP
   匹配，且不存在重复端口、死端口或 reshape 交换；
2. **二维邻域测试**：分别扰动同行、跨排和对角端口对，比较残差相关性和 HFSS
   耦合/场差异，证明 `3×3` 卷积对应真实二维邻接而非偶然索引；
3. **全阵元影响测试**：对输出关于 16 路 I/Q 求 Jacobian，每个健康端口均须有有限且
   可解释的影响；端口置换后仅按同一置换变换结果，不允许网络对不同阵元无差别；
4. **齐次性**：随机复标量 `alpha` 下验证 `f(alpha*w,q) ≈ alpha*f(w,q)`；
5. **叠加性**：独立激励 `w1,w2` 下验证 `f(w1+w2,q) ≈ f(w1,q)+f(w2,q)`；
6. **优化分布外测试**：把正向模型优化器产生的困难权值作为 hard negative，回到 HFSS
   基底和直接源设置验证，防止优化器利用模型误差。

算子修正模型的齐次性与叠加性应由结构精确保证；测试用于发现实现、归一化或复数符号
错误。直接激励到场 CNN 若只能靠损失近似满足这两项，只能作为消融，不能成为默认
优化代理。

### D5. 问题驱动的层级修正方案

模型按“能解释残差的最小层级”逐级增加复杂度：`L0` 理想远场物理层，`L1` 逐阵元
复增益，`L2` 中心置零的二维 `3×3` 复耦合，`L3a` 方向/极化二维修正，`L3b`
边缘/角点二维修正，`L4` 可选 multihop 上下文。未来取得合法近场标签后才新增独立
Green 头；OTA 阶段才允许条件适配与器件非线性。不得在诊断前同时启用所有扩展层。

| 观察到的问题 | 优先诊断 | 允许的结构修正 |
|---|---|---|
| 训练/验证误差低，但齐次性或叠加性失败 | 检查直接 CNN 是否非线性读取 `w`、逐样本归一化是否破坏尺度 | 改为预测 `delta_H(q)` 后显式乘 `w`；移除逐样本归一化 |
| 某些端口几乎不影响输出 | 检查端口映射、二维索引、张量收缩、梯度/Jacobian | 修正二维映射；保留逐阵元旁路；禁止纯 GAP 和阵元展平 |
| 同排预测好、跨排误差大 | 核查 15 mm 方向坐标和跨排 HFSS 耦合 | 保持二维 `3×3`，增加排轴位置编码或各向异性特征；必要时启用 L3 全局混合 |
| 边缘/角点误差显著 | 检查有限地板、边界阵元 EEP 与 padding 偏差 | 增加边缘/角点通道或非循环 padding 消融，不先加深整个网络 |
| 远距离阵元组合误差大，局部对正确 | 检查二维全局核和张量修正的分解秩 | 启用 `4×4` 全局卷积分支或二维可分离低秩核，并用消融确定最小秩 |
| 主瓣准确但旁瓣/深零陷误差大 | 检查角网格、动态范围、相位参考与低幅点数值噪声 | 增加角域 Fourier 特征和困难查询采样；对低幅点使用掩码/复 NMSE，不盲目扩大解码器 |
| 远场好、近场差 | 核查是否误用平面波、距离衰减或错误坐标类型 | 启用独立 Green 近场头和距离特征；前提是已有合法近场标签 |
| 近场好、远场差 | 检查近远场变换、极化基、球坐标约定 | 分离最终查询头并验证 `ETheta/EPhi`；不强迫两个标签共用最终解码层 |
| 训练集好、空间块留出差 | 检查查询编码和采样覆盖 | 加强坐标编码、空间块采样和算子平滑正则；不先增加训练激励数量 |
| 正向测试好，但优化结果回 HFSS 后变差 | 优化器可能利用代理模型局部误差 | 加 hard-negative 闭环、信赖域或不确定性惩罚；最终始终以 HFSS 层排名 |
| 参数增加后验证无提升或波动变大 | 检查过拟合、数据重复和基底在线合成相关性 | 回退到低秩/小宽度层，冻结物理主干，按激励族和空间块重做消融 |
| FP32 正常、量化后相位/零陷崩溃 | 检查 I/Q 尺度、量化步进和 CPU/DPU 边界 | 仅在 HFSS 正向闭环完成后做量化感知训练和离散权值复验 |

### D6. HFSS 未覆盖误差与后期结构补丁

以下项只建立扩展接口和数据需求，不进入当前 HFSS 训练，不用人工噪声冒充实测误差，
也不以其为理由提前扩大网络。

| HFSS 当前未覆盖项 | 后期需要的可观测量/数据 | 可能的最小结构补丁 | 当前状态 |
|---|---|---|---|
| 温漂与热时间常数 | 阵元/板级温度、功率历史、多温度会话 | 温度条件 FiLM 或低秩逐阵元复增益；必要时加入小型时序状态 | 禁用 |
| PA/LNA AM/AM、AM/PM 和压缩 | 每端口多功率档幅相扫描 | 在复线性传播前增加共享或逐端口单调 LUT/小 MLP | 禁用 |
| 移相器/衰减器量化与码字偏差 | 实际码字、码字到复响应标定表 | 网络外确定性量化器 + 码字条件小残差，不把量化误差混进空间 CNN | 禁用 |
| 馈线、连接器和本振相位漂移 | 相干校准通道、会话 ID、参考端口 | 对角复增益 `D(state)`；公共相位作为 nuisance 对齐 | 禁用 |
| 加工/装配与阵元个体差异 | 多块实物、装配批次、少量校准扫描 | `array_id` 条件低秩适配器或少样本校准头 | 禁用 |
| 互耦随外壳/安装变化 | 多安装状态的 S 参数或 OTA 扫描 | 在二维局部分支后增加受稀疏/低秩约束的复耦合矩阵 | 禁用 |
| 测量噪声、低 SNR 与缺测 | 重复扫描、噪声底、有效掩码 | 异方差不确定性头和似然损失；不把随机噪声拟合成确定性场 | 禁用 |
| 暗室残余反射与实际环境多径 | 空场校准、不同布置/距离/会话 | 环境条件通道或独立信道残差头；无环境输入时不得声称可泛化 | 禁用 |

启用任一补丁前必须先证明：对应误差在分组留出的 OTA 数据中稳定存在、现有最低层级
无法解释、所需状态在部署时可测，并且补丁在跨温度/会话/实物测试上有独立收益。

## 7. 阶段 E：旧 oracle 审计与替代参考

旧 oracle 的 1×4 单目标目标函数、局部多起点策略和可行性判据都不直接适用于 V2.8。
处理原则如下：

1. 冻结旧实现，不将其输出写入 V2.8 正向模型训练标签；
2. 把 4×4 HFSS 线性层作为目标函数的直接计算器，而不是再训练第二个黑盒 oracle；
3. 对同一四目标问题至少比较：多起点投影梯度、坐标/邻域搜索，以及半正定松弛等可给
   上界的方法；
4. 报告“可行候选下界、可计算上界及二者差距”，不把一次 SLSQP 成功称为全局最优；
5. 固定独立种子复算、扰动初值、目标顺序置换和全局相位变换，检查结果稳定性；
6. 所有最终候选都回到未参与优化的 HFSS 直接重组，关键样本再用独立 `Edit Sources`
   导出复验。

## 8. 阶段 F：四目标 max-min 优化

对四个查询点 `q_i`，正向模型给出复响应 `y_i(w)`，基本目标定义为：

```text
maximize_w    min_i P_i(w),    P_i(w) = |y_i(w)|^2
subject to    |w_n| <= A_n,max
              sum_n |w_n|^2 <= P_total
              phase/amplitude obey hardware resolution when enabled
```

必须固定总发射功率，否则不同方法可通过增加总功率获得虚假优势。优化阶段可用平滑
soft-min 提供梯度，但最终排名必须使用精确 `min`。

候选流程：

1. 由二维 DFT 波束组合、随机相位和物理启发式生成多起点；
2. 在 FP32 连续复圆盘上做投影梯度优化；
3. 对幅度/相位硬件步进量化，并做离散邻域修正；
4. 用 HFSS 线性层复验四点功率；关键案例再做 HFSS 直接源设置；
5. 输出 `amplitude[4,4]`、`phase_deg[4,4]`、端口顺序、总功率、四点各自功率、
   最小功率、方法间上/下界差和失败原因；
6. 旁瓣、峰值歧义和非目标区辐射作为诊断量报告，但不擅自替换用户指定的 max-min
   主目标。

未来实测数据到位后，扩展为跨校准状态/会话的稳健目标
`maximize_w min_{state,i} P_i(w,state)`，但 HFSS 第一阶段不伪造这些实物误差。

## 10. 实施前仍需冻结的两项语义

这两项不影响当前规划文件，但会影响数据导出和验收：

1. 四个“位置点”究竟是远场方向，还是带有限距离的三维 Cartesian 接收点；
2. 实际发射链的总功率、单阵元最大幅度、幅度档位和相位分辨率。

若暂时未知，首轮 HFSS 只能按“47 GHz、远场方向点、连续复权值、固定归一化总功率”
做可行性验证，并在报告中明确这是临时合同。
