# V2.17 数据处理与分阵列模型可行性方案

## 目标边界

V2.17 不再以“单一统一网络跨尺寸零样本迁移”为主目标。四种阵列分别建立与自身几何匹配的模型、分别训练、分别在本阵列 validation 上评价；所谓“普适”只表示同一个物理建模思想在不同阵列规模上都相对各自匹配的 control 有收益，不表示参数、checkpoint 或方向图可直接跨阵列复用。

本轮只做 feasibility pilot，不升级为正式模型版本。四阵列数据门禁全部 PASS 前不启动训练；结构、种子和阈值只使用 train 数据及既有 V2.16 证据冻结，blind-test 保持封闭。

## 数据合同

canonical 保存绝对 `complex128` Etheta/Ephi/三维横向场，不平滑、不插值、不归一化。integer/offset 网格保留来源标签并形成无重复前半球联合索引；绘图插值不回流训练。

每个阵列独立使用其 train split 的单端口 Ephi RMS：

\[
s_A=\sqrt{\frac{1}{|\mathcal T_A|N_A}
\sum_{q\in\mathcal T_A}\sum_{n=1}^{N_A}|g_{A,n}(q)|^2},
\qquad \tilde g_A=g_A/s_A.
\]

派生缓存为 `float32/complex64`，只包含 train 和 validation。不得创建或读取 blind-test 低精度缓存；checkpoint 只能由本阵列 validation linear NMSE 选择。

## 统一验证的模型思想

所有阵列只共享以下思想与评价协议，不共享网络参数：

1. 保留解析阵列相位 `exp(j k q^T r_n)` 和相干求和；
2. 用从本阵列 train 数据学习的相干低秩 EEP 骨架初始化，而不是用会发生复相位抵消的逐阵元算术平均；
3. CNN 只学习复数包络残差；
4. 空间传播按阵列几何定制，并由方向编码产生 gate；
5. candidate 与本阵列 control 保持相同输入、深度、训练预算和近等参数量；
6. 同时检查幅度、复 operator、强弱场分桶、有限值、参数量与延迟。

## 分阵列结构

| 阵列 | control | candidate | 原因 |
|---|---|---|---|
| 1×4 | 两层 column-only `1×3` residual，固定 gate | 同深度 column-only residual，每 block 方向 gate | row 轴退化，禁止用无意义的 row 卷积填充参数 |
| 1×8 | 三层 column-only `1×3` residual，允许 dilation `1/2/1` | 同结构、逐 block 方向 gate | 更长孔径需要覆盖远于 1×4 的列向邻域 |
| 2×4 | row-pair 全高混合 + column `1×3` 两分支，固定 gate | 同两分支、逐 block 方向 gate | 两行阵列的 row 轴应直接建模成成对耦合，不照搬 4×4 的 `3×1` 零填充 |
| 4×4 | V2.16 深度保持、近等参数 static DCAR | V2.16 `dcar_gated_pm` 思路 | 4×4 已有控制变量证据，可作为冻结参照而不修改 V2.16 |

各模型均有独立的宽度/分支宽度配置，使 candidate 与对应 control 参数差绝对值不超过 `0.5%`；不要求不同阵列之间参数量相等。

静态结构审计已通过，回执为 `artifacts/per_array_model_static_audit_20261014.json`：四组完整算子的 complex operator/amplitude shape、有限值、candidate/control 严格相同公共初始化、独立参数存储、有限非零反向梯度和 `≤0.5%` 参数匹配全部 PASS。完整算子参数差分别为 1×4 `+0.393%`、2×4 `+0.428%`、4×4 `−0.114%`、1×8 `+0.442%`。该审计不含训练或性能结论。

## Train-only 预分析（2026-10-14）

证据文件：`artifacts/train_only_pre_feasibility_20261014.json`。分析已读取四阵列的 `train_operator_cache.npz`；未读 validation/blind-test，未训练 CNN。旧三阵列回执保留在 `artifacts/stage_history/`。

| 阵列 | 公共平均 EEP operator NMSE | 最优 rank-1 operator NMSE | 最优 rank-1 Q NMSE | rank-1 能量 | train scale |
|---|---:|---:|---:|---:|---:|
| 1×4 | −1.272 dB | −15.841 dB | −14.275 dB | 97.394% | 7.1503 |
| 1×8 | −1.240 dB | −18.287 dB | −16.672 dB | 98.516% | 7.4859 |
| 2×4 | −1.265 dB | −14.056 dB | −13.293 dB | 96.070% | 7.1466 |
| 4×4 | −1.228 dB | −13.484 dB | −12.546 dB | 95.517% | 7.2849 |

四阵列 normalization scale 相对极差为 `4.67%`，但简单公共平均 EEP 均失败；原因是逐阵元复相位差会在平均时抵消，而不是端口幅度异常。每阵列独立的最优复 rank-1 骨架稳定解释 `>95%` 加权能量，1×8 最高为 `98.516%`，说明“相干低秩骨架 + 几何残差”值得进入 feasibility pilot。该结果不证明同一个 rank-1 因子可跨阵列复用。

一次仅用 train 的固定线性 Fourier-27 拟合远差于最优 rank-1，因此不把训练方向上的 SVD 左因子做成查表，也不冻结线性角向系数。完整模型使用每阵列独立训练的 `Fourier-27 -> MLP-64 -> complex scalar` rank-1 角向分支、静态复数阵元 gain、解析相位和 geometry-matched CNN 残差；control/candidate 的骨架完全相同，只改变残差传播与方向 gate。

## Feasibility pilot 协议

- paired seeds：`21721, 21722, 21723`；各阵列独立从头训练；
- control/candidate 使用相同 train/validation、优化器、epoch、batch 和 checkpoint 规则；
- 每个阵列只比较自己的 candidate 与 control，不横向比较绝对 NMSE 排名；
- 主指标：validation amplitude linear NMSE；辅指标：complex Ephi operator NMSE、Q NMSE、MAE、四档场强误差、参数量和延迟；
- validation 可用于 checkpoint 选择和 pilot 判断，不能修改结构族、阈值或种子；
- blind-test 在本 pilot 中完全不读取，即使某一阵列提前通过也不例外。

单阵列 feasibility PASS 条件：

1. candidate 相对 control 的 validation NMSE 三种子平均改善至少 `0.30 dB`；
2. 至少 `2/3` 种子正向；
3. complex operator NMSE 与 Q NMSE 的三种子平均均为正向；
4. candidate/control 参数差绝对值不超过 `0.5%`；
5. 全部输出有限，且最强场与最弱场分桶均无超过 `0.20 dB` 的平均退化。

普适性只分三级报告：

- `SUPPORTED_4_OF_4`：四阵列各自 PASS，支持思路普适；
- `PARTIAL_k_OF_4`：仅部分阵列 PASS，报告适用几何，不称普适；
- `NOT_SUPPORTED`：少于两个阵列 PASS，停止该思路。

阈值是 feasibility 筛选，不是正式 confirmatory 结论。任何 PASS 最多允许下一版本另建、预注册且保持 blind-test 隔离的确认实验。

## Feasibility pilot 结果（2026-10-14）

回执：`artifacts/feasibility_pilot_20261014/pilot_summary.json`。四阵列各自使用固定的 16,384 个 train-only 查询、40 epochs、batch 2,048 和 paired seeds `21721/21722/21723`；共 24 个独立 run，checkpoint 只按本阵列 validation amplitude linear NMSE 选择。

| 阵列 | 判定 | amplitude 改善 | complex 改善 | Q 改善 | 解释 |
|---|---|---:|---:|---:|---|
| 1×4 | FAIL | +1.645 dB | +1.718 dB | −0.419 dB | 2/3 主指标正向，但 Q 与最强场稳定性未过门禁 |
| 1×8 | PASS | +1.350 dB | +0.886 dB | +0.993 dB | 长列向 dilation + direction gate 在 3/3 种子稳定正向 |
| 2×4 | PASS | +1.312 dB | +1.206 dB | +1.131 dB | 行对全高混合 + 列向分支在 3/3 种子稳定正向 |
| 4×4 | FAIL | −0.401 dB | −0.572 dB | −0.510 dB | 当前 gated axial candidate 在 2/3 种子不如 isotropic control |

所以本轮只能报告 `PARTIAL_2_OF_4`。结果支持“阵列专属结构”这一实验原则，也说明同一抽象思路不能自动推定对所有几何有效。1×4 与 4×4 的失败结果保持冻结；不得打开 blind-test 做事后结构修订。若继续，应在后续版本另行预注册失败几何的新假设。
