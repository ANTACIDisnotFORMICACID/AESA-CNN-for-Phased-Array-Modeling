## 0. 先记住这段总述

初始项目实际上有两条彼此独立的链路：

1. `simulation.py` 中的物理仿真与 SciPy 优化器，输入阵元幅相和目标角，计算方向图并搜索提高目标方向增益的幅相；
2. `cnn_copilot.py` 中的 CNN，输入已经确定的阵元复权值，预测固定 64×64 网格上的完整复方向图。这个 CNN 是前向代理，不是根据目标角产生权值的智能控制器，也未被原 `main.py` 控制链调用。

V2.1–V2.4 没有简单“加深原 CNN”，而是重新厘清任务分工：已知的阵列传播交给物理模型，CNN 改为从目标、解析初值和校准状态中学习少量非理想残差，输出真正应下发的阵元权值。V2.5 又把原版“权值→64×64 完整复方向图”能力以零参数物理观察器补齐。最新完整链路是：

```text
目标方向 + 标称几何 + 一次近场校准/状态
                 |
                 v
         解析波束权值 w0
                 |
                 v
     轻量拓扑自适应 CNN 学习残差
                 |
                 v
     复圆盘约束 / INT8 输出参考
                 |
          +------+------+
          |             |
          v             v
     实际阵列/FPGA   V2.5 物理观察器
                        |
                        v
                 64×64 完整复方向图
```

因此，组会上最准确的一句话是：

> 新版本保留了 CNN 和全部原算法层面的核心功能，但把“大网络近似已知传播公式”改为“轻量 CNN 学习未知硬件残差，物理层精确完成已知传播”；V2.5 已恢复旧 64×64 完整复方向图接口，同时兼容 4×4 理论阵列和 1×4 实际阵列。

不能把 V2.5 表述为“已经在真实 FPGA 上证明”；也不能把物理实现的 `1e-5` 级 FP32 数值误差称为 CNN 的预测误差。

### 1.2 什么可以直接比较，什么不能

原 CNN 的任务是前向方向图回归；V2.2/V2.4 CNN 的任务是权值控制。两者的 NMSE、增益比和损失含义不同，不能把数值放在同一列后直接断言“精度提高了多少”。公平对比应拆成两组：

- 功能与计算量：原 CNN 前向代理 vs V2.5 前向物理观察器；
- 波束控制质量：解析初值 vs V2.2/V2.3/V2.4 轻量控制器。

V2.1 的非理想误差生成器后来发现相关平滑会降低实际 RMS，因此 V2.1 结果只作为结构探索史，不作为强误差域的公平基准；正式强误差结论从 V2.2 开始。

## 2. 数学符号与评价指标

### 2.1 几何和复权值

设阵元数为 `N`，4×4 时 `N=16`，1×4 时 `N=4`。第 `n` 个标称坐标为

```math
\mathbf r_n=[x_n,y_n,z_n]^T,
```

波数 `k=2π/λ`。方向角 `(θ,φ)` 的单位向量采用项目当前约定：

```math
\mathbf u(\theta,\phi)=
[\sin\theta\cos\phi,\;\sin\theta\sin\phi,\;\cos\theta]^T.
```

阵元权值为

```math
w_n=a_n e^{j\psi_n}=I_n+jQ_n.
```

代码内部主要使用 I/Q 两个实通道，因为常规深度学习和后续定点硬件都以实数张量实现。

### 2.2 理想与非理想远场

理想远场阵列因子为

```math
E(\theta,\phi)=\sum_{n=1}^{N}w_n
e^{jk\mathbf r_n^T\mathbf u(\theta,\phi)}.
```

考虑位置误差 `Δr_n`、阵元复响应 `g_n=(1+ε_{a,n})e^{jε_{φ,n}}` 和复互耦矩阵 `C` 后，统一写成

```math
\mathbf E=\mathbf S(\mathbf r+\Delta\mathbf r)
\operatorname{diag}(\mathbf g)\mathbf C\mathbf w.
```

这条式子是 V2.2 非理想仿真、V2.4 稀疏测量和 V2.5 完整方向图观察器的共同物理主线。

### 2.3 解析初值

若要把主瓣指向 `u_t`，按本项目传播相位符号，理想相位共轭权值为

```math
w_{0,n}=e^{-jk\mathbf r_n^T\mathbf u_t}.
```

代回目标方向，传播相位与权值相位抵消，理想目标场幅度为 `N`。CNN 不从零猜测全部权值，而是在 `w0` 上预测小残差：

```math
\hat w_n=\Pi_{\mathcal D}
\left\{w_{0,n}\left[(1+\delta_{r,n})+j\delta_{i,n}\right]\right\},
```

其中 `Π_D` 把复数投影到单位复圆盘，保证 `|w_n|≤1`，对应有限幅度执行器。

### 2.4 报告里的常用指标

- `oracle 增益比`：模型目标方向功率或增益相对于同一非理想 realization 的 oracle 最优权值；越接近 100% 越好。
- `增益差(dB)`：模型与 oracle 的目标增益差；越接近 0 越好。
- `复场 NMSE`：`10log10(||E_hat-E||²/||E||²)`；越负越好。
- `相位 MAE`：通常先消除不影响方向图的公共相位，再计算阵元相位误差。
- `P05`：oracle 增益比分布的第 5 百分位，用来观察尾部可靠性。
- `MAC`：按卷积/全连接每次乘加为一个 MAC；复乘累加按 4 个实 MAC。三角函数、激活、内存搬运通常另计。

## 3. 初始项目到底做了什么

### 3.1 原物理仿真链

代码入口是 `main.py:45` 的 `process_single_file()`。其核心过程为：

1. `simulation.py:75` 的 `set_origins()` 建立阵元位置、幅度和相位；
2. `simulation.py:157` 的 `set_targets()` 建立目标方向；
3. `simulation.py:64` 的 `sumup()` 或向量化逻辑叠加复场；
4. 若启用优化，`simulation.py:238` 的 `optimize_phases_and_amps()` 用 SciPy `L-BFGS-B` 搜索幅相；
5. `visualization.py:245` 的 `generate_image_and_write_json()` 输出方向图 JSON 和图像。

其目标函数本质上是最大化指定目标方向的阵列增益：

```math
\min_{\mathbf a,\boldsymbol\psi}
-\left|\sum_n a_n e^{j(\psi_n+k\mathbf r_n^T\mathbf u_t)}\right|,
```

并对幅度和相位施加边界。历史实现只把第一个目标用于优化，因此“支持多个 target 的输入格式”不等于“联合优化多目标波束”。这条传统优化链与 CNN 训练是两个不同程序。

### 3.2 原方向图 CNN 的任务

原 `cnn_copilot.py` 读取历史 JSON 中已经应用的阵元幅度和相位，转成 `[B,N,2]` I/Q；输出 `[B,2,64,64]`，两个通道分别是远场实部和虚部。历史网格为：

```text
theta: 60°...120°，64点
phi:  -30°... 30°，64点
```

网络结构位于 `cnn_copilot.py:469`：

```text
[B,N,2]
  -> ComplexConv1d 1->64->128->64 + ComplexTanh
  -> 对阵元轴做带mask全局平均，得到128个实特征
  -> Linear 128->512->4096
  -> reshape为复64通道、8×8
  -> 3层ComplexConvTranspose2d: 8->16->32->64
  -> 复输出头
  -> [B,2,64,64]
```

关键实现位置：复一维卷积 `cnn_copilot.py:195`，复二维卷积 `:224`，复反卷积 `:246`，`ComplexTanh` `:270`。总参数 `2,352,770`。历史真实 1×4 输入的计算量是 `29,552,128 MAC/样本`；早期 `31,932,928` 是把输入长度按 `N=16` 代入的结构示例，不应再称为历史 1×4 实算。

### 3.3 原 CNN 为什么采用复数编码、编码器—解码器和 GAP

- 复数 I/Q 与阵列叠加的物理量一致，避免幅相在 `±π` 处不连续。
- 一维卷积试图从阵元序列提取局部组合特征，反卷积解码器把低维表示放大为 64×64 图。
- GAP 使不同阵元数可以汇聚成固定长度，便于变长输入和固定 FC。
- `ComplexTanh` 用有界非线性稳定中间复特征。

这些选择在“输入长度可能变化、输出固定图像”的工程语境里是可理解的，但物理上存在明显代价：GAP 弱化阵元身份和坐标关系；FC/反卷积再用 235 万参数重构一个已知线性传播映射；几何、波长、位置误差、互耦和角网格没有显式输入，换拓扑时不能保证泛化。网络也不是全程复数：中间 FC 是实值 Linear/ReLU，进入解码器时虚部被重新置零，因此准确名称应是“带实数瓶颈的复卷积编码/解码器”。

### 3.4 AdamW 的意义，及它与物理优化器的区别

训练器位于 `cnn_copilot.py:576`。实际训练入口使用 `AdamW(lr=5e-4, weight_decay=2e-4, betas=(0.9,0.999))`，batch=4，最多 200 epoch，配合余弦退火到 `1e-6`、patience=20 和梯度裁剪 1。

AdamW 对第 `t` 步梯度 `g_t` 维护一、二阶矩：

```math
m_t=\beta_1m_{t-1}+(1-\beta_1)g_t,
\qquad
v_t=\beta_2v_{t-1}+(1-\beta_2)g_t^2,
```

在偏差校正后做自适应步长，并把权重衰减与梯度更新解耦：

```math
\theta_{t+1}=(1-\eta\lambda)\theta_t
-\eta\frac{\hat m_t}{\sqrt{\hat v_t}+\epsilon}.
```

选择它的合理原因是：复卷积/反卷积各层梯度尺度差异大，自适应矩估计能提高离线训练稳定性；解耦权重衰减比把 L2 混入自适应梯度更清晰，有助于约束大模型。它不是波束成形物理求解器，也不在 FPGA 在线运行。

必须区分：

| 名称 | 优化对象 | 目标 | 运行阶段 |
|---|---|---|---|
| SciPy L-BFGS-B | 一次任务的阵元幅度/相位 | 提高目标方向增益 | 原仿真/控制流程 |
| AdamW | CNN 的全部可训练参数 | 降低训练集/验证集回归损失 | 离线训练 |

不能说“AdamW 替代了相控阵优化”；它只训练网络。V2 新版本继续可用 AdamW 训练轻量 CNN，但在线只做一次前向推理。

### 3.5 原 CNN 的历史结果和边界

历史记录为：标准化复损失 `0.00282475`，反标准化后的复场 NMSE `-28.592 dB`，平均样本相对 L2 `3.416%`，幅度相关系数 `0.99854`，CPU batch=1 中位时间约 `3.99 ms`。

这些数据只证明网络能拟合历史固定 1×4、固定波长和固定网格的仿真分布。它们不证明 4×4 泛化，不证明真实阵列补偿，也不证明比解析公式更精确。旧样本波长 `6.83`，而 V2 默认配置为 `6.36502`；不能混用 checkpoint 后宣称跨频率有效。

## 4. P0 修复：为什么必须先做，修了什么

P0 的原则是只修复会破坏数据可信性、复现性或基础逻辑的问题，不改变研究任务。详细记录在根目录 `P0修复与FPGA迁移分析.md`。

| 初始风险 | 修复 | 代码落点 | 为什么不改变算法语义 |
|---|---|---|---|
| 初始/优化后两张图可能分到训练与验证，形成同一次仿真泄漏 | 按 `run_id` 分组切分，并跳过 sidecar JSON | `cnn_copilot.py:124,162` | 只修正样本划分 |
| 验证集自己拟合 scaler，损失口径不一致 | scaler 只在训练集拟合，验证/推理复用状态 | `cnn_copilot.py:19,320` | 保持同一标准化定义 |
| Padding 后卷积和 GAP 会把补零当信号 | 每层后恢复 valid mask，最终做 masked GAP | `cnn_copilot.py:291,469` | 使变长批处理等价于有效序列 |

| checkpoint 缺少 scaler、配置、split 和历史 | 保存模型、scaler、配置、split 和历史并严格加载 | trainer checkpoint 路径 | 增强推理可复现性 |

回归证据包括：4 个有效方向图、1 个 sidecar 被跳过；训练/验证 `run_id` 交集为 0；固定阵元数修复前后最大差 0；短序列单独推理与 padding 批推理最大差 `2.98e-8`；checkpoint 恢复输出一致；物理优化器 smoke test 的目标增益从 `0.491223` 提升到 `3.0`。

数据当时只有 4 个有效样本、2 个 `run_id`，因此 P0 后没有把一次小数据重训包装成新泛化结论。这也是报告可信性的边界。

P0 checkpoint 仍未包含 optimizer/scheduler 状态、完整 RNG 状态、阵列几何和 schema 版本，因此可以恢复基础推理，却不能称为无缝续训或安全跨几何部署。

仍保留在 legacy 路径的已知问题：旧复卷积 bias 的组合不完全符合标准复 bias 数学定义；原 SciPy 目标只优化第一个 target；smoke test 得到 3 而解析理想上界为 4，说明局部优化仍可能未达全局最优。V2 控制器使用实值 I/Q 卷积和解析初值，没有复制旧复卷积 bias 实现。

## 5. 为什么不继续扩张原 235 万参数 CNN

### 5.1 关键判断

对于固定几何和网格，权值到远场是已知线性映射：

```math
\mathbf E=\mathbf S\mathbf w.
```

用大 CNN 学这条映射，相当于用数据逼近已经知道的矩阵乘法。真正未知、值得学习的部分是 `Δr`、`g`、`C`、温漂和硬件非线性造成的控制残差。因此把 CNN 从“传播解码器”移动到“权值校正器”既保留 CNN，又更符合智能波束成形目标。

### 5.2 四项修改意见如何转成研究决策

| 修改意见 | 决策 | 验证版本 |
|---|---|---|
| 4×4 输入二维化、增加合理卷积通道、评估 GAP | 4×4 用真实 3×3 二维邻域；1×4 用 1×3，绝不伪造成 4×4；对 2D/1D/broadcast/GAP-only 做消融 | V2.1–V2.2 |
| 近远场推导给 FC 物理初值，减少数据和层数 | 用 Tikhonov 近场逆和远场矩阵直接构造冻结线性层，仅训练低秩 adapter | V2.3 |
| 注入位置/幅相误差，理想或合成预训练后少量误差域微调 | 校准 RMS 后加入位置、幅相、空间相关梯度、局部互耦和噪声；按 profile 无泄漏切分；比较预训练、微调、从头训练 | V2.2–V2.4 |
| 每组幅相只能测数十点 | 明确 `Q×P×M×R` 数据预算，设计 D-optimal 测点并分别验证相干 I/Q、未知公共相位和仅功率 | V2.4 |

### 5.3 4×4 理论与 1×4 实物如何统一

统一的是物理接口、损失、校准逻辑和残差控制思想，不是强迫两者使用同一卷积核：

- 4×4 有二维邻域，使用 `3×3 depthwise Conv2d`；
- 1×4 只有一维孔径，使用 `1×3 Conv2d`，其数值与相同权重的 Conv1d 等价；
- 几何坐标作为显式输入，阵元数和拓扑由配置决定；
- 1×4 即使输出二维角网格，也不会凭算法获得原本不存在的二维孔径自由度。

这正是“用二维卷积解决 4×4 物理结构、同时适配 1×4 实物”的正确方式。把 1×4 reshape/padding 成虚假的 4×4 会引入不存在的邻接关系，反而错误。

## 6. V2.1：4×4 二维物理残差 CNN

### 6.1 结构改动

`beamforming_v2.py:33` 固定 4×4 配置，`:55` 生成坐标，`:149` 生成解析初值，`:203` 构造导向矩阵，`:355`/`:394` 计算非理想远场，`:771` 定义控制 CNN。

每个阵元输入 8 个局部通道：

```text
w0 的 I/Q（2）
校准孔径响应 I/Q（2）
health mask（1）
三维位置误差 Δx/Δy/Δz（3）
```

目标集合被编码成 7 维全局特征，并通过 FiLM 调制残差块。主体是二维 depthwise-separable residual block；输出头零初始化，所以训练开始时 `δ=0`，网络精确退化为解析权值 `w0`。最后由 `project_complex_unit_disk_iq()`（`:258`）执行硬幅度约束。

零初始化不是“让网络什么也不学”，而是把已知正确解作为起点，使梯度只学习非理想修正，降低数据需求并避免随机初值破坏主瓣。

V2.1 训练目标同时约束权值 I/Q、目标增益和幅度越界：

```math
L=L_{IQ}+0.75\left(1-\frac{G(\hat w)}{G(w^*)}\right)^2
+0.25L_{overflow}.
```

这里 `w*` 是使用仿真非理想真值构造的 oracle，只用于训练/评价研究，不是实机可直接观测标签。训练使用 AdamW `lr=2e-3, weight_decay=1e-4`、余弦退火和梯度裁剪 1；这与原 235 万参数 CNN 的 `5e-4/2e-4` 是两套实验超参数。

## 8. V2.3：近远场物理 FC 初始化与少样本迁移

### 8.1 修改建议中的“给全连接层一个物理初值”如何落地

设近场探针位置为 `p_m`，阵元实际复孔径响应为 `a_n`。项目采用的近场 Green 矩阵为

```math
G_{mn}=e^{-jk\|\mathbf p_m-\mathbf r_n\|},
\qquad \mathbf z=\mathbf G\mathbf a+\mathbf n.
```

通过带 Tikhonov 正则的伪逆估计孔径：

```math
\hat{\mathbf a}=
(\mathbf G^H\mathbf G+\lambda\mathbf I)^{-1}\mathbf G^H\mathbf z.
```

远场为 `E=S a`，于是可以直接得到近场到远场的线性变换：

```math
\mathbf T=\mathbf S
(\mathbf G^H\mathbf G+\lambda\mathbf I)^{-1}\mathbf G^H,
\qquad
\hat{\mathbf E}=\mathbf T\mathbf z.
```

复矩阵 `A` 在实值网络中展开为

```math
\begin{bmatrix}
\Re A&-\Im A\\
\Im A& \Re A
\end{bmatrix},
```

因此 FC 权重不是随机数，而是电磁传播与正则逆问题推导出的确定矩阵。代码位置：探针网格 `physics_initialized_frontend.py:27`，Green 矩阵 `:70`，远场矩阵 `:102`，伪逆 `:126`，近远场变换 `:139`，实块矩阵 `:152`，物理初始化估计器 `:175`。

### 8.2 为什么要冻结物理主层，只训练低秩 adapter

物理主层已经表达已知传播；若全部参数自由训练，小数据会把它改坏。V2.3 冻结主矩阵，只训练 rank-4 瓶颈残差 adapter：

```math
\hat{\mathbf a}=\mathbf P_\lambda\mathbf z
+\alpha\mathbf U\tanh(\mathbf V\mathbf z),
\qquad \dim(\mathbf V\mathbf z)=4.
```

adapter 参数仅为 4×4 的 `416`、1×4 的 `136`。这把学习能力集中在模型失配，而不是重新学习完整近远场变换。

实现中的物理 FC 实际写入孔径恢复矩阵 `Pλ` 并输出逐阵元 `a_hat`，随后再由远场层计算 `S a_hat`；代码同时实现并测试了直接近远场矩阵 `T=S Pλ`。保留孔径作为中间表示，能够复用于不同远场角网格，也可直接作为控制 CNN 的校准输入。

### 8.3 数值条件与零训练结果

- 4×4 使用 32 个相干复探针：矩阵秩 16，条件数 `5.248`；
- 1×4 使用 12 个探针：矩阵秩 4，条件数 `3.045`；
- 探针半径达到约 `10λ` 时，4×4/1×4 相位误差约 `1.12°/1.00°`，幅度差仅 `-0.000947/-0.001323 dB`；
- 零训练物理 FC 的远场 NMSE 已达 4×4 `-21.62 dB`、1×4 `-22.91 dB`。

4×4 用 256 profile 训练 adapter 后为 `-22.29 dB`，随机 FC 同数据只有 `-5.86 dB`；16 profile 时物理初始化相对随机初始化改善 `19.245 dB`，95% CI `[18.879,19.611]`。1×4 物理基线已经很强，adapter 256 为 `-22.79 dB`，略差于 `-22.91 dB` 的零训练层，说明可训练层并非必然提升；随机 FC 为 `-9.20 dB`。

## 9. V2.4：数十测点监督和单板适配

### 9.1 从完整图标签改为稀疏观测

实际系统难以对每条幅相命令采完 64×64 图。V2.4 对每条命令只采 `M` 个方向点：

```math
\mathbf y=\mathbf H_M\mathbf w,
\qquad
\mathbf H_M=\mathbf S_M(\mathbf r+\Delta\mathbf r)
\operatorname{diag}(\mathbf g)\mathbf C.
```

第一个测点始终是当前目标方向；其余 `M-1` 个点在 17×13 候选网格上用贪心 D-optimal 准则离线选择。每轮选择最大化 `h_i^H A^{-1}h_i` 的候选行，并用 Sherman–Morrison 更新逆信息矩阵。实现见 `run_v24_sparse_end_to_end_study.py:64–117`，场矩阵构造见 `:179–234`。

目标方向在损失中的总权重固定为 25%，避免 `M` 增大后主目标被大量旁侧点稀释。

### 9.2 为什么推荐 32 点和 8 点

| 拓扑 | M | 满列秩率 | 条件数中位/P90/最大 | 判断 |
|---|---:|---:|---:|---|
| 4×4 | 8 | 0% | — | 欠定，只能依赖强先验 |
| 4×4 | 16 | 99.95% | 21.67/184.55/145750.84 | 方程数下限，尾部严重病态 |
| 4×4 | 24 | 100% | 1.655/1.741/1.787 | 良态起点 |
| 4×4 | **32** | **100%** | **1.465/1.547/1.604** | 推荐 |
| 1×4 | 4 | 100% | 8.737/38.558/10213.97 | 方程数下限，尾部病态 |
| 1×4 | 6 | 100% | 1.482/1.657/1.686 | 良态起点 |
| 1×4 | **8** | **100%** | **1.509/1.564/1.591** | 推荐 |

推荐值不是仅由平均增益决定，而是同时考虑满秩、条件数、噪声和模型失配余量。4×4 用 8 点也可能得到较高目标增益，是“解析初值+小残差 CNN”的强先验效果，不代表 8 个复测点能唯一恢复任意 16 阵元孔径。

### 9.3 三种测量条件必须使用三种损失

相干接收、绝对相位稳定时：

```math
L_{coh}=\frac{\sum_m\rho_m|\hat y_m-y_m|^2}
{\sum_m\rho_m|y_m|^2}.
```

每次采集有未知公共相位时，先求最优公共相位对齐：

```math
\alpha^*=\frac{\sum_m\rho_m\hat y_m^*y_m}
{|\sum_m\rho_m\hat y_m^*y_m|},
\qquad
L_{inv}=\frac{\sum_m\rho_m|\alpha^*\hat y_m-y_m|^2}
{\sum_m\rho_m|y_m|^2}.
```

仅有功率读数时：

```math
L_{pow}=\frac{\sum_m\rho_m(|\hat y_m|^2-|y_m|^2)^2}
{\sum_m\rho_m|y_m|^4}.
```

三类损失在 `sparse_beamforming_v24.py:89` 的 `SparseFieldObjective` 中实现。

关键结果：

| 拓扑/监督 | M | oracle 比例 | 方向图指标 |
|---|---:|---:|---:|
| 4×4 相干 I/Q | 32 | 98.904% | P05 97.771%，增益差 -0.0959 dB，NMSE -17.17 dB |
| 1×4 相干 I/Q | 8 | 99.262% | P05 97.965%，增益差 -0.0645 dB，NMSE -18.05 dB |
| 4×4 相位不变 I/Q | 32 | 99.152% | 对齐 NMSE -19.26 dB |
| 1×4 相位不变 I/Q | 8 | 99.428% | 对齐 NMSE -22.28 dB |
| 4×4 错误绝对 I/Q | 32 | 23.503% | 对齐 NMSE -2.23 dB |
| 1×4 错误绝对 I/Q | 8 | 24.152% | 对齐 NMSE -2.36 dB |
| 4×4 仅功率 | 32/64/96 | 98.838/98.817/98.837% | 功率 NMSE约 -20.2 dB |
| 1×4 仅功率 | 8/12/16 | 99.386/99.362/99.364% | 功率 NMSE约 -24.3 dB |

“错误 I/Q”从约 99% 跌到约 24% 是最有力的物理一致性例子：损失必须尊重测量系统的不变量。仅功率的高目标增益仍主要受强先验约束，且当前测点少于一般复孔径常见的 `4N-4` 强度观测规模；不能称为已经证明通用相位恢复唯一性。

### 9.4 数据量必须写成 Q×P×M×R

```text
Q：独立阵列/环境 realization 数
P：每个 realization 的不同幅相命令数
M：每条命令的远场方向测点数
R：每点重复测量次数
远场观测数 = Q×P×M×R
近场校准数 = Q×M_cal×R_cal
```

推荐配置的实际预算：

| 场景 | 4×4远场复观测 | 4×4近场 | 1×4远场复观测 | 1×4近场 |
|---|---:|---:|---:|---:|
| 合成预训练 Q=96,P=8 | 24,576 | 3,072 | 6,144 | 1,152 |
| 单板 P=8 | 256 | 32 | 64 | 12 |
| 单板 P=16 | 512 | 32 | 128 | 12 |
| 单板 P=32 | 1,024 | 32 | 256 | 12 |
| 单板 P=64 | 2,048 | 32 | 512 | 12 |
| 单板 P=128 | 4,096 | 32 | 1,024 | 12 |

每条命令的 30 dB SNR 标签只生成一次，`R=1`；SGD 多次读取同一标签不重新计为实测样本。source train 为 96 profile×8 方向，target validation 为 24×8，只用于选模；target test 为 48×8，选模后才评价。单板的 128/64/64 条 train/validation/test 方向互不重叠。

### 9.5 预训练、一次近场校准和微调

必须准确表述为：

```text
理想解析初值
 + 多样化合成非理想数据预训练
 + 目标板一次近场物理校准
 + 独立validation决定是否进行远场微调
```

当前 CNN 预训练不是“纯理想数据训练”；理想知识通过解析权值和物理伪逆注入，学习数据则包含合成非理想。尚未做“纯理想 CNN 预训练 vs 非理想微调”的一对一消融。

五种子单板曲线中，零远场更新平均为 4×4 `98.734%`、1×4 `99.403%`。全参和仅 34 参数输出头微调没有稳定提高目标增益。独立 validation 最终为两种拓扑都选择 `zero_shot` checkpoint：

| 拓扑 | seed | oracle 比例 | P05 | 增益差 | NMSE |
|---|---:|---:|---:|---:|---:|
| 4×4 | 24003 | 98.765% | 97.870% | -0.1081 dB | -19.01 dB |
| 1×4 | 24001 | 99.541% | 98.839% | -0.0400 dB | -29.61 dB |

“zero-shot”是零远场训练命令更新，不是零真实信息：仍接入该板一次近场校准，4×4 为 32 点，1×4 为 12 点。

1×4 零更新相对 P=16/32/64/128 从头训练的 oracle 比例配对改善分别为 `+0.007992/+0.004598/+0.004989/+0.004678`，95% CI 均不跨 0，NMSE 改善分别为 `5.633/6.421/5.979/5.608 dB`，即约 `5.6–6.4 dB`。4×4 不存在同样一致优势：从头训练的目标增益有时略高，而微调可能改善方向图 NMSE、却牺牲目标增益。这是 Pareto 权衡，不能宣称预训练对两种拓扑、所有指标都全面更优。

一次早期试验曾错误使用 test 选种子，已完整废弃并删除相关 checkpoint/golden vectors；发布结果只由独立 validation 选择。这一点应主动说明，体现实验纠错而不是隐藏过程。

### 9.6 INT8 复圆盘输出参考

两个 I/Q 分量不能各自独立量化到方形 `[-127,127]^2`，因为角点会违反 `|w|≤1`。V2.4 求解最近整数复圆盘格点：

```math
\mathbf q^*=\arg\min_{q_I,q_Q\in\mathbb Z}
\|\mathbf q-127\mathbf w\|_2^2,
\quad q_I^2+q_Q^2\le127^2.
```

`sparse_beamforming_v24.py:24` 的 `ComplexDiskInt8Quantizer` 给出算法级全局最近格点参考。

| 拓扑 | FP32 oracle | INT8 oracle | 比例退化 | 增益差退化 |
|---|---:|---:|---:|---:|
| 4×4 | 98.765% | 98.415% | -0.003495 | -0.03079 dB |
| 1×4 | 99.541% | 99.203% | -0.003386 | -0.02960 dB |

最大整数半径平方均为 `16129=127²`，FP32 权值违规率为 0。独立 I/Q 四舍五入后约 `57.910%/55.078%` 的阵元需要调整回圆盘。当前只是严格的输出 golden reference；CNN 内部仍为 FP32，不能称为全 W8A8 bit-exact，也没有把最近格点搜索综合成硬件。

## 10. V2.5：恢复原完整方向图功能

### 10.1 “原功能未原样保留”究竟是什么意思

V2.4 控制器和原 CNN 的映射方向相反：

```text
原CNN：给定权值 w -> 预测完整复方向图 E
V2.4：目标角/校准状态 -> 生成应下发的权值 w
```

V2.4 在训练和评价内部已有物理场计算，但正式训练使用稀疏点，held-out 评价网格是 21×21；缺少的是与旧版一致的 64×64 公开调用外形和 JSON 封装，而不是阵列因子公式消失。

V2.5 在 `full_pattern_v25.py` 增加零参数 `FullPatternPhysics`（`:207`）和 `V25BeamformingSystem`（`:463`），完整链路为：

```text
目标/校准 -> V2.4 CNN -> w -> 实际阵列
                           `-> V2.5物理层 -> 64×64复方向图
```

### 10.2 数学和兼容契约

V2.5 计算

```math
E(\theta,\phi)=\sum_n g_n(Cw)_n
e^{jk(\mathbf r_n+\Delta\mathbf r_n)^T\mathbf u(\theta,\phi)}.
```

支持：4×4/1×4、任意角网格/旧 64×64 网格、I/Q 输入/旧幅相输入、位置误差、幅相响应、复互耦，以及旧 `mag_db_rows`、`phase_rows`、`applied_amp_errors`、`applied_phase_errors_rad` 字段。

旧网格严格为 theta 60°–120°、phi -30°–30°，均 64 点；输出形状 `[B,2,phi,theta]`，行是 phi、列是 theta。历史 1×4/波长 6.83 的显式配置在 `full_pattern_v25.py:39`，幅相适配在 `:51`，网格契约在 `:91`，互耦在 `:160`，完整图层在 `:207`。

输出包括复 I/Q、线性幅度、绝对 dB、每样本峰值归一化 dB、`[0,2π)` 相位和明确的角轴。固定几何的导向矩阵会缓存，但以 `persistent=False` 注册，不进入控制器 checkpoint。`render_pattern=False` 可让在线 FPGA 链只输出 4 或 16 个复权值。

### 10.3 为什么不恢复旧 235 万参数解码器

- 传播公式已知，物理层精确且零训练参数；
- 旧代理只在固定 1×4、固定波长和固定网格上训练；
- 几何/误差/互耦没有显式输入；
- GAP 弱化阵元身份，大 FC/反卷积占用大量存储和 MAC；
- 若实测存在未建模残差，应在物理输出上增加经过独立实测验证的小残差模块，而不是无条件恢复整个旧网络。

## 11. 从初始算法到 V2.5 的总对照

### 11.1 功能职责变化

### 11.3 质量结果不能混成一个“准确率”

| 结果 | 数值 | 正确解释 |
|---|---:|---|
| 原 CNN 复场 NMSE | -28.592 dB | 历史理想1×4分布上的学习代理误差 |
| V2.2控制器 4×4/1×4 oracle比 | 99.038%/99.371% | 强误差目标域中的权值控制质量 |

| V2.4发布checkpoint oracle比 | 98.765%/99.541% | 独立单板validation选出的zero-shot测试值 |

## 12. 初始历史数据为何不能代表一般 4×4 问题

经固定历史产物审计，原 CNN 的 1,000 个样本具有以下条件：

- `x_num=1,y_num=4`，实际为 1×4；
- 波长 `6.83`，间距配置 `x_dis=6.83,y_dis=15`；
- theta 60°–120°、phi -30°–30°，各 64 点；
- 阵元幅度独立均匀于 `[0,1]`，相位独立均匀于 `[0°,360°]`；
- 幅度误差和相位误差全部为 0；
- 输入不含目标角；生成脚本未固定 Python `random.seed`。

该线阵的历史标签沿 phi 方向完全不变，1,000 个样本的最大行间复场差为 0。也就是说，名义 64×64 图实际上只有 64 个不同 theta 采样。这解释了旧 CNN 为什么能得到很高的幅度相关性，也说明其任务明显简单于一般 4×4 面阵的二维方向图。

历史模型重新推理得到标准化复损失 `0.0028247529`，与报告 `0.002825` 绝对差 `2.471e-7`；实/虚 MSE 为 `0.001432215/0.001392538`，线性幅度 MAE `0.023849`，dB 幅度 MAE `0.2569 dB`，峰值 -20 dB 以上区域相位 MAE `1.440°`。完整过程材料属于早期历史归档，当前仓库仅保留本节结论与 V2.5 的可复核发布产物。

按旧语义重新训练 200 epoch，epoch 1 的 train/val 为 `0.730686/0.146807`，epoch 200 为 `0.000125/0.002980`，最佳 val `0.002976` 出现在 epoch 189；与历史 200 点验证曲线相关系数 `0.9764`。这是趋势复现，不是跨软件/硬件环境逐位复现。

## 16. FPGA 前的算法冻结判断

### 16.1 当前已经匹配的部分

- 控制核心小：4×4 `5,538参数/67,104 MAC`，1×4 `4,962/15,264`；
- 主体由 1×1、depthwise 3×3/1×3 卷积和 ReLU6 构成，较接近 Vitis AI/DPU 常见算子；
- I/Q 输入输出明确；目标 7 维特征可由 PS/LUT 预计算；
- 输出单位复圆盘约束和 INT8 golden vectors 已定义；
- 4×4/1×4 的张量形状和权值语义已经显式化；
- `render_pattern=False` 允许在线只输出阵元权值。

### 16.2 仍不应直接声称可下板的部分

- CNN 内部尚未完成 QAT/PTQ 的全 W8A8 等价验证；
- FiLM、残差复乘、tanh/复圆盘投影、最近整数圆盘搜索不一定全部落入 DPU；
- 尚未导出并验证 ONNX、XIR/DPU 模型；
- 目标角三角函数、动态导向相位和完整图的 log/atan2 需要明确放在 PS、LUT、HLS 或主机；
- 没有板级吞吐、时延、BRAM/DSP/LUT、功耗和闭环波束指标；
- 当前 1×4 坐标、实际频率、移相/衰减码本、通道失效格式仍需由实物参数替换。

实时系统建议：FPGA/DPU 只运行轻量控制器并输出 4 个或 16 个复权值；完整 64×64 图留在主机做显示和验收。若必须在 FPGA 渲染完整图，可把固定导向矩阵放 ROM 后流式复 MAC；4×4 FP32 缓存 512 KiB，1×4 128 KiB，小器件需研究 INT16/INT8 表、URA 可分离结构或分块流式。动态位置误差不能直接复用固定导向缓存，应尽量并入慢速离线校准矩阵。

## 18. 组会高频问答

### 18.1 定位与任务

**问：原来的 CNN 不就是智能波束成形吗？**

不是。原 CNN 输入已经确定的阵元幅相，输出方向图；它不读取目标角、不输出控制权值。当前 CNN 才位于目标/校准到权值的逆向控制位置。

**问：V2.5 是否把原 CNN 删除了？**

没有删除 CNN 这一研究要求。智能控制 CNN 完整保留；只把“权值到方向图”的已知传播从大型学习解码器换成零参数物理层，并恢复相同的 64×64 功能和旧 JSON 契约。

**问：既然有物理公式，为什么仍需要 CNN？**

公式负责已知传播；CNN 学位置偏差、通道幅相、互耦、温漂等模型失配对最优控制权值的残差。若实测证明没有稳定残差，CNN 输出可退化为零修正，但研究接口仍保留。

**问：V2.5 是否提高了 V2.4 的波束质量？**

没有自动提高。V2.5 新增完整图观察和兼容接口；控制器 checkpoint 和输出逐位不变，波束质量沿用 V2.4 指标。

### 18.2 几何、二维卷积和 GAP

**问：阵列几何是否被优化算法修改？**

没有。4×4 和 1×4 是两个显式固定配置，算法只读取坐标；误差 `Δr` 是仿真/校准变量，不是把设计几何改成另一种阵列。

**问：为什么 4×4 要二维卷积？**

互耦、幅相偏差和位置邻域在面阵上有二维局部结构，3×3 核提供正确归纳偏置。V2.2 显示目标增益相对 1D 有小而稳定的优势，同时 GAP-only 明显退化。

**问：为什么 1×4 不也 reshape 成 4×4？**

那会制造 12 个虚假阵元和不存在的二维邻接。1×4 用 1×3，既保持 Conv2d 工具链接口，又与同权重 Conv1d 数值等价。

**问：GAP 是否完全错误？**

不是。原任务中它解决变长到固定 FC 的工程问题；但对逐阵元控制，纯 GAP 会弱化绝对身份。当前可以使用全局目标上下文，但不能用 GAP 替代局部逐阵元特征。

**问：为什么没有继续增加通道数？**

容量扫描没有单调收益；width 16 已接近或优于更宽模型。增加通道会提高参数、MAC 和量化难度，只有实测欠拟合证据才值得扩张。

### 18.3 物理初值与优化器

**问：物理初值具体是什么，不只是口号吗？**

有两层：权值初始为解析共轭导向 `exp(-jkr·u_t)`；近场 FC 权重直接写成 `S(GᴴG+λI)⁻¹Gᴴ` 的实 I/Q 块矩阵。后者零训练已取得 -21.62/-22.91 dB NMSE。

**问：为什么物理层还要正则化？**

直接逆会放大噪声和小奇异值。Tikhonov 的 `λI` 在偏差和噪声放大之间折中；同时通过探针设计保证满秩和较低条件数。

**问：为什么只训练 rank-4 adapter？**

已知主映射不应被少量数据重写；低秩残差限制自由度，降低过拟合和灾难性遗忘，并把训练集中在未建模失配。

**问：AdamW 和 L-BFGS-B 谁更好？**

它们不解决同一问题。AdamW 离线训练网络参数；L-BFGS-B 为一条任务搜索阵元幅相。原项目没有 AdamW/Adam/SGD 公平消融，因此只能说 AdamW 是合理基线，不能说最优。

**问：为什么不用原 L-BFGS-B 直接部署？**

单目标理想问题有解析解，L-BFGS-B 反而可能停在局部点；加入非理想和复杂约束后逐任务迭代的时延又不确定。轻量 CNN 可把离线学习压缩成固定时延前向推理。

### 18.4 非理想、预训练和数据量

**问：V2.1 已经验证 13%/22°/0.02λ 了吗？**

不能这样说。平滑后实际 RMS 约 7.09%/12.63°/0.00966λ；V2.2 修正生成器后才真正达到目标 RMS，正式强误差结论应引用 V2.2 以后。

**问：预训练是不是只用无误差理论数据？**

不是。无误差理论用于解析初值和物理矩阵；CNN source 训练使用多样化合成非理想数据。纯理想 CNN 预训练与非理想微调尚未单独做一对一消融。

**问：为什么少量数据可以微调？**

网络不是从零学习任意映射，而是在解析/物理初值附近学习低维残差；V2.3 中预训练+16 profile 明显优于从头64。但这种优势依赖同板数据，跨板残差可能负迁移。

**问：为什么 V2.4 最后反而选择不微调？**

独立 validation 显示少量远场命令的全参或头部更新没有稳定提高目标增益。科学结论应服从验证集，因此选择零远场更新，而不是为了满足“微调”形式强行更新。

**问：zero-shot 是否完全不采真实数据？**

不是。它只表示零远场训练命令更新；仍需要该板一次近场校准，4×4 32 点、1×4 12 点。

**问：需要多少实际数据？**

相干 I/Q 的起步协议是每条命令 4×4 32 点、1×4 8 点；先做一次近场校准，再从 `P=8/16/32/64/128` 形成学习曲线。最终数量不能只报 P，必须同时报告 `Q×P×M×R`。

### 18.5 稀疏测点、相位与功率

**问：为什么 4×4 不只测 16 点？**

16 只是复方程数下限，尾部条件数最大超过 14 万；32 点的 P90 条件数为 1.547，抗噪声和模型失配明显更稳。

**问：为什么 1×4 不只测 4 点？**

4 点虽满秩，但最大条件数超过 1 万；8 点提供过定约束和工程余量。

**问：低于阵元数的测点为何也能有高目标增益？**

强解析初值把解限制在小残差邻域，目标方向又固定占 25% 权重；这不等价于从欠定观测唯一恢复任意复孔径。

**问：公共相位为什么这么重要？**

每次采集的整体相位若漂移，绝对 I/Q 标签彼此矛盾。相位不变损失先对齐等价解；错误处理让 oracle 比例从约 99% 降到约 24%。

**问：仅功率结果很高，是否解决了相位恢复？**

没有。当前有强物理先验，且噪声由相干 I/Q 后平方得到，尚非完整检波器模型；需要多编码激励、平方律噪声和多初始化相位恢复实测。

### 18.6 量化、完整图和 FPGA

**问：为什么 INT8 不能分别量化 I/Q？**

独立范围是方形，角点的复幅度大于 1；执行器可行域是圆盘。超过一半的输出在独立四舍五入后需要调整到整数圆盘内。

**问：INT8 结果是否表示整个网络已经 INT8？**

不是。当前只冻结输出码字的精确 golden reference；内部卷积、FiLM、激活和投影仍是 FP32。

**问：V2.5 的 `1e-15` 精度是否意味着真实方向图也一样准？**

不意味着。它验证软件实现与指定物理公式一致；真实阵列的未建模效应必须用实测集评价。

**问：1×4 为什么也能生成二维 64×64 图？**

任何阵列都可在二维角网格上评价场，但线阵对某些二维方向不可唯一分辨。生成二维图不增加物理孔径自由度。

**问：现在能否直接通过 Docker/Vitis AI 下板？**

还不能宣称直接完成。卷积主体基本友好，但需完成 ONNX 导出、算子审计、QAT/PTQ、DPU 编译、PS/PL 分工、输出投影/量化等价和板级性能闭环。

**问：完整 64×64 图一定要在 FPGA 上计算吗？**

不一定。实时控制只需 4 或 16 个复权值，完整图可留在主机做显示和验收。只有系统明确要求实时图时才值得占用 ROM、DSP 和带宽。

### 18.7 可靠性与结论边界

**问：怎样证明没有数据泄漏？**

历史数据按 run_id 分组；新数据按独立 profile 分组；单板命令方向分为不重叠 train/validation/test；scaler 只在训练集拟合，test 不参与选模。

**问：为什么相信报告里的数字？**

不仅有汇总表，还有逐种子 CSV、训练日志、8 个 checkpoint、两阶段 golden
vectors、中间值、版本输入/输出 JSON 和 6 张图；当前完整包 35/35，总 validator
逐项重算，历史 JSON 也以固定 blob 自包含逐点回放。

**问：当前最主要的风险是什么？**

外部有效性：非理想分布仍是仿真，实际 1×4 坐标、频率、互耦、相位参考、温漂和量化链尚未测量。下一步应先做真实校准协议和模型失配审计，再决定微调或新增小残差模块。

## 19. 汇报时的“可宣称/不可宣称”清单

### 可以宣称

- P0 修复未改变物理公式和旧 CNN 主体语义，修正了切分、标准化、padding、快照和产物可靠性；
- 4×4 使用二维卷积，1×4 使用真实 1×3 拓扑；纯 GAP 在逐阵元控制上显著退化；
- 物理初值和低秩残差明显降低了随机初始化和少样本训练难度；
- 在当前仿真协议下，相干稀疏监督建议 4×4 32 点/命令、1×4 8 点/命令；
- V2.5 功能等价恢复原 64×64 完整复方向图，并且不改变 V2.4 控制输出；
- 当前端到端 MAC 相对原完整图 CNN 至少降低约 97×（4×4含完整图）和 365.7×（1×4含完整图）；只在线输出权值时缩减更大；
- 所有结论均有明确代码、逐样本/逐种子产物和自动门槛。

### 不可宣称

- 原 CNN 已完成智能波束成形或在 4×4 上训练验证；
- AdamW 已被证明优于所有优化器；
- V2.1 已验证名义强误差 RMS；
- 仅功率低测点已经唯一恢复一般复孔径；
- 预训练对 4×4/1×4 所有指标都必然优于微调或从头训练；
- V2.5 的浮点一致性就是实物方向图精度；
- 当前 INT8 是全网络 W8A8；
- 当前已完成 FPGA/Vitis AI 部署、板级实时性或功耗验证。

## 20. 最终答辩结论

本项目的算法演进不是简单把原 CNN 换成另一个 CNN，而是完成了任务重构和证据补全：

1. 保留原相控阵数学模型和 CNN 研究要求；
2. 把已知传播与未知硬件残差分工，解析/物理层负责前者，轻量 CNN 负责后者；
3. 用真实拓扑表达 4×4 与 1×4，而不是用 reshape 伪造统一；
4. 用物理初始化、低秩适配和无泄漏预训练降低数据需求；
5. 把实测约束写成可执行的 QPMR 预算、相位不变量和 INT8 复圆盘契约；
6. 用 V2.5 恢复并严格验证旧 64×64 完整复方向图能力；
7. 明确当前停在 FPGA 前算法冻结候选，下一步必须由真实 1×4 校准、全链量化和板级闭环给出最终结论。

组会收尾建议使用：

> 目前最有价值的改动不是单一指标增加，而是把一个固定 1×4、理想数据上的大方向图代理，演进成了同时适配 4×4 理论研究与 1×4 实物约束的物理引导智能控制链。已知物理不再浪费网络容量，CNN 聚焦补偿真实非理想；完整方向图、稀疏实测、量化和验证接口又都保留下来。下一阶段的核心问题已从“代码能否运行”转变为“仿真先验在真实板上能保留多少，以及怎样在 Vitis AI/FPGA 中保持数值等价”。
