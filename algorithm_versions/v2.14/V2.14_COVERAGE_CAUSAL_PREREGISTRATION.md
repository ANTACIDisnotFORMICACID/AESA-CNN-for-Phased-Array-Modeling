# V2.14 角域覆盖嵌套因果验证预注册（2026-09-13）

## 问题

冻结 CNN 的逐方向误差与最近训练角距离 Spearman 相关为 `0.638`，但相关不等于因果。
本实验检验：在相同样本预算和相同模型初始化下，将少量有标签方向从已有角格替换到空缺
角格，能否降低其余空缺方向误差。

## 防泄漏设计

- 只在原 `query_train` 的 22600 个方向内部构造 nested experiment；
- 使用既有 checkerboard spatial-gap checkpoint：其训练集为 nested keep，验证集为 nested gap；
- 从每个 nested gap 角格仅按方向几何选择 10 个 maximin augmentation 点，不读取幅度误差；
- augmentation 点加入处理组训练后，从两组共同的 nested evaluation 中永久移除；
- 处理组从 nested keep 随机移除相同数量方向，保证训练方向数和更新步数完全相同；
- 外层 4900 validation directions 只作固定 secondary diagnostic；external test 继续封存。

## 配对条件

对种子 21201–21203 的冻结 `G2-J-LR240_sep0p001_*_gap` checkpoint 分别执行：

- `control`：继续使用原 nested keep；
- `coverage_exchange`：`keep - K random points + K geometry-only gap points`。

两组从相同 checkpoint 开始，固定微调 30 epochs、AdamW、LR=`1e-4`、batch=512，
不按中间 validation 选择 epoch。损失使用冻结 amplitude objective、`db_floor=1e-8` 和相同
residual regularization；不重新施加 separation penalty。

## 固定指标与判定

主要指标为共同 nested-gap evaluation 的 amplitude NMSE；次要指标为 outer validation-D
NMSE、MAE/P95 absolute dB、弱场 NMSE、训练集到 nested evaluation 的最近角距离。

覆盖因果假设记为通过仅当：

1. nested-gap NMSE 平均改善至少 `0.50 dB`，且 3/3 种子同方向；
2. outer validation-D 平均不得恶化超过 `0.10 dB`；
3. 任一种子 outer validation-D 不得恶化超过 `0.50 dB`；
4. 两组预算相同、无 NaN、无 external-test access。

该实验即使通过，也只支持“新增覆盖标签有帮助”，不授予新模型资格；若失败，则 V2.14
不再继续结构或采样调参，直接封版。
