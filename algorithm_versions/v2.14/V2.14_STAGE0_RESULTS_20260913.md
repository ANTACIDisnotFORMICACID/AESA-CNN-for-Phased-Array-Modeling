# V2.14 Stage-0 2×2 结构筛选结果（2026-09-13）

## 结论

按预注册规则，本路线 **Stage-0 stop，不扩展到十种子正式实验**。跨分支 1×1 adapter
和当前强度的去相位包络 jitter 都只产生约 `0.01–0.03 dB` 的名义 NMSE 变化，远低于
`0.15 dB` 扩展阈值；同时 0.5° 包络稳健性没有改善。

这不是证明所有 fusion 或 jitter 都无效，而是排除当前具体实现：8→4→2 zero-start adapter、
0.25°/weight=0.05/interval=4 的 jitter，以及 30-epoch 小学习率微调。

## 聚合结果

|---|---|---|---:|---:|---:|---:|
| C00 | off | off | -24.540 dB | 0 | -29.376 dB | 0 |
| C10 | on | off | -24.560 dB | +0.020 dB | -29.264 dB | -0.112 dB |
| C01 | off | on | -24.552 dB | +0.013 dB | -29.348 dB | -0.028 dB |
| C11 | on | on | -24.565 dB | +0.026 dB | -29.324 dB | -0.052 dB |

三个处理 cell 的名义 NMSE 均在 3/3 种子上略有改善，但最大均值只有 `0.026 dB`，
实际尺度不足。三格的稳健性改善均为负，表示 0.5° 包络输出变化略微增大。

2×2 主效应（正值为名义 NMSE 改善）：

- cross-branch access：`+0.0167 dB`，3/3 同方向；
- jitter regularization：`+0.0091 dB`，3/3 同方向；
- interaction：`-0.0071 dB`，仅 1/3 为正。

adapter correction 能量只占最终包络约 `0.009%–0.010%`，说明它在本次微调中基本保持
为小修正。C11 的平均 MAE/P95 absolute dB 为 `0.738/2.661 dB`，相对 C00 的
`0.741/2.666 dB` 同样只是微小变化。

## 对 CNN 结构优化的更新判断

1. 不继续扩大当前 1×1 fusion，也不扫更多 hidden width；现有结果没有显示容量不足。
2. 不直接提高 jitter 权重。当前正则没有改善目标稳健性，继续调权重容易形成验证集搜索。
3. 下一项应转向 **角域覆盖因果验证**：保持冻结模型结构，使用 train-only 规则对远离训练集
   和已知困难角格进行重采样/加权，再与原采样做等预算配对。只有确认覆盖干预能稳定降低
   validation 长尾，才考虑将其纳入正式训练。
4. 若以后重访 fusion，应换成有明确物理对象的 operator-mode 或低阶/高阶误差路由，而不是
   继续给两个 latent 分支增加通用混合器。
