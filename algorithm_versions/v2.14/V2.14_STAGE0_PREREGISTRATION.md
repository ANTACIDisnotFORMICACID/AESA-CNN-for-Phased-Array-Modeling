# V2.14 Stage-0 预注册：跨分支融合与包络抖动

## 固定目的

验证两个可操作假设，而不是寻找最终模型：

1. SSH 信息直接进入小型 1×1 adapter，是否优于同参数量的 Fourier+geometry adapter；
2. 仅在去相位包络坐标上加入 0.25° 扰动监督，是否降低 0.5° 包络敏感度且不损害名义预测。

## 2×2 因子

| cell | SSH cross-branch access | envelope jitter regularization |
|---|---|---|
| C00 | off | off |
| C10 | on | off |
| C01 | off | on |
| C11 | on | on |

两种 access 条件都保留完全相同的 8→4→2、1×1 adapter。off 条件把 SSH 输入置零，
但保留 Fourier residual 和四张几何图；on 条件只多开放 SSH 输入。adapter head 为零初始化，
因此四格在微调前与各自冻结 V2.12 checkpoint 精确等价。

## 数据与训练边界

- Stage-0 种子：21201–21203，严格配对；
- 初始化：对应冻结 V2.12-S `G2-J-LR240_sep0p001` checkpoint；
- 仅使用原 22600 个 train directions、64 train commands；
- 模型选择只使用 4900 个 validation directions、16 validation commands；
- 微调 30 epochs，AdamW，LR=`1e-4`；其余四格一致；
- 幅度目标保持冻结数据合同的 `db_floor=1e-8`；所有原模型参数和 adapter 一起微调；
- 不重新施加 separation penalty，避免在 2×2 外引入第三个实验因子；
- jitter angle=`0.25°`，每 4 step 计算一次，等效权重 `0.05`；
- 解析传播相位始终使用名义方向，扰动只进入 envelope；
- external test 不得访问，Stage-0 不授予模型资格。

## 预先固定指标

主要指标：validation amplitude NMSE。辅助指标：MAE/P95 absolute dB、弱场误差、0.5°
envelope-only self-change NMSE、adapter 输出能量和逐种子稳定性。

效应均采用配对定义：access effect=`off NMSE - on NMSE`；jitter effect=`off NMSE - on
NMSE`，正值表示处理组更好。三个种子只报告均值、范围及方向一致性，不做正式显著性声明。

## Stage-0 扩展规则

只有同时满足下列条件，才建议扩展为十种子正式实验：

1. 至少一个处理 cell 相对 C00 的平均 validation NMSE 改善不少于 `0.15 dB`，或
   0.5° envelope sensitivity 改善不少于 `0.5 dB`；
2. 该 cell 的平均 validation NMSE 不得恶化超过 `0.10 dB`；
3. 任一种子 validation NMSE 不得恶化超过 `0.50 dB`；
4. 没有 NaN、合同破坏或 test access。

若只改善稳健性，则正式实验必须将名义 NMSE 作为非劣门；若两项都无改善，停止该结构路线。
