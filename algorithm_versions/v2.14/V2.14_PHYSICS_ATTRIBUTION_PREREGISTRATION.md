# V2.14 物理归因附录预注册

本附录依据已冻结计划执行，不创建 V2.15，不改变 V2.14 原 Stage-0、覆盖实验或模型筛选结论。主线只研究 Ephi 复端口算子；Etheta 与三维复场仅作极化、横向性诊断。external-test 方向块和命令全程排除。

## 数据合同

- 半度 FFD 与 V2.12 的 train/validation 方向对齐，只导出 22600/4900 条；不导出 4900 条 test 场值。
- 整数 FFD 仅引用原文件，不复制。Gate-A 八条直接 HFSS 组合复场用于独立路径抽查；若未达到 `-120 dB` 才允许内存重导 AEDT，关闭时 `save=False`。
- `physics_train_validation.npz` 包含 Ephi、Etheta、三维复场、几何、47 GHz S 矩阵和球面权重；S 参数只做归因，不进入 CNN 标签。
- Ephi 对现有 complex-audit 需优于 `-100 dB`，方向误差需小于 `1e-7`。

## 物理残差阶梯

只用 train 拟合和选择，train 内采用三个确定性 10° 空间折；outer validation 在全部选择冻结后只评估一次。

1. P0 公共单元方向图：复数 SSH，`L={1,3,5,8,12}`。
2. P1 逐阵元复增益：均值增益和平均相位规范化。
3. P2 有效相位中心：零均值 gauge、每轴 `±lambda/4`、加权 L-BFGS。
4. P3 S 引导互耦：`I + alpha1*S_off + alpha2*S_off^2`，只拟合两个复系数。
5. P4 corner/edge/interior 类别方向图：和为零、`L<=5`。
6. P5 低秩残差：`rank={1,2,4,8}`，角因子必须由 train-only SSH 回归。

每一模块必须在三折中平均改善至少 `0.50 dB` 且 `3/3` 同方向才可进入下一基线。失败结果保留，但不污染后续阶梯。冻结 V2.12 十种子仅作为 amplitude 性能参照，不读取复数标签。

## 新角域标签合同

- 整数网格经极点、接缝和 `q_x>0` 过滤后必须为 32041 条，按当前 block 分为 train/validation/external-test `22301/4870/4870`。
- 只根据角度和 split，在 49 个 validation block 内各 greedy maximin 选择 10 条，共 490 条 `acquisition_train`；其余 4380 条为 `coverage_probe`。
- `acquisition_train.npz` 只含 64 个 train commands 的幅度；`coverage_probe.npz` 只含 16 个 validation commands 的幅度。
- `complex_audit_only.npz` 只供审计，训练加载器必须拒绝；external-test block 不读场值、不打包。

冻结 CNN 三臂均从 V2.12 种子 21201–21203 的同一 checkpoint 出发，固定 30 epochs、AdamW、LR `1e-4`、batch 512：control=22600，exchange=移除 490 条旧 train 后加入 490 条新标签，plus=23090。

标签价值通过条件：exchange 对 probe 平均改善至少 `0.50 dB` 且 3/3 正向；plus 相对 exchange 平均恶化不超过 `0.10 dB`；处理组旧 validation 平均不低于 control `0.10 dB`、任一种子不低于 `0.50 dB`；指标有限且 external-test 封存。
