# 当前硬件与误差假设

## 已知

- 阵列部署在卫星，服务地面四个接收站。
- FPGA 参数预算、相移器类型、控制位数和测量误差暂时未知。
- 下一轮板上最终仍以单模型为目标，多 seed/ensemble 只用于离线训练和校准。

## 待补充

- FPGA/SoC 型号、时钟、DSP、BRAM/URAM、权重/激活位宽、最大推理时延；
- 仅相位还是幅相控制、相位 bit 数、幅度档位、控制码到复激励 LUT；
- 单阵元/总功率、功放饱和、故障阵元和安全回退；
- 坐标更新周期、总控制延迟和允许的相位变化率；
- 不同频率、温度、功率和批次下的幅相误差。

未知项在下一轮只能进行参数扫描，不得标注为实际硬件验证。
