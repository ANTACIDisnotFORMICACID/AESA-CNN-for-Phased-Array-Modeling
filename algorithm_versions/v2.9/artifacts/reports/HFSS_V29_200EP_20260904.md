# V2.9 HFSS 200 Epoch 实现与训练报告

## 结论

V2.9 已完成独立实现、200 epoch 分阶段对照、200 epoch 全联合训练、validation/test 评估、
结构后验消融、四目标优化和直接 HFSS FFD 重组验证。

当前正式候选为：

```text
artifacts/checkpoints/hfss_47ghz_ephi_v29_joint_200ep.pt
```

它使用 34,973 个参数，相比 V2.8 的 62,098 个参数减少约 43.7%，测试全局幅度 NMSE
由 -16.02 dB 改善至 -16.49 dB。

## 训练合同

- 数据：V2.8 `hfss_47ghz_ephi_amplitude`；
- split：`hfss_47ghz_ephi_seed28001`；
- 方向：45,110/9,660/9,670 train/validation/test；
- 命令：92/18/18 train/validation/test；
- 每轮随机采样 8,192 个训练方向；
- 训练标签只有标量 `|Ephi|`；
- 接收复相位和 S16P 未进入训练输入或损失；
- 设备：CPU，PyTorch 2.13.0；
- 总训练轮数：200。

## 两种调度结果

| 调度 | Epoch 分配 | 参数量 | Validation 全局幅度 NMSE | Test 全局幅度 NMSE |
|---|---|---:|---:|---:|
| staged | 80/40/60/20 | 34,973 | -13.23 dB | -14.14 dB |
| **joint** | **200 全联合** | **34,973** | **-15.83 dB** | **-16.49 dB** |

阶段训练中，nominal 阶段将 validation 从约 -1.17 dB 提升到约 -13.42 dB；耦合阶段只有
约 0.1 dB 的边际收益；独立 residual 阶段没有改善并由 validation 回退到阶段初始状态；
最后 20 个联合 epoch 虽仍改善，但预算不足。

全联合训练在约 150 epoch 后继续稳定改善，最优状态出现在第 200 epoch。因此当前证据支持
保留分层结构，但默认采用联合优化；80/40/60/20 作为消融而不是推荐调度。

## 四目标 HFSS 闭环

使用 `data/fixtures/four_targets.example.json`，优化器预测四目标功率：

```text
[5.913, 5.975, 6.140, 5.714]
```

直接从 16 个 HFSS FFD 复场基底重组得到：

```text
[5.182, 6.565, 5.599, 5.279]
```

- 预测最弱目标功率：5.714；
- HFSS 重组最弱目标功率：5.182；
- HFSS 值约为预测值的 90.7%；
- 模型对最弱目标约有 10.3% 乐观偏差；
- 最大目标到 HFSS 网格角误差：0.111°。

因此优化入口和物理重组闭环已经工作，但下一步必须把最弱目标 regret 纳入模型选择。

## 结论边界

当前 test 在 V2.8 和本轮 V2.9 工程迭代中都已经被读取，因此只能用于同一旧基准上的工程
比较。任何后续结构或超参数修改都必须建立新的未读取命令/角块测试集。当前 HFSS checkpoint
不具备 OTA 部署资格，也不能把内部 C 或 residual 数值解释成真实器件/互耦参数。
