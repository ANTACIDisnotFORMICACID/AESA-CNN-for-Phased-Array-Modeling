# V2.9：固定结构收敛训练与错位网格盲测结果

日期：2026-09-05。状态：`training_complete / dual_blind_complete / acceptance_failed / ota_not_validated`。

## 1. 结论

本轮已完成既定的 10 次训练、三 seed 正式收敛训练和冻结后的两级盲测。
CNN 结构与 34,973 参数量不变，没有修改 V2.8、原始 HFSS 导出或覆盖旧 checkpoint。

- 三 seed 均达到预设的验证平台期判据；整数盲测幅度 NMSE 均值从本轮各自 epoch200 的 -16.9887 dB 改善至 -20.1397 dB，平均改善 3.1509 dB。
- 错位网格保留角块上的均值为 -19.7673 dB，相对整数盲测平均退化 0.3724 dB，满足不超过 0.5 dB 的条件。
- 尚未通过全部验收：seed 样本标准差 0.6444 dB 高于 0.25 dB；30 组四目标相对数值参考的损失中位数 7.2098%、P95 22.1033%，高于 5% / 10%。
- 本轮审计未发现训练、验证、主要盲测之间的命令或角块交叉使用，也未发现用盲测结果反向调参。此结论限于本轮流程，不声称旧整数数据在历史上从未被查看。

因此：更充分的训练已经明显改善前向模型，但“训练完成”不等于“全部验收通过”，更不等于实测部署完成。

## 3. 训练执行与收敛

保持原损失组成：幅度项、dB 项权重 0.03、功率项 0.10；残差能量和耦合 L2 各 1e-4、互易性 1e-3。
AdamW，weight decay 1e-5，梯度裁剪 5；每轮抽取 8,192 个训练方向，每批 1,024 个方向与全部训练命令配对，验证批次 2,048。
因此这里一个 epoch 是既定的方向抽样轮，不是完整 45,140 个方向的一次遍历。

策略仅依据验证集比较：R1 为初始学习率 1e-3 的平台降率；R2 为 20 轮预热加余弦降率；R3 为初始学习率 5e-4 的平台降率。
平台调度等待 25 轮后乘 0.5，最低 1e-5。各阶段从头训练，未从旧 checkpoint 或筛选阶段权重暖启动。

R1 确认阶段验证均值约 -19.1456 dB，优于 R3 的 -18.0243 dB，所以 R1 胜出。

每 25 轮保存优化器、调度器、采样器和随机状态；保留每个正式 seed 的实际 epoch200 状态做配对基线，既非旧项目的 200 轮模型，也非挑选 200 轮以内最优结果。

## 5. 四目标诊断与验收

冻结前已确定的诊断流程：在新网格的保留角块、法向 60° 内生成 30 组四目标；五档最小夹角 2° / 5° / 10° / 20° / 30°，每档 6 组。
使用验证集选出的代表模型，32 起点、600 次更新，优化四目标最小 `|Ephi|²`，命令约束为 `||w||₂=1`。这不是额外训练 CNN，也未修改模型权重。

参考计算使用同一批目标的 HFSS 嵌入式基底相干重组，另做 32 起点数值优化，并包含 CNN 解作为初始候选之一。
相对损失为 `(参考最小值 - CNN 命令的 HFSS 最小值) / 参考最小值`。
参考值是可行数值解形成的下界，并非已证明的全局最优；真正最优参考下的损失可能更大。
结果同时包含前向误差和数值优化误差，不能仅凭此将全部差距归因于 CNN。

| 预先固定的条件 | 本轮结果 | 判定 |
|---|---|---|
| 三个 seed 均达到收敛判据 | 764 / 923 / 847 轮均满足 | 通过 |
| 配对平均幅度 NMSE 改善 ≥0.3 dB | 3.1509 dB | 通过 |
| seed 样本标准差 ≤0.25 dB | 0.6444 dB | 未通过 |
| 任意 seed 不倒退超过 0.1 dB | 三者均改善至少 2.7464 dB | 通过 |
| 功率 NMSE 不整体恶化 | -15.3930 → -18.3061 dB | 通过 |
| dB MAE 不整体恶化 | 1.9818 → 1.3849 dB | 通过 |
| 错位相对整数平均退化 ≤0.5 dB | 0.3724 dB | 通过 |
| 四目标相对损失中位数 ≤5% | 7.2098% | 未通过 |
| 四目标相对损失 P95 ≤10% | 22.1033% | 未通过 |

30 组中有 7 组损失不超过 5%，19 组不超过 10%；最差约 29.6074%（case 26）。全部命令及参考命令的单位二范数约束均经核验。
这些是合成方向的 HFSS 基底重组诊断，没有重新启动 HFSS 求解，也不是已确认的实际四目标坐标验收。
用户此前尚未确认实际目标坐标，因此四目标阈值作为诊断门槛记录，不把它当成已知全局极小点的证明。

## 8. 后续边界与建议

本轮不再调参，当前错位网格的测试结果已经揭示，后续不能继续称其为全新盲测。
如保持结构继续改善，应在新的开发实验中验证：跨 seed 的训练稳定性、仅由训练/验证集产生的难例及优化诱导命令、以及训练期目标相关误差与纯前向误差的关系。
这些是基于本轮失败项提出的后续假设，不是已经验证的修复；不能只补几个 seed 后从已看过的测试成绩中挑一个。
下一轮需预先确定独立留出命令/方向或新测量会话及验收规则，模型与策略冻结后再开启。
对于同一 HFSS 解，继续错位采样仍只验证方向泛化；真实器件误差和实测迁移最终需要独立器件状态或 OTA 数据。
