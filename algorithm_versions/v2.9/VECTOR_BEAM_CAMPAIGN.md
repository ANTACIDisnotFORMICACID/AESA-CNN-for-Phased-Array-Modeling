## 1. 数据与物理结论

24组命令共享47GHz、16端口嵌入式方向图。A01已与HFSS直接报表对齐，其余命令是线性合成，
不能作为24个独立电磁状态。新训练不用这24个诊断命令，尤其不回灌历史四目标优化命令。

波长6.379mm，行/列间距为2.352λ/1.066λ；4×4阵列的阵元中心跨度45×20.4mm。
同相A01峰值14.68dBi，位于θ=115.5°、φ=−8.5°，另有3个相隔至少5°的峰高于峰值−3dB。
因此最高峰不必是几何法向，扫描时也会出现竞争峰重排；不可把多峰当作CNN噪声删除。
峰值邻域与其他竞争峰分别统计，但局部峰不全部称为已经确认的栅瓣。

A01 Eθ占球面积分场能量约22.49%，原Eφ-only输出不能直接作为RealizedGainTotal。
随机相位B组峰值约10.4–12.2dBi，能量更加分散；相对峰值覆盖扩大可能只是峰值降低。
调幅改变能量分配而非必然抬高最大峰：C03/D03的有效激励阵元数约11.14/16，峰值约14.36/14.49dBi。
需要在同一四点坐标下评价其最小值，不能仅比较峰值判断调幅是否有效。

全球辐射算子有效秩约15.94/16，说明阵列整体未丧失大量辐射自由度；固定总功率且去掉公共相位后，
幅相/仅相位方向图控制约有30/15个实自由度。但四站高增益可行性还受孔径、方向相关性、极化和能量
分摊制约，不能用“16大于4”保证所有四站组合都可行。Gram最大特征值约1.018，需要保留数值积分/
归一化误差边界，不能将其解释为无源阵列效率超过100%。

## 2. 模型预算与结构

新候选使用同一套4×4孔径卷积模块、共享方向Fourier特征、阵元行列/边缘/角点特征。
学习Cartesian复场，固定横向投影后仅有两种独立极化；这样避免球面极点基底奇异。
解析传播相位exp(jkq·r)和线性Hᵀw收缩保留，RealizedGainTotal由复场和入射功率计算。
固定HFSS基底已经包含互耦，不另重复叠加相同含义的互耦矩阵，也不声称分离出器件误差。

参数28,854，低于旧34,973约17.5%；卷积MAC为459,648/方向。
最大单个方向特征张量31×4×4=496个float，不能将其误当全部运行时峰值内存。
Fourier、复收缩、横向投影不计入上述卷积MAC，实际FPGA资源、量化和时延待验证。
完整FFD表只在离线数据准备/参考评估使用，不需要作为模型权重部署。

## 3. 训练与消融

每轮采样2048个方向，分4批；每批64条训练命令。采用同一学习率调度和3个seed：29511/29512/29513。
基础loss为幅度NMSE+0.1功率NMSE+0.03dB Huber；dB数值底−50dB，不把它解释为实测噪声底。

| 配方 | 内容 |
|---|---|
| A | 双极化新结构的基础loss，从头训练 |
| B | A+0.5公共相位对齐的复算子监督，从头训练 |
| C | 继承A/B中被保留者的监督方式，增加0.08训练四点困难样本Huber |
| D | 困难样本loss增加0.01单侧高估惩罚，容差0.1dB |
| E | 累计困难样本/高估loss增加0.02四点弱点排序KL |

后三阶段从目前开发集最佳父配方初始化，属于顺序微调消融，不是完全因子实验。
困难命令由训练轨迹参考优化和每100轮的模型优化产生，验证/保留轨迹不回灌。
每条运行至少600轮；连续200轮最佳验证幅度NMSE改善<0.03dB则早停。
最初3000轮上限仍改善，故在保留集打开前统一允许延长到6000轮；达到上限仍改善要标为未收敛。
所有完成的checkpoint保留，后续不会为了选型覆盖旧运行。

配方以开发集phase-only四点P95 regret选择，同时全场NMSE不得比当前保留者退步超过0.3dB。
每运行checkpoint由验证NMSE选择；代表seed由开发四点P95 regret选择。不会根据最终保留结果重新选seed。

## 4. 隔离与验收

方向按绝对10°角块划分，并按30°×60°大区分层：训练36000点、验证10800点、校准7200点、保留10800点。
命令256/96/96/96，包含连续相位、4bit相位、连续幅相和指向命令；去公共相位后检查集合不交叉。
轨迹64/24/64/120条，每条3帧、每帧4站；全轨迹始终留在自己的角块分区。
三个轨迹族为聚集、前半球分散、全球压力。全局压力包含卫星不可能观测的方向，单列统计。

完整方向图在历史宏观诊断中已暴露，本轮是新命令/新轨迹与内部角块保留评估，不称为未见电磁状态盲测。
训练入口只加载dev文件；校准及holdout标签在选择冻结后评估。冻结/开启标记存在后训练入口拒绝重训。
按用户要求省略不必要哈希，使用分区不交叉检查、独立目录、配置比较和冻结标记约束流程。

沿用研究门槛：总增益全域MAE≤0.5dB，强场MAE≤0.35dB，四点MAE≤0.3dB，瓶颈高估P95≤0.75dB，
regret中位/P95≤5%/10%，三seed NMSE标准差≤0.25dB，且收敛。
尚无轨道、链路和FPGA约束，不能宣称达到绝对链路余量或板上验收。
